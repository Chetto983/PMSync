## Component Inventory

### Modified: `NotificationSettings` (`frontend/components/dashboard/settings/NotificationSettings.tsx`)

Current state: Single master toggle (enable/disable push notifications).

Addition for PUSH-05: Three category-specific toggles, visually nested below the master toggle.

```
[Bell icon] Push Notifications                    (h6 heading)
Receive alerts when new emails arrive...          (body1 description)

[!] Notifications blocked (Alert, only if denied)

[Switch] Enable push notifications                (master toggle)

  Category Preferences                            (subtitle2 subheading)
  [Switch] New email                              (category toggle)
           Get notified when new emails arrive    (body2 secondary)
  [Switch] Calendar                               (category toggle)
           Event invitations and reminders        (body2 secondary)
  [Switch] AI assistant                           (category toggle)
           AI task completions and suggestions    (body2 secondary)
```

**Behavior contract:**
- Category toggles are visually indented 32px (`pl: 4` in MUI spacing) from the master toggle
- Category toggles are disabled when master toggle is off (use `disabled` prop)
- Category toggles are disabled when permission is `denied`
- Each category toggle shows a `CircularProgress size={16}` replacing the switch during save
- Category preferences persist via a new backend endpoint (not localStorage)
- Default state for all categories: enabled (opt-out model, not opt-in)

### Not modified: Service Worker (`frontend/public/sw.js`)

PUSH-06 requires a `notificationclick` event handler in the service worker. This is invisible -- no UI component. The handler reads `event.notification.data.url` and calls `clients.openWindow(url)`.

No visual contract needed for this.

## Copywriting Contract

All strings go through the translation system (`frontend/locales/en.ts` and `it.ts`) under the `pwa.push` namespace.

| Element | Key | English Copy |
|---------|-----|-------------|
| Section heading | `pwa.push.title` | Push Notifications |
| Section description | `pwa.push.description` | Receive alerts when new emails arrive, even when PMSync is closed. |
| Master toggle label | `pwa.push.enableLabel` | Enable push notifications |
| Category subheading | `pwa.push.categoriesTitle` | Category Preferences |
| Category: email label | `pwa.push.categories.email` | New email |
| Category: email desc | `pwa.push.categories.emailDescription` | Get notified when new emails arrive |
| Category: calendar label | `pwa.push.categories.calendar` | Calendar |
| Category: calendar desc | `pwa.push.categories.calendarDescription` | Event invitations and reminders |
| Category: AI label | `pwa.push.categories.ai` | AI assistant |
| Category: AI desc | `pwa.push.categories.aiDescription` | AI task completions and suggestions |
| Error: subscribe fail | `pwa.push.subscribeError` | Could not enable notifications. Please try again. |
| Error: unsubscribe fail | `pwa.push.unsubscribeError` | Could not disable notifications. Please try again. |
| Error: prefs save fail | `pwa.push.prefsSaveError` | Could not save notification preferences. Please try again. |
| Blocked title | `pwa.push.blockedTitle` | Notifications blocked |
| Blocked description | `pwa.push.blockedDescription` | Your browser has blocked notifications for this site. Open your browser settings to re-enable them. |
| Empty state | N/A | Not applicable -- there is no empty state (toggles always render) |
| Destructive action | N/A | Not applicable -- no destructive actions in this UI surface |

**Push notification payload copywriting** (displayed by the browser, not React):

| Element | Copy pattern |
|---------|-------------|
| Single email notification title | `New email from {senderName}` |
| Single email notification body | `{subject}` (truncated to 120 chars) |
| Grouped notification title | `{count} new emails in "{threadSubject}"` |
| Grouped notification body | `from {sender1}, {sender2}, and {remainingCount} others` |
| Calendar notification title | `Calendar: {eventTitle}` |
| Calendar notification body | `{startTime} - {endTime}` |
| AI notification title | `AI Assistant` |
| AI notification body | `{taskSummary}` (truncated to 120 chars) |
