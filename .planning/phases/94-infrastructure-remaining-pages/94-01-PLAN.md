Health endpoint response shapes (from backend/src/modules/health/services/health.service.ts):
- GET /health -> { status: "healthy"|"degraded", timestamp, services: { database: {status, responseTime}, redis: {status, responseTime}, mistral: {status, ...} } }

Webhook endpoints (all @Public(), @SkipThrottle()):
- POST /webhooks/gmail/push -> body: { message: { data (base64), messageId, publishTime }, subscription }
- POST /webhooks/microsoft/notifications -> body: { value: MicrosoftGraphNotification[] } | query: ?validationToken=
- POST /webhooks/calendar/google/push -> headers: x-goog-channel-id, x-goog-resource-id, x-goog-channel-token
- POST /webhooks/calendar/microsoft/notifications -> body: { value: [...] } | query: ?validationToken=
- POST /webhooks/contacts/google/sync -> body: { providerId } + header: x-webhook-token
- POST /webhooks/contacts/microsoft/notifications -> body: { value: [...] } | query: ?validationToken=

Realtime auth flow:
1. GET /realtime/auth-token (with Better Auth cookie) -> { token: "pmsync.ws.<payload>.<signature>", expiresAt }
2. io("${baseUrl}/realtime", { auth: { token }, transports: ["websocket"] })
3. Server emits "connected" event: { userId, tenantId, email, timestamp }

Playwright config: baseURL from E2E_BASE_URL, apiURL from E2E_API_URL (default localhost:3100)
Auth: storageState at playwright/.auth/user.json (from auth.setup.ts)
Test pattern: import { test, expect } from '@playwright/test'; const apiURL = process.env.E2E_API_URL ?? 'http://localhost:3100';
