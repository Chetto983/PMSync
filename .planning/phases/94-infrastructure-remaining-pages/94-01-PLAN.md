Create `frontend/scripts/test-websocket.ts` as a **standalone Node script** (NOT a Playwright spec) that uses `socket.io-client` directly. Run with `npx tsx frontend/scripts/test-websocket.ts`.

The script:
1. Reads `E2E_API_URL` env var (default `http://localhost:3100`) for the backend URL.
2. Reads `E2E_USER_EMAIL` (default `admin@pmsync.local`) and `E2E_USER_PASSWORD` (default `TestPassword123!`).
3. Authenticates via HTTP: `POST ${apiURL}/api/auth/sign-in/email` with `{ email, password }`, extracts session cookie from `set-cookie` response header.
4. Requests realtime token: `GET ${apiURL}/realtime/auth-token` with the session cookie, parses JSON to get `{ token, expiresAt }`.
5. Asserts token is a non-empty string starting with `pmsync.ws.` and expiresAt is truthy.
6. Connects Socket.IO: `io(\`${apiURL}/realtime\`, { auth: { token }, transports: ['websocket'] })`.
7. Listens for `'connected'` event within 10 seconds (Promise.race with a timeout).
8. Asserts connected event data has `userId` (string), `tenantId` (string), `email` (string), `timestamp` (truthy).
9. Disconnects the socket cleanly.
10. Exits with code 0 on success, code 1 on any failure.

Use plain `fetch()` for HTTP calls (Node 18+ built-in). Use `console.log` for progress messages and `console.error` + `process.exit(1)` for failures. Import `io` from `socket.io-client`.

Structure as an async IIFE with try/catch. On any assertion failure or timeout, print the error and exit(1). On success, print "WebSocket test PASSED" and exit(0).

This is intentionally NOT a Playwright spec — per locked user decision, standalone Node scripts are more reliable for protocol-level WebSocket assertions.
