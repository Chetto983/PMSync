Create a new hook `useEmailChatActions` that returns context-aware email actions based on ViewContext.

Implementation:
1. Import ViewContext from use-voltagent-chat
2. Import useTranslations hook
3. Define EmailChatAction interface: { icon: ElementType, label: string, prompt: string, color: string }
4. Export function `useEmailChatActions(viewContext: ViewContext | undefined)`
5. Return empty array if viewContext.currentView !== 'thread' or !viewContext.selectedEmailId
6. When in thread view, return these 4 actions:
   - Reply (Reply icon): "Draft a professional reply to this email"
   - Summarize (FileText icon): "Summarize this email thread concisely"
   - Archive (Archive icon): "Archive this email"
   - Add Label (Tag icon): "Suggest appropriate labels for this email"
7. Use theme.palette for colors: primary.main for Reply, secondary.main for Summarize, success.main for Archive, warning.main for Label

Example structure:
```typescript
export function useEmailChatActions(viewContext: ViewContext | undefined) {
  const t = useTranslations();
  const theme = useTheme();

  if (viewContext?.currentView !== 'thread' || !viewContext?.selectedEmailId) {
    return [];
  }

  return [
    { icon: Reply, label: t.ai.emailActions.reply, prompt: '...', color: theme.palette.primary.main },
    // ... other actions
  ];
}
```
