<objective>
Externalize TriageLearningService signal buffer and score cache to Redis so that all backend replicas share the same signal state.

Purpose: With N replicas, each replica's in-memory Map buffer is invisible to other replicas. Signals hitting replica A are lost to replica B until periodic flush. The scoreCache Map diverges across replicas, serving stale scores. Moving to Redis lists for buffering and removing the scoreCache (Redis HGET is sub-ms) eliminates both problems.

Output: Updated triage-learning.service.ts with Redis-list signal buffer + atomic Lua drain, no in-memory scoreCache, and a test file validating the Redis operations.
</objective>

private async drainAndFlush(bufferKey: string, tenantId: string, senderEmail: string): Promise<void> {
  const rawSignals = await this.redis.eval(this.DRAIN_SCRIPT, 1, bufferKey) as string[];
  if (!rawSignals || rawSignals.length === 0) return;
  const signals = rawSignals.map(raw => JSON.parse(raw) as TriageSignal);
  await this.flushSenderSignals(`${tenantId}:${senderEmail}`, signals);
}
