## Spacing Scale

Declared values from `frontend/theme/tokens.ts` spacing export (8px base, Tailwind-inspired):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (spacing 1) | Icon gaps, inline padding |
| sm | 8px (spacing 2) | Compact element spacing |
| md | 16px (spacing 4) | Default element spacing, card padding (sm) |
| lg | 24px (spacing 6) | Card padding, section padding |
| xl | 32px (spacing 8) | Section spacing, content padding (md) |
| 2xl | 48px (spacing 12) | Large section breaks |
| 3xl | 64px (spacing 16) | Header height, page-level spacing |

Exceptions: Interactive elements (admin action buttons: ban, impersonate, revoke; all clickable controls) must have a CSS `min-height: 44px` and `min-width: 44px` for touch-target accessibility. This is a sizing constraint on interactive elements, not a layout spacing token.

## Typography

All values from `frontend/theme/typography.ts` MUI theme configuration. 4-size scale:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Caption (caption, body2 labels) | 12px (0.75rem) | 400 (normal) | 1.5 |
| Body (body1, body2, button) | 14px (0.875rem) | 400 (normal), 600 for buttons | 1.625 (relaxed) |
| Heading (h4) | 20px (1.25rem) | 600 (semibold) | 1.375 (snug) |
| Page title (h3) | 24px (1.5rem) | 600 (semibold) | 1.375 (snug) |

**MUI variant mapping:** `body2` uses 14px (same as body1) at weight 400. `caption` uses 12px at weight 400. The theme `body2` fontSize should be set to `0.875rem` (14px), not `0.8125rem` (13px), to maintain the 4-size scale.

## Color

All values from `frontend/theme/tokens.ts` dark/light color exports. Theme-aware via MUI `theme.palette.*`.

| Role | Dark Mode | Light Mode | Usage |
|------|-----------|------------|-------|
| Dominant (60%) | #0c1017 (background.default) | #f8fafc (background.default) | Page backgrounds, surfaces |
| Secondary (30%) | #131a24 (background.paper) | #ffffff (background.paper) | Cards, sidebar, settings panels, dialogs |
| Accent (10%) | #55cae5 (primary.main) | #00aced (primary.main) | See reserved list below |
| Destructive | #ef4444 (error.main) | #dc2626 (error.main) | Ban, delete, cancel subscription, remove member, account deletion |

Accent reserved for:
- Primary CTA buttons (Connect Provider, Create Organization, Invite Member, Save Changes)
- Active sidebar selection in settings navigation
- Active tab indicator in billing tabs
- OAuth provider connection success state
- Link text for upgrade prompts

## Interaction States

All pages must exhibit these states during verification:

| State | Expected Behavior |
|-------|-------------------|
| Loading | MUI Skeleton matching content layout (not spinner) |
| Error | MUI Alert with user-friendly message + retry action |
| Empty | Descriptive empty state with guidance and relevant CTA (not blank area) |
| Success | MUI Snackbar toast (auto-dismiss 5s) |
| Destructive success | MUI Snackbar toast confirming action completed |

**Note:** Full empty state and loading skeleton polish is deferred to Phase 96 (UIPOL-01, UIPOL-02). Phase 93 verifies existing states work, not that they are polished.
