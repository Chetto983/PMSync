## Visual Focal Point

## Interaction Contract

### Trigger Interactions

| Trigger | Action | Source Decision |
|---------|--------|-----------------|
| `Cmd+J` / `Ctrl+J` | Toggle overlay open/closed | D-01 |
| Header Sparkles icon click | Toggle overlay open/closed | D-02 |
| Command Palette "Open AI Assistant" | Open overlay (if closed) | D-03 |
| `Esc` key (when overlay focused) | Close overlay | D-12 |
| Close (X) button in drawer header | Close overlay | D-12 |
| Click outside drawer (backdrop) | Close overlay (MUI Drawer temporary default) | Discretion |

### Resize Interaction

| Interaction | Behavior | Source Decision |
|-------------|----------|-----------------|
| Drag left edge handle | Resize drawer width between 320px and 600px | D-10 |
| Release drag | Persist width to `localStorage` key `pmsync:ai-overlay-width` | D-11 |
| Initial open (no stored width) | Default width 420px | D-10 |
| Window narrower than drawer width | Clamp to `min(storedWidth, viewportWidth)` | Defensive |

### State Transitions

```
CLOSED --> [Cmd+J | icon click | palette command] --> OPEN
OPEN   --> [Cmd+J | Esc | X button | backdrop click] --> CLOSED
OPEN   --> [user navigates to different page] --> OPEN (context updates, D-07)
OPEN   --> [user starts dragging resize handle] --> RESIZING
RESIZING --> [mouseup / pointerup] --> OPEN (width persisted)
```

### Context Detection Flow

1. `usePageContext` reads `router.pathname` + `router.query`
2. Pattern-matches route:
   - `/dashboard/email/[threadId]` -> Email context
   - `/dashboard/contacts/[contactId]` -> Contact context
   - `/dashboard/crm/deals/[dealId]` -> Deal context
   - `/dashboard/calendar` -> Calendar context (if event selected)
   - All other routes -> General (no context)
3. For Email/Contact/Deal: reads entity from Zustand store or TanStack Query cache
4. Assembles `PageContext { type, entityId, label, metadata }` for system message injection
5. Context re-evaluated on every route change (D-07) via `useEffect` on `router.asPath`

## Drawer Layout Spec

```
+--+------------------------------------------+
|RH|  [Sparkles] AI Assistant    [context] [X] |  <- AiOverlayHeader (48px height)
|  |------------------------------------------|
|  |  [Thread List]  |  [Chat Thread]          |  <- ChatDesktopLayout (fills remaining)
|  |  (when width    |                         |
|  |   >= 480px)     |                         |
|  |                 |                         |
|  |  OR             |                         |
|  |                 |                         |
|  |  [Chat Thread only]                       |  <- When width < 480px, hide thread list
|  |                                           |
|  |------------------------------------------|
|  |  [Composer input]                         |  <- ChatThread footer
+--+------------------------------------------+

RH = Resize Handle (8px wide, full height, cursor: col-resize)
```

- Thread list sidebar within drawer: visible only when drawer width >= 480px (at 420px default, thread list is hidden; user must widen to see it)
- At widths < 480px: single-panel chat thread only, with a menu button to toggle thread list (reuses mobile layout pattern)
- Drawer occupies full viewport height (top: 0, bottom: 0)
- Drawer sits at `z-index: 1200` (MUI drawer default from tokens)

## Loading & Error States

### Loading States

| State | Visual | Duration |
|-------|--------|----------|
| Drawer opening | MUI Drawer slide-in animation (225ms, easing.out) | <300ms |
| Chat history loading | Skeleton placeholder matching existing `chat-skeleton` CSS class | Until data arrives |
| AI response streaming | Existing streaming UI in ChatThread (typing indicator + incremental text) | Variable |

### Error States

| Error | Visual | Recovery |
|-------|--------|----------|
| AI service unreachable | Alert (severity="error") at top of drawer body, above chat thread | Retry button in alert |
| Context enrichment failure | Context indicator shows "General assistant" fallback, no error UI | Automatic (degrades gracefully) |
| Chat history load failure | Alert with retry, replacing thread list area | Retry button |

## Discretion Decisions (Researcher Recommendations)

Per CONTEXT.md "Claude's Discretion" sections:

| Decision | Recommendation | Rationale |
|----------|---------------|-----------|
| Drawer variant | `variant="temporary"` (float on top with backdrop) | Matches "overlay" mental model from D-04; avoids Layout refactoring that "persistent" would require; consistent with SchedulingDrawer pattern |
| Keep /dashboard/ai route | Yes, keep route; render same ChatPage components | Backward compatibility per D-05; both route and overlay share ChatRuntimeProvider at Layout level; trivial to maintain |
| Backdrop style | Semi-transparent backdrop (`rgba(0,0,0,0.4)` light / `rgba(0,0,0,0.7)` dark) + blur(8px) | Matches existing MuiBackdrop overrides in theme; provides visual separation without full blackout |
| Animation style | Standard MUI Drawer slide-in from right | Consistent with SchedulingDrawer; no custom spring/bounce needed |
