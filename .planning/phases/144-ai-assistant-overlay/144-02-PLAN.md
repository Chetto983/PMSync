**1. Create `frontend/components/ai-overlay/ResizeHandle.tsx`:**

A left-edge drag handle using pointer capture for reliable cross-browser resize. Follows accessibility patterns from ChatMobileLayout.tsx (aria-label, keyboard handling).

```typescript
'use client';

import { useCallback } from 'react';
import { Box, alpha } from '@mui/material';
import { useTranslations } from '@/lib/hooks/use-translations';
```

**Props:**
```typescript
interface ResizeHandleProps {
  currentWidth: number;
  onResize: (width: number) => void;
}
```

**Pointer drag implementation:**
- `onPointerDown`: capture the starting `clientX` and `currentWidth`. Call `el.setPointerCapture(e.pointerId)`.
- Add `pointermove` listener on the element: `const delta = startX - ev.clientX;` (moving mouse LEFT increases width because drawer is right-anchored). Call `onResize(startWidth + delta)`.
- Add `pointerup` listener to clean up both listeners.
- Wrap in `useCallback` with deps `[currentWidth, onResize]`.

**Keyboard resize:**
- `onKeyDown`: `ArrowLeft` calls `onResize(currentWidth + 20)`, `ArrowRight` calls `onResize(currentWidth - 20)`.

**Accessibility attributes:**
- `role="separator"`
- `aria-orientation="vertical"`
- `aria-label={t.ai.overlay.resizeHandle}`
- `tabIndex={0}`

**Styling (MUI sx):**
```typescript
sx={{
  width: 8,
  cursor: 'col-resize',
  flexShrink: 0,
  display: 'flex',
  alignItems: 'center',
  justifyContent: 'center',
  transition: 'background-color 150ms',
  '&:hover, &:active': {
    bgcolor: (theme) => alpha(theme.palette.primary.main, 0.1),
  },
  '&:focus-visible': {
    bgcolor: (theme) => alpha(theme.palette.primary.main, 0.15),
    outline: (theme) => `2px solid ${theme.palette.primary.main}`,
    outlineOffset: -2,
  },
}}
```

Render a subtle vertical grip indicator (thin line) using a child `Box` with `width: 2`, `height: 24`, `borderRadius: 1`, `bgcolor: 'divider'`.
