  <action>
Create lighthouserc.js with:

```javascript
// Lighthouse CI Configuration
// https://github.com/GoogleChrome/lighthouse-ci

module.exports = {
  ci: {
    collect: {
      // URLs to test (run against local build)
      url: [
        'http://localhost:3001/dashboard/email',
        'http://localhost:3001/dashboard/email/compose',
      ],
      // Run 3 times for stability
      numberOfRuns: 3,
      // Start server during collect
      startServerCommand: 'npm run start',
      startServerReadyPattern: 'Ready in',
      startServerReadyTimeout: 30000,
    },
    assert: {
      assertions: {
        // Performance score (warn at 80, fail at 70)
        'categories:performance': ['warn', { minScore: 0.8 }],

        // Core Web Vitals 2025 thresholds
        // LCP: Good <= 2.5s
        'largest-contentful-paint': ['error', { maxNumericValue: 2500 }],
        // CLS: Good <= 0.1
        'cumulative-layout-shift': ['error', { maxNumericValue: 0.1 }],
        // INP proxy (TTI): Good <= 3.5s
        'interactive': ['warn', { maxNumericValue: 3500 }],

        // Project-specific targets from ROADMAP.md
        // Email list scroll < 100ms (measured via Performance API in app)
        // Thread load < 200ms (measured via Performance API in app)

        // Accessibility score
        'categories:accessibility': ['warn', { minScore: 0.9 }],

        // Best practices
        'categories:best-practices': ['warn', { minScore: 0.9 }],
      },
    },
    upload: {
      // Use temporary storage (no external service needed)
      target: 'temporary-public-storage',
    },
  },
};
```

This config:
- Tests email list and compose pages
- Runs 3 times for reliable metrics
- Enforces Core Web Vitals thresholds
- Uploads to temporary storage for PR review

<task type="auto">
  <name>Task 2: Integrate bundle analyzer into Next.js config</name>
  <files>frontend/next.config.ts</files>
  <action>
Modify next.config.ts to integrate @next/bundle-analyzer:

1. Import the bundle analyzer:
```typescript
import bundleAnalyzer from '@next/bundle-analyzer';

const withBundleAnalyzer = bundleAnalyzer({
  enabled: process.env.ANALYZE === 'true',
});
```

2. Wrap the existing config:
```typescript
export default withBundleAnalyzer(nextConfig);
```

3. Add npm script to package.json:
```json
"analyze": "ANALYZE=true npm run build"
```

The analyzer only runs when ANALYZE=true, so it won't affect normal builds.

DO NOT change any existing next.config.ts settings. Only add the bundle analyzer wrapper.

For Windows compatibility, the npm script should use cross-env or the Windows-compatible syntax. Actually, since Next.js reads the env var, we can just document running it manually:
```bash
# Unix/Mac
ANALYZE=true npm run build

# Windows PowerShell
$env:ANALYZE="true"; npm run build

# Windows CMD
set ANALYZE=true && npm run build
```

No need to add cross-env dependency.
  </action>
