# Phase 100 — UI Design Contract

> Visual and interaction contract for PWA Foundation. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope Note

Phase 100 is an **infrastructure phase**. It adds a web app manifest, service worker registration, PWA icon set, and Vercel cache headers. There are **no new UI components or screens**. The visual contract here covers manifest metadata, icon specifications, and meta tag values that affect how the app appears when installed on a home screen.

User-facing UI (install prompts, offline banners, update snackbars) is deferred to Phases 101, 102, and 105.

## Icon Specification (Phase 100 specific)

Source files: `frontend/public/Logo PMSync.svg`, `frontend/public/favicon.svg`

| File | Size | Purpose | Notes |
|------|------|---------|-------|
| `icons/icon-192x192.png` | 192x192 | Standard PWA icon (any) | Used by Android/desktop for app launcher |
| `icons/icon-512x512.png` | 512x512 | Splash/install icon (any) | Used by install dialog and splash screen |
| `icons/icon-maskable-192x192.png` | 192x192 | Android adaptive icon (maskable) | Logo content within central 80% safe zone |
| `icons/icon-maskable-512x512.png` | 512x512 | Android adaptive icon (maskable) | Logo content within central 80% safe zone |

Constraints:
- Each icon MUST be a separate file -- never use `"purpose": "any maskable"` on a single icon (anti-pattern from RESEARCH.md)
- Maskable icons MUST have the logo content within the central 80% circle (40px padding on 192, 51px padding on 512)
- Background for maskable icons: `#0c1017` (dark theme background, matches `background_color`)
- Output format: PNG, 8-bit, no transparency for maskable variants
- Standard (any) icons: transparent background with logo centered
