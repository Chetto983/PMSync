Internal validation functions:

1. **`validateAttachmentDownload(context, cookieHeader, providerId, results)`** (READ-06):
   - GET `/api/v1/emails?providerId=${providerId}&hasAttachments=true&limit=5` to find emails with attachments
   - Unwrap emails with `unwrapEmails(res)`
   - Find first email where `email.attachments?.length > 0`
   - If none found, log `SKIP: No emails with attachments for provider` and return (do NOT fail)
   - Extract `attachmentId = email.attachments[0].id`
   - GET `/api/v1/email/attachments/${attachmentId}/metadata` via `apiGet()` -- note singular `email` not `emails`
   - Unwrap: `const meta = res?.data ?? res`
   - `assertTrue(meta.filename, 'READ-06: Attachment has filename')`
   - `assertTrue(meta.mimeType, 'READ-06: Attachment has mimeType')`
   - `assertTrue(meta.size > 0, 'READ-06: Attachment has positive size')`
   - For the download endpoint, use Playwright `context.request.get()` directly (NOT `apiGet` which expects JSON):
     ```
     const dlResponse = await context.request.get(
       BACKEND_URL + `/api/v1/email/attachments/${attachmentId}/download`,
       { headers: { Cookie: cookieHeader } },
     );
     ```
   - `assertEqual(dlResponse.status(), 200, 'READ-06: Download returns 200')`
   - `const contentType = dlResponse.headers()['content-type']`
   - `assertTrue(contentType && contentType !== 'application/json', 'READ-06: Content-Type is not JSON')`
   - `const contentDisposition = dlResponse.headers()['content-disposition']`
   - `assertTrue(contentDisposition?.includes('attachment'), 'READ-06: Content-Disposition is attachment')`
   - `const body = await dlResponse.body()`
   - `assertTrue(body.byteLength > 0, 'READ-06: Downloaded file has content')`

2. **`validateOnDemandFetch(context, cookieHeader, providerId, attachmentId, metaRes, dlStatus, bodyLength, results)`** (READ-07):
   - This runs AFTER validateAttachmentDownload, reusing the same attachment data
   - If no attachmentId was found (SKIP scenario), skip this too
   - Check `meta.isInS3` or `meta.storageType` to determine cache state
   - Log whether this was a cache hit or on-demand fetch: `console.log('  INFO: Attachment ' + (isInS3 ? 'served from S3 cache' : 'fetched on-demand from provider'))`
   - `assertTrue(dlStatus === 200, 'READ-07: Download succeeds regardless of cache state')`
   - `assertTrue(bodyLength > 0, 'READ-07: File content returned regardless of cache state')`
   - IMPORTANT: To avoid duplicate download, pass the download results from validateAttachmentDownload into this function. Structure the caller to run attachment download first, capture results, then pass to on-demand validation.

3. **`validateFolderStats(context, cookieHeader, providerId, results)`** (READ-08):
   - GET `/api/v1/emails/stats?providerId=${providerId}` via `apiGet()`
   - Unwrap: `const stats = res?.data ?? res`
   - `assertTrue(typeof stats.total === 'number' && stats.total >= 0, 'READ-08: total is non-negative number')`
   - `assertTrue(typeof stats.unread === 'number' && stats.unread >= 0, 'READ-08: unread is non-negative number')`
   - `assertTrue(stats.total >= stats.unread, 'READ-08: total >= unread')`
   - `assertTrue(typeof stats.starred === 'number', 'READ-08: starred is number')`
   - `assertTrue(typeof stats.today === 'number', 'READ-08: today is number')`
   - `assertTrue(typeof stats.thisWeek === 'number', 'READ-08: thisWeek is number')`
   - `assertTrue(typeof stats.attachments === 'number', 'READ-08: attachments count is number')`
   - `assertTrue(typeof stats.byFolder === 'object' && stats.byFolder !== null, 'READ-08: byFolder is object')`
   - `assertTrue(Object.keys(stats.byFolder).length > 0, 'READ-08: byFolder has entries')`
   - Verify all byFolder values are non-negative numbers: `Object.values(stats.byFolder).every(v => typeof v === 'number' && v >= 0)`
   - Note: Do NOT assert byFolder sum equals total (emails can be in multiple folders/labels on Gmail)

4. **`validateSearch(context, cookieHeader, providerId, results)`** (READ-09):
   - GET `/api/v1/emails?providerId=${providerId}&limit=1` to get a real email
   - Unwrap emails, if empty, SKIP
   - Extract subject from first email
   - Extract a word of length >= 4 from subject: `subject.split(/\s+/).filter(w => w.length >= 4)`
   - Clean to alphanumeric: `word.replace(/[^a-zA-Z0-9]/g, '')`
   - If no suitable word found, SKIP with message
   - GET `/api/v1/emails/search?q=${encodeURIComponent(searchTerm)}&providerId=${providerId}&limit=20` via `apiGet()`
   - Unwrap: `const searchData = res?.data ?? res; const searchEmails = searchData?.emails ?? searchData ?? []`
   - `assertTrue(Array.isArray(searchEmails), 'READ-09: Search returns array')`
   - `assertTrue(searchEmails.length > 0, 'READ-09: Search returns at least 1 result for known term "' + searchTerm + '"')`
   - Verify at least one result contains the search term (case-insensitive) in subject or from:
     `searchEmails.some(e => (e.subject||'').toLowerCase().includes(searchTerm.toLowerCase()) || (e.from||'').toLowerCase().includes(searchTerm.toLowerCase()))`

5. **Main `validateAttachmentsSearch` function:**
   - Get all providers via `getProviders(context, cookieHeader)`
   - Filter by `options.provider` (mapping: 'gmail'->'google', 'outlook'->'microsoft', 'imap'->'imap')
   - For each matching provider:
     - Create results object: `{ name: providerLabel, checks: 0, passed: 0, failed: 0, failures: [] }`
     - `setResultsCollector(results)`
     - Run validateAttachmentDownload, capturing attachmentId/meta/dlStatus/bodyLength
     - Run validateOnDemandFetch with captured data
     - Run validateFolderStats
     - Run validateSearch
     - Each wrapped in try/catch pushing errors to failures
     - Push results to array
   - Return array

function providerTypeLabel(provider) {
  const type = provider.providerType || provider.type || '';
  if (type === 'google') return 'Gmail';
  if (type === 'microsoft') return 'Outlook';
  if (type === 'imap') return 'IMAP';
  return type;
}

function matchesProviderFilter(provider, filter) {
  if (filter === 'all') return true;
  const type = provider.providerType || provider.type || '';
  if (filter === 'gmail') return type === 'google';
  if (filter === 'outlook' || filter === 'microsoft') return type === 'microsoft';
  if (filter === 'imap') return type === 'imap';
  return false;
}

```javascript
/**
 * Attachments & Search Validation Orchestrator
 *
 * Usage:
 *   node scripts/validate-attachments-search.mjs --provider=gmail --quick
 *   node scripts/validate-attachments-search.mjs --provider=outlook
 *   node scripts/validate-attachments-search.mjs --provider=imap
 *   node scripts/validate-attachments-search.mjs                          # all providers
 *
 * Flags:
 *   --provider=gmail|outlook|microsoft|imap|all  (default: all)
 *   --quick    Skip extended tests
 *
 * Tests: READ-06 (attachment download), READ-07 (on-demand fetch),
 *        READ-08 (folder stats), READ-09 (full-text search)
 *
 * Requires Edge running with --remote-debugging-port=9222 and logged into PMSync.
 */
import { connectCDP, getAuthCookies, getCsrfToken, report } from './lib/validation-helpers.mjs';
import { validateAttachmentsSearch } from './lib/validate-attachments-search.mjs';

const args = process.argv.slice(2);
const providerFlag = args.find(a => a.startsWith('--provider='))?.split('=')[1] || 'all';
const quickMode = args.includes('--quick');

async function main() {
  console.log('=== Attachments & Search Validation ===');
  console.log(`Provider: ${providerFlag} | Quick mode: ${quickMode}\n`);

  const { browser, context } = await connectCDP();
  const cookieHeader = await getAuthCookies(context);
  const { csrfToken, cookieHeader: finalCookies } = await getCsrfToken(context, cookieHeader);

  const results = await validateAttachmentsSearch(context, finalCookies, csrfToken, {
    provider: providerFlag,
    quick: quickMode,
  });

  const exitCode = report('Attachments & Search Validation', results);
  await browser.close();
  process.exit(exitCode);
}

main().catch(err => { console.error('Fatal error:', err.message); process.exit(1); });
```

This is a short file (~45 lines). The orchestrator does nothing beyond CLI parsing, CDP auth setup, calling `validateAttachmentsSearch`, and reporting.
