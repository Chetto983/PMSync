- Call `apiPost(context, '/api/v1/email-sync/sync/' + providerId, null, cookieHeader, csrfToken)` to trigger sync for just the Gmail provider (NOT sync-all, which purges everything)
- Call `waitForSyncCompletion(context, cookieHeader)` — poll until queues empty
- Log "Gmail sync completed" with elapsed time

**Step 3: Folder validation**
- GET `/api/v1/folders?providerId={providerId}` — retrieve all folders for this provider
- Check system folders present: verify that `specialUse` values include at least: `INBOX`, `SENT`, `DRAFTS`, `TRASH` (Gmail always has these as labels)
- For each folder, verify `name` is non-empty and `externalId` is non-null
- Check folder hierarchy: if any folder has `parentId`, verify the parent exists in the folder list
- Log folder list with name, specialUse, totalCount, unreadCount

**Step 4: Email count validation**
- GET `/api/v1/emails?providerId={providerId}&folder=INBOX&limit=1` — extract pagination total from response
- Compare DB email count (from API response totals) against reasonable range: should be > 0 and <= fullSyncMaxMessages budget (default 2500)
- For INBOX specifically: verify count > 0 (every Gmail account has inbox emails)
- DO NOT compare against Gmail API directly (we don't have direct Google API access from script). Instead verify counts are plausible and non-zero.

**Step 5: Email field spot-check (5 emails)**
- GET `/api/v1/emails?providerId={providerId}&folder=INBOX&limit=5` — fetch 5 recent emails
- For each email, verify:
  - `subject` is non-empty string (not null, not "")
  - `from` is non-empty string containing "@"
  - `to` is an array with at least 1 element
  - `receivedAt` is a valid ISO date string
  - `externalId` is non-empty string
  - `labels` is an array (Gmail emails always have labels)
- GET single email by ID: `/api/v1/emails/{id}` — verify full body response includes `bodyHtml` or `bodyText` (at least one non-null)

**Step 6: Dedup check**
- GET `/api/v1/emails?providerId={providerId}&limit=100` — fetch 100 emails
- Extract all `externalId` values, put in a Set, verify Set.size === array.length (no duplicates)

**Step 7: Report**
Collect all checks into a results object: `{ name: 'Gmail', checks: N, passed: P, failed: F, failures: [...] }` and return it.

Use `assertEqual` and `assertRange` from the helpers for all assertions. Each assertion gets a descriptive label like `"Gmail: INBOX folder exists"`, `"Gmail: email[0].subject is non-empty"`.
