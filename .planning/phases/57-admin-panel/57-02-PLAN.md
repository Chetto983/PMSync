**3. Query hooks** (`frontend/hooks/queries/use-admin.ts`):
- `useAdminUsers(params: { limit?: number; offset?: number; searchField?: string; searchValue?: string })` -- useQuery wrapping `authClient.admin.listUsers()`
- `useBanUser()` -- useMutation wrapping `authClient.admin.banUser()`, invalidates admin users query on success
- `useUnbanUser()` -- useMutation wrapping `authClient.admin.unbanUser()`, invalidates admin users query
- `useImpersonateUser()` -- useMutation wrapping `authClient.admin.impersonateUser()`, does `window.location.reload()` on success (session changes)
- `useStopImpersonating()` -- useMutation wrapping `authClient.admin.stopImpersonating()`, does `window.location.reload()`
- `useAdminUserSessions(userId: string)` -- useQuery wrapping `authClient.admin.listUserSessions()`
- `useRevokeUserSessions()` -- useMutation wrapping `authClient.admin.revokeUserSessions()`, invalidates user sessions query
- Follow existing hook patterns: use queryOptions, staleTime: 30_000, import authClient from '@/lib/auth-client'

- Props: `open: boolean, onClose: () => void, userId: string, userName: string`

**9. ImpersonationBanner** (`frontend/components/admin/ImpersonationBanner.tsx`):
- Uses `authClient.useSession()` to get current session
- Checks if session has `impersonatedBy` field set (cast session as any to access it, since better-auth types may not expose it directly)
- If impersonating: renders a fixed-position Banner (MUI Alert severity="warning") at the top of the page with user's name and a "Stop Impersonating" button
- Uses `useStopImpersonating` mutation on button click
- If not impersonating: renders null
