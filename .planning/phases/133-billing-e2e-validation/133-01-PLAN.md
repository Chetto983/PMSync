**Infrastructure (copy from reference script):**
- `BACKEND` constant: `'https://backend-production-78e1.up.railway.app'`
- `RESULTS` array for tracking test outcomes
- `getSessionFromCDP()` function — identical to reference (ws import, port 9222, extract session_token + csrf cookies)
- `log(label, pass, detail)` function — color-coded PASS/FAIL with `\x1b[32m`/`\x1b[31m`
- `api(method, path, cookie, csrf, body)` function — fetch wrapper with Cookie and x-csrf-token headers, returns `{ status, data, latency }`

**Main function test cases in this exact order:**

1. **B-01 Session + Subscription state** — `GET /api/auth/get-session` to extract tenantId, then `GET /api/v1/subscription` to verify response shape. Log plan, status, autumnCustomerId. PASS if status 200 and `plan` is one of `['FREE', 'STARTER', 'PROFESSIONAL', 'ENTERPRISE']`.

2. **B-02 Feature check (entitlement gating)** — `POST /api/v1/autumn/check` with body `{ featureId: 'email-processing' }`. PASS if status 200. Log `allowed` and `remaining` values.

3. **B-03 Usage tracking** — First `GET /api/v1/subscription/usage` to capture `aiCallsUsed` baseline. Then `POST /api/v1/autumn/track` with body `{ featureId: 'ai-calls', amount: 1 }`. Then `GET /api/v1/subscription/usage` again. PASS for track if status 200. PASS for increment if `aiAfter >= aiBefore` (Autumn may batch-process). Log before/after values.

4. **B-04 Billing portal URL** — `POST /api/v1/autumn/billing_portal` with body `{}`. PASS if status 200 and response has a `url` field that is a non-empty string. Log first 60 chars of URL.

5. **B-05 Attach flow** — First check current subscription. If plan is `'FREE'`, call `POST /api/v1/autumn/attach` with body `{ productId: 'starter' }`. PASS if status 200 and response contains `checkoutUrl` that starts with `https://`. If already on paid plan, log `SKIPPED -- already subscribed` and mark PASS. **Do NOT follow the checkoutUrl** (it opens Stripe hosted checkout).

6. **B-06 Cancel flow** — If subscription plan is NOT `'FREE'`, call `POST /api/v1/autumn/cancel` with body `{ productId: '<lowercase plan name>' }`. PASS if status 200. Then `GET /api/v1/subscription` and log `cancelAt` and `status`. If plan IS `'FREE'`, mark PASS with `SKIPPED -- on FREE plan`.

7. **B-07 Webhook rejects unsigned** — Direct `fetch` (NOT through `api()` helper since webhook path is `/webhooks/autumn` not `/api/v1/...`) to `${BACKEND}/webhooks/autumn` with POST, body `{ type: 'test', data: {} }`, no auth cookies, no Svix headers. PASS if status is 401 OR 400 OR 500 (any rejection). FAIL only if status is 200 (would mean unsigned requests are accepted).

8. **B-08 Cost protection status** — `GET /api/v1/subscription/cost-status`. PASS if status 200. Log `dailyCost`, `dailyCap`, `percentUsed`, `alertLevel`.

9. **B-09 Subscription state consistency** — Final `GET /api/v1/subscription`. Validate: `plan` is in `['FREE', 'STARTER', 'PROFESSIONAL', 'ENTERPRISE']`, `status` is in `['ACTIVE', 'PAST_DUE', 'CANCELED', 'TRIALING']` (or null for FREE), `usage` object exists. PASS if all valid.

10. **B-10 Pricing table** — `GET /api/v1/autumn/components/pricing_table`. PASS if status 200. Log response data type and length.

**Summary section:**
After all tests, log a summary line with total passed/failed count in green (0 failures) or red, then list all failures with label and detail.

**Error handling:**
- Wrap each test case in try/catch. On error, log FAIL with error message. Do NOT abort the script on individual test failure.
- If `getSessionFromCDP()` fails, log instructions: "Launch Edge with --remote-debugging-port=9222 and open https://mail-agent-indol.vercel.app"
- If subscription response has no `autumnCustomerId`, log warning: "Autumn may not be configured on Railway -- some tests may return fallback data"

**File constraints:**
- Max 500 lines (project rule). Target ~300-350 lines.
- Standalone `.mjs` file, no imports except dynamic `ws` import in CDP function.
