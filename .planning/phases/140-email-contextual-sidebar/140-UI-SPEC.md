# Phase 140 — UI Design Contract

> Visual and interaction contract for the Email Contextual Sidebar. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | MUI (Material UI) |
| Icon library | lucide-react |
| Font | System default (inherited from MUI theme) |

**Note:** This project uses MUI exclusively. No shadcn, no Tailwind utilities in components. All styling via MUI `sx` props and theme tokens.

---

## Spacing Scale

Declared values (MUI 8px base, `theme.spacing(n)` where 1 = 8px):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (0.5) | Icon-label gaps, chip margins |
| sm | 8px (1) | Compact element spacing, section divider vertical margins, tag container bottom margin |
| lg | 16px (2) | Sidebar content padding, sidebar header padding, section bottom margins |
| xl | 24px (3) | Not used in this phase |
| 2xl | 48px (6) | Not used in this phase |

Exceptions: Touch targets for collapse/expand IconButton are 44x44px (accessibility minimum). Already implemented.

---

## Typography

All typography uses MUI `variant` prop. No custom font sizes in this phase.

| Role | MUI Variant | Size | Weight | Line Height |
|------|-------------|------|--------|-------------|
| Body | body2 | 14px | 400 | 1.43 |
| Label | caption | 12px | 400 | 1.66 |
| Section heading | subtitle2 | 14px | 500 | 1.57 |
| Tag chip text | (custom) | 11px (0.7rem) | 400 | 1.2 |

Source: Existing `EntityContextSidebar.tsx` already uses these variants. Tags chip text at `fontSize: '0.7rem'` matches existing deal stage chip pattern (`fontSize: '0.65rem'` on deal stage, `0.7rem` for tags is the recommended size for better readability at small scale).

---

## Color

All colors use MUI theme tokens. No hardcoded hex values except the existing relationship strength colors.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `background.default` | Email content area behind sidebar |
| Secondary (30%) | `background.paper` | Sidebar Drawer surface, toggle button background |
| Accent (10%) | `primary.main` (teal hsl(189,70%,50%)) | Avatar background, contact name links |
| Destructive | Not used in this phase | No destructive actions |

Accent reserved for: Contact avatar background color only.

Semantic colors already in use (DO NOT CHANGE):
- Relationship strength: `#4caf50` (strong), `#ff9800` (moderate), `#ef5350` (weak)
- Deal stage chips: Use `deal.stage.color` from backend
- Ticket status chips: Default outlined variant (no custom color)
- Tag chips: `outlined` variant, inherits `text.primary` border and text (no accent color)

## Interaction Contract

### Collapse/Expand

| Behavior | Specification |
|----------|---------------|
| Toggle trigger | IconButton with `PanelRightClose` (when open) / `PanelRightOpen` (when closed) |
| Touch target | 44x44px |
| Animation | MUI Drawer `persistent` variant transition (theme default duration) |
| Persistence | localStorage `pmsync:crm-sidebar-open`, survives page reload and navigation |
| Sidebar width | 320px (constant `SIDEBAR_WIDTH`) |

### Tag Chips

| Behavior | Specification |
|----------|---------------|
| Interaction | Display-only, not clickable, not editable |
| Overflow | Flex wrap to multiple rows |
| Max tags shown | No limit (all tags rendered) |
| Keyboard | Not focusable (display-only) |

### Loading States

| State | Behavior |
|-------|----------|
| Loading | `SidebarSkeleton` (already implemented) -- circular + text + rectangular skeletons |
| Error | Warning Alert with "No CRM data" message (already implemented) |
| Unknown contact | "Unknown Contact" text + "Create Contact" chip (already implemented) |
| No CRM data | Info Alert "No CRM data yet" (already implemented) |
| No tags | Tags section not rendered at all |
