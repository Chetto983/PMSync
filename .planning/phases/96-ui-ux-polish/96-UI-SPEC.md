## Spacing Scale

MUI spacing unit is 8px. All spacing uses MUI `sx` numeric shorthand (e.g., `py: 2` = 16px).

| Token | Value | MUI sx | Usage |
|-------|-------|--------|-------|
| xs | 4px | 0.5 | Icon gaps, inline padding |
| sm | 8px | 1 | Compact element spacing |
| md | 16px | 2 | Default element spacing, card inner padding |
| lg | 24px | 3 | Section padding, card padding (layout.card.padding.lg) |
| xl | 32px | 4 | Layout gaps, section spacing |
| 2xl | 48px | 6 | Large section breaks |
| 3xl | 64px | 8 | Page-level spacing, header height |

Exceptions:
- Empty state vertical padding: `py: 8` (64px) for centered empty state layout
- Touch targets: minimum 44px (MUI Tab minHeight already 44px)
- Content max width: 1400px (layout.content.maxWidth)

## Component Inventory (New Shared Components)

### EmptyState

| Property | Value |
|----------|-------|
| Location | `frontend/components/common/EmptyState.tsx` |
| Props | `icon: ReactNode`, `color: string`, `title: string`, `description: string`, `actionLabel?: string`, `onAction?: () => void` |
| Layout | Vertically centered flex column. Icon in 48x48 circle with `alpha(color, 0.12)` background. Icon size 24px. Title as `Typography variant="h6"`. Description as `Typography variant="body2" color="text.secondary"` with `maxWidth: 360`. Optional contained Button. |
| Spacing | `py: 8` (64px top/bottom), `px: 3` (24px sides), `mb: 2` (16px) below icon, `mb: 1` (8px) below title, `mb: 3` (24px) below description |

### QueryErrorAlert

| Property | Value |
|----------|-------|
| Location | `frontend/components/common/QueryErrorAlert.tsx` |
| Props | `error: Error | null`, `onRetry: () => void`, `title?: string` |
| Layout | MUI `Alert` with `severity="error"`, standard variant. Action slot contains small Button with `RefreshCw` icon (14px) and retry label. |
| Spacing | `mx: 2, my: 2` (16px margin) |
| Behavior | Replaces content area inline. Stays visible until retry succeeds or component unmounts. |

### Page Data Flow Pattern

Every page that fetches data MUST follow this exact order:

```
1. if (isLoading) return <PageSkeleton />;
2. if (error) return <QueryErrorAlert error={error} onRetry={refetch} />;
3. if (!data || data.length === 0) return <EmptyState ... />;
4. return <ActualContent data={data} />;
```

Use `isLoading` (not `isFetching`) to prevent skeleton flash on cached data.

## Mobile Responsiveness Contract

Minimum supported width: 375px (iPhone SE).

| Breakpoint | MUI key | Value | Behavior |
|------------|---------|-------|----------|
| Mobile | xs | 0-639px | Single column, stacked layouts, hamburger nav |
| Tablet | sm | 640-767px | Transitional (same as mobile for most pages) |
| Small desktop | md | 768-1023px | Side panel layouts begin (email, chat already use this) |
| Desktop | lg | 1024px+ | Full layout with expanded sidebar |

### Mobile Rules

- No horizontal overflow at 375px. Use `overflow: hidden` + `textOverflow: 'ellipsis'` on text.
- Tables: use `{ display: { xs: 'none', md: 'block' } }` to hide non-essential columns.
- Side-by-side layouts: stack vertically below `md` breakpoint.
- Content padding: `layout.content.padding.xs` (16px) on mobile, `layout.content.padding.sm` (24px) on tablet, `layout.content.padding.md` (32px) on desktop.
- Use `useMediaQuery(theme.breakpoints.down('md'))` for mobile detection (consistent with existing email/chat patterns).

## Dark Mode Contract

- All colors through MUI `palette.mode` system. Never use hardcoded hex in `sx` props.
- Reference palette tokens: `background.default`, `background.paper`, `text.primary`, `text.secondary`, `divider`, `action.hover`.
- ChatThemeBridge stays (removed in Phase 97). Do not touch chat dark mode.
- MUI Skeleton backgroundColor is already themed (`darkColors.background.hover` / `lightColors.background.hover`).
- Verify: no white backgrounds, no invisible text, no unreadable borders in dark mode per page.

---

## Keyboard Navigation Contract

- Level: Tab + Enter on all interactive elements. No custom keyboard shortcuts.
- Focus rings: MUI default `:focus-visible` styling (browser outline or MUI focus ring).
- Every `Button`, `IconButton`, `ListItemButton`, `Tab`, `TextField`, `Select`, `Checkbox`, `Switch`, `Radio` is natively keyboard-accessible via MUI.
- Audit targets: any custom `Box` or `div` with `onClick` handlers MUST have `role="button"`, `tabIndex={0}`, and `onKeyDown` for Enter/Space.
- Dialog/Drawer focus trapping: handled by MUI built-in.

## i18n Contract

- Script-based key comparison: `en.ts` vs `it.ts` leaf key paths.
- Grep `.tsx` files for hardcoded English strings: `>'[A-Z]`, `"[A-Z][a-z]+ `, string literals in JSX.
- Every new string added in this phase gets both `en` and `it` translations in the same task.
- Translation key namespace for new empty state strings: `t.{domain}.emptyTitle`, `t.{domain}.emptyDescription`, `t.{domain}.emptyCta`.
- Error state strings: `t.errors.genericError`, `t.errors.genericErrorDescription`, `t.errors.connectionError`, `t.errors.connectionErrorDescription`, `t.errors.accessDenied`, `t.errors.accessDeniedDescription`.
- Common strings: `t.common.retry`.
