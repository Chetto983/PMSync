  <action>
Replace the static import of Calendar with a next/dynamic import in `frontend/pages/dashboard/calendar.tsx`.

Current line to remove:
```typescript
import { Calendar } from '@/components/dashboard/Calendar';
```

Add these imports at the top:
```typescript
import dynamic from 'next/dynamic';
import { Skeleton } from '@mui/material';
```

Add the dynamic import after the imports:
```typescript
const Calendar = dynamic(
  () => import('@/components/dashboard/Calendar').then(m => ({ default: m.Calendar })),
  { ssr: false, loading: () => <Skeleton variant="rounded" height={600} /> },
);
```

Keep the `React` import only if still needed (check if JSX transform requires it). Keep Layout, PageErrorBoundary imports. Keep `getServerSideProps`. The rest of CalendarPage component body stays identical.

The `.then(m => ({ default: m.Calendar }))` is required because Calendar is a named export, not default.

`ssr: false` is required because FullCalendar accesses `window`/`document`.
