2. Create `frontend/hooks/use-hover-popover.ts`:
   - Implement `useHoverPopover(openDelay = 300, closeDelay = 200)` exactly as specified in the research:
     - `anchorEl` state (HTMLElement | null)
     - `openTimer` and `closeTimer` refs
     - `handleMouseEnter`: clears close timer, starts open timer (captures `event.currentTarget` in closure BEFORE setTimeout)
     - `handleMouseLeave`: clears open timer, starts close timer
     - `handlePopoverMouseEnter`: clears close timer (prevents flicker)
     - `handlePopoverMouseLeave`: starts close timer
     - Cleanup: `useEffect` that clears both timers on unmount
   - Return: `{ anchorEl, open: !!anchorEl, triggerProps: { onMouseEnter, onMouseLeave }, popoverProps: { onMouseEnter, onMouseLeave } }`
   - CRITICAL for flicker prevention: the popover's mouse handlers must be on a wrapper `Box` inside the `Popover`, not on the `Popover` itself (MUI Popover has a backdrop that intercepts events).

3. Create `frontend/components/contacts/ContactHoverCard.tsx`:
   - Props: `{ email: string; anchorEl: HTMLElement | null; open: boolean; popoverProps: { onMouseEnter: () => void; onMouseLeave: () => void } }`
   - Use MUI `Popover` with `anchorEl`, `open`, `anchorOrigin: { vertical: 'bottom', horizontal: 'left' }`, `transformOrigin: { vertical: 'top', horizontal: 'left' }`
   - Set `disableRestoreFocus`, `sx: { pointerEvents: 'none' }` on Popover, and `sx: { pointerEvents: 'auto' }` on the inner Box wrapper (standard MUI hover popover pattern to prevent flicker)
   - Wrap inner content in a `Box` with `{...popoverProps}` for mouse enter/leave
   - Fetch data: `useCrmContextByEmail(email)` (already cached with staleTime 5min)

   - No data state: subtle "No CRM data" text (when API returns null)
