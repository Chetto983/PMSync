## Spacing Scale

Declared values (MUI spacing factor = 8px base):

| Token | Value | Usage |
|-------|-------|-------|
| 0.5 | 2px | Tight inline gaps (chip margins) |
| 1 | 4px | Icon gaps, inline padding, list/menu item margins |
| 1.5 | 6px | Small icon button padding |
| 2 | 8px | Base unit, compact element spacing, accordion margin |
| 3 | 12px | Menu item padding, alert/dialog content padding |
| 4 | 16px | Default element spacing, card padding (sm), accordion details |
| 5 | 20px | Card padding (md), dialog title/actions vertical padding |
| 6 | 24px | Section padding, card padding (lg), dialog horizontal padding |
| 8 | 32px | Layout gaps, content padding (md) |
| 12 | 48px | Large section breaks |
| 16 | 64px | Header height, page-level spacing |

Exceptions: Touch targets at 44px (MuiTabs minHeight, icon button sizeLarge at 12px padding ~ 48px total).

Source: `frontend/theme/tokens.ts` spacing scale + layout constants.

## Interaction Contracts

These are the specific interaction behaviors this phase verifies. Each maps to a requirement.

### Email List (FE-03)
| Interaction | Expected Behavior |
|-------------|-------------------|
| Scroll to bottom | Next page loads (infinite scroll or pagination) |
| Click thread row | Opens thread view in reading pane |
| Checkbox click | Selects email without opening thread |
| Quick action hover | Archive/delete/star icons appear on row hover |
| Search input | Filters email list by query, debounced 300ms |
| Folder sidebar click | Filters list to selected folder |
| Label sidebar click | Filters list to selected label |

### Thread View (FE-04)
| Interaction | Expected Behavior |
|-------------|-------------------|
| Open thread | All messages render with correct sender, date, body |
| Click attachment | Downloads file (on-demand fetch if storageType=pending) |
| Reply button | Opens compose dialog pre-filled with reply context |
| Forward button | Opens compose dialog pre-filled with forward context |
| Star/flag toggle | Immediate optimistic update, persists on refresh |
| Delete | Moves to trash with undo snackbar |

### Compose (FE-05)
| Interaction | Expected Behavior |
|-------------|-------------------|
| New compose | Empty dialog with To/Subject/Body fields |
| Reply compose | Pre-filled recipients + quoted body, editable subject |
| Forward compose | Pre-filled body with forwarded content, empty To |
| Edit subject in reply | User edit persists through send (not reverted) |
| Add attachment | File picker, attachment chip appears |
| Schedule send | Date/time picker dialog, deferred send via BullMQ |
| Send | Button disabled during send, success snackbar, dialog closes |
| Undo send | Snackbar with undo action (client-side delay before actual send) |
| Draft save | Auto-saves on interval, manual save button |

### Folders (FE-13)
| Interaction | Expected Behavior |
|-------------|-------------------|
| Create folder | Dialog with name + optional parent, creates via API |
| Rename folder | Context menu > rename, inline edit or dialog |
| Delete folder | Confirmation dialog, deletes via API |
| Drag email to folder | Email moves to target folder, optimistic update |
| Drag folder to reorder | Folder order updates, persists after refresh |
| DnD isolation | Folder reorder and email drop use separate DnD contexts |

### Labels (FE-12)
| Interaction | Expected Behavior |
|-------------|-------------------|
| Create label | Dialog with name + color picker |
| Edit label | Context menu > edit, dialog pre-filled |
| Delete label | Confirmation dialog |
| Drag label to reorder | Order persists after refresh (orderIndex saved) |
| Drag email to label | Label assigned to email(s), chip appears on thread row |
| Cross-parent level shift | Label can be nested/unnested via drag |

### Signatures & Templates (BAPI-04, BAPI-05)
| Interaction | Expected Behavior |
|-------------|-------------------|
| List signatures | All signatures displayed |
| Create/edit/delete signature | CRUD via API, list refreshes |
| Set default signature | Default indicator updates |
| Signature in compose | Selected signature appended to email body |
| List templates | All templates displayed with categories |
| Create/edit/delete/duplicate template | CRUD via API, list refreshes |
| Template in compose | Template content inserted into editor |
