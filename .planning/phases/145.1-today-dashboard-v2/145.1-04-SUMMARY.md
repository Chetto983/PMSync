# Phase 145.1 Plan 04: Composite Components + Barrel Cleanup Summary

## One-liner

Ships the composite core of the Today Dashboard v2 — `TodayStream` (sticky collapsible header, role="list" as sibling of AnimatePresence, useReducedMotion wiring on 4 surfaces), `TodayRow` (40px, native anchor title, hover-reveal actions trio, 6s dismiss undo via Zustand), `TodayDashboard` (single-filter container, 4 streams in STREAM_ORDER, Stack maxWidth 880 shell) — and a barrel cleanup that deletes 6 legacy tier/greeting files. The three structural review findings (WR-03, WR-04, WR-06) are fixed by construction and grep-verifiable.

## What shipped

### `TodayStream.tsx` (new — 168 lines)

Renders the sticky header + collapsible list container for one of the four streams. Composition (grep-verifiable):

```
<Collapse in={expanded} timeout={reducedMotion ? 0 : 200}>      line 140
  <Box id={`stream-${name}-body`} role="list">                  line 141
    <AnimatePresence initial={false} mode={...}>                line 149
      {items.map(item => <motion.div key=...><TodayRow/></motion.div>)}
    </AnimatePresence>
  </Box>
</Collapse>
```

**WR-03 structural fix.** `role="list"` sits on a Box that is a SIBLING (not parent, not child) of `<AnimatePresence>` — inside `<Collapse>` but outside `<AnimatePresence>`. framer-motion no longer injects DOM wrappers between `role="list"` and `role="listitem"`. Direct-child semantics preserved for screen readers.

**Empty-stream hiding (D-02).** `if (!loading && items.length === 0) return null` at line 63 hides empty streams entirely. Loading still renders a 3-skeleton placeholder to avoid layout jump.

**Sticky header a11y.** `role="button"`, `tabIndex={0}`, `aria-expanded={expanded}`, `aria-controls={stream-${name}-body}`, Enter/Space keyboard activation, `&:focus-visible` outline. The chevron rotation is wrapped in `<Box component="span" sx={{ ... }}>` so the `@media (prefers-reduced-motion: reduce)` block inside the sx can actually apply — the prior `<ChevronDown style={{ transform }}>` inline pattern from PATTERNS.md line 816 would have been outside sx's media-query emitter.

**Plan 02 store consumption.** `useTodayFeedStore((s) => s.isToggled(name))` + `useTodayFeedStore((s) => s.toggleStream)` — the semantically-correct `toggledStreams` slice (NOT `collapsedStreams`/`isCollapsed`/`toggleCollapsed`). The `expanded` boolean is computed as `storeToggled ? !defaultExpanded : defaultExpanded` — flip-from-default semantics.

**Reduced-motion wiring (4 surfaces).** Line numbers for Plan 05's mock authors:

| Surface | Line | Pattern |
|---|---|---|
| `useReducedMotion` import | 24 | `import { AnimatePresence, motion, useReducedMotion } from 'framer-motion'` |
| Hook invocation | 54 | `const reducedMotion = useReducedMotion();` |
| Chevron `@media` fallback | 128 | `'@media (prefers-reduced-motion: reduce)': { transition: 'none' }` inside same sx as `transition: 'transform 150ms ease-out'` |

## WR-xx Resolutions (grep-verified)

### WR-03 — role="list" parent/child a11y

Prior bug: `TodayFeedList.tsx` wrapped `role="list"` as the outer element, but `<AnimatePresence>` + `<motion.div>` children broke the direct-child semantics — screen readers saw zero `role="listitem"` direct children of `role="list"`.

Fix location: `frontend/components/dashboard/today/TodayStream.tsx`, lines 140-163.

Structural grep:

```
$ grep -nE '<Collapse|role="list"|<AnimatePresence' frontend/components/dashboard/today/TodayStream.tsx
140:      <Collapse in={expanded} timeout={reducedMotion ? 0 : 200}>
141:        <Box id={`stream-${name}-body`} role="list">
149:            <AnimatePresence initial={false} mode={reducedMotion ? 'wait' : 'popLayout'}>
```

Order: `<Collapse` (140) → `role="list"` (141) → `<AnimatePresence` (149). ✓ `role="list"` is INSIDE `<Collapse>` but OUTSIDE `<AnimatePresence>` — a sibling of AnimatePresence, not a parent or child of motion.div.

### WR-04 — double-filter

Prior bug: `TodayDashboard.tsx` computed `visibleItems` via `.filter(dismissed)` and then passed `data.items` (unfiltered!) into `TodayFeedList`, which re-applied the same filter. Two filter calls, inconsistent state during the gap.

Fix location: `frontend/components/dashboard/today/TodayDashboard.tsx`, line 65 (only filter call in file).

Sentinel grep:

```
$ grep -nE '\.filter\(' frontend/components/dashboard/today/TodayDashboard.tsx
65:    const visible = items.filter((i) => !dismissedIds.has(i.id));
```

Exactly 1 filter call. Downstream `TodayStream` receives `items={itemsByStream[stream]}` and never re-filters. `TodayStream.tsx` contains zero `dismissedIds` references (verified: `grep -c dismissedIds frontend/components/dashboard/today/TodayStream.tsx` returns 0).

### WR-06 — Cmd/Ctrl/middle-click on rows

Prior bug: `TodayFeedItem.tsx` routed clicks via `const navigate = () => router.push(...)` — a synchronous `onClick` that swallowed modifier keys. Cmd+click opened in the same tab; middle-click did nothing.

Fix location: `frontend/components/dashboard/today/TodayRow.tsx`, lines 176-177.

Grep:

```
$ grep -n 'component="a"' frontend/components/dashboard/today/TodayRow.tsx
176:        component="a"
$ grep -n 'href={item.routeUrl}' frontend/components/dashboard/today/TodayRow.tsx
177:        href={item.routeUrl}
$ grep -c "next/link\|useRouter\|router\.push" frontend/components/dashboard/today/TodayRow.tsx

```

Title is a real `<a href>` — browser handles Cmd/Ctrl/middle-click natively. `stopBubble` onClick calls `stopPropagation()` only (NOT `preventDefault`) so the native anchor behaviour is preserved while blocking any future row-body handler from double-firing.


**Test mocks MUST expose `isToggled` + `toggleStream`**, NOT the legacy `isCollapsed` / `toggleCollapsed` / `collapsedStreams` names. Any mock that maps the legacy names back will produce expansion state inverted from the real component.

### Rule 2 (missing critical correctness) — `stopBubble` onClick on Link

Plan draft had no onClick on the row title. Added `onClick={stopBubble}` with `e.stopPropagation()` only (NO `preventDefault`). Critically, `preventDefault` is NOT called — the anchor's native Cmd/Ctrl/middle-click behaviour is preserved (which is the whole point of WR-06). This is defense-in-depth for the WR-06 fix, not a scope expansion.
