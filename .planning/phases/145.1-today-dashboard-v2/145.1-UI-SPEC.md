## Components

### `<TodayDashboard>` (container)
- Props: none.
- Fetches `GET /dashboard/today` via `useTodayFeed` hook.
- States: loading (per-stream skeleton), error (full-page `Alert`), empty-all (celebration card), populated (streams).
- Layout: `<Stack maxWidth={880} mx="auto" px={{ xs: 2, md: 3 }} py={3} spacing={2}>`.

### `<TodayHeader>`
- Renders greeting (localized `dashboard.today.greeting.{morning|afternoon|evening}`), date (localized via date-fns), and `<TodayKpiChip>` grid.
- No click handlers on greeting or date; they are inert.
- Responsive: KPI chips wrap to 2 rows on viewport < 600px.

### `<TodayKpiChip>`
- Props: `{ icon: LucideIcon, count: number, secondary?: string, href: string, label: string }`.
- Visual: `<Chip>` variant outlined, 14px/600 gray-900 count, 16px lucide icon.
- Click: `router.push(href)`. Cmd+click = new tab.
- Hover: shadow-sm + border darkens to gray-300. 150ms ease-out.
- Focus ring: 2px primary outline, offset 2px.

### `<TodayStream>`
- Props: `{ name: string, items: TodayFeedItem[], defaultExpanded: boolean, icon: LucideIcon }`.
- Sticky header: `position: sticky; top: 0; background: surface; z: 1;` — stays pinned when scrolling within a long stream. Renders `{icon} {name.toUpperCase()} · {count}` and a chevron.
- Header is clickable to toggle collapse (state in Zustand session store, keyed by stream name).
- Body: `role="list"` on a `<Box>` that is a **sibling** of the framer `<AnimatePresence>`, NOT a parent (fixes WR-03 a11y). Each row renders inside `<motion.div>` but the `role="listitem"` lives on an inner `<Box>` that inherits.
- Empty state: stream returns `null` when `items.length === 0` (hide entirely).
- Collapse animation: CSS `height` transition 200ms ease. No framer for this.

### `<TodayRow>`
- Props: `{ item: TodayFeedItem }`.
- Height: exactly 40px (`height: 40, minHeight: 40` — both required to defeat MUI's flex defaults).
- Padding: `py: 1, px: 2` (8px vertical, 16px horizontal).
- Layout: `<Stack direction="row" alignItems="center" spacing={2}>` with:
  1. Type icon 16px (lucide, color from `typeColor(item.type)` helper).
  2. Title link: `<Link component="a" href={item.routeUrl} underline="none" sx={{ fontSize: 14, fontWeight: 500, color: 'text.primary', flex: 1, overflow: 'hidden', textOverflow: 'ellipsis', whiteSpace: 'nowrap' }}>`
  3. Meta: `<Typography variant="caption" color="text.secondary" sx={{ fontVariantNumeric: 'tabular-nums' }}>` — tabular numerics so "2h" and "14:00" align vertically across rows.
  4. `<TodayActions>` — 3-button group.
- Hover: `bg: 'action.hover'` (maps to gray-50 in theme).
- Focus (keyboard): 2px primary `border-left` + `bg: 'action.hover'`.
- Active mutation state: opacity 0.5, spinner replaces leading icon.

### `<TodayActions>`
- Props: `{ item: TodayFeedItem, onComplete, onSnooze, onDismiss }`.
- 3 `<IconButton>` 24px size, 16px lucide icon, idle opacity 0.5, parent-row hover brings to 1.0.
- Order always: ✓ · ⏰ · ✕.
- Snooze button omitted (not rendered at all) when `item.canSnooze === false`.
- Each button: `stopPropagation` on click so row navigation doesn't fire.
- Tooltip on each via MUI `<Tooltip>` with 800ms enterDelay.
- ARIA: each `IconButton` has `aria-label` from translations.

### `<SnoozeMenu>` (adapted from existing)
- Anchored MUI `<Menu>` with 4 items + custom picker:
  - Between 15 min / 1 hour / Tonight 6pm
  - Tomorrow 9am / Next week (Monday 9am)
  - "Custom..." opens date-time picker dialog
- Item style: 14px/400, 32px height, hover bg `action.hover`.
- Menu elevation: shadow-lg (floating).

### `<TodayEmptyState>` (redesigned)
- Rendered only when ALL streams are empty (true inbox-zero).
- Single card: `<Box maxWidth={480} mx="auto" py={6} textAlign="center">`:
  - 32px ✨ emoji (the ONE decorative emoji allowed).
  - H2 "Inbox zero." / "Inbox vuota."
  - Body "Take the afternoon off." / "Goditi il pomeriggio."
- No illustration. No CTA. Minimal by design.

## Design tokens

### Type scale
| Token | Size | Weight | Line-height | Color |
|---|---|---|---|---|
| `display.h1` | 24px | 600 | 1.2 | `text.primary` |
| `display.h2` | 14px | 400 | 1.5 | `text.secondary` |
| `stream.header` | 11px | 700 | 1.2 | `text.secondary` (uppercase, 0.05em ls) |
| `row.title` | 14px | 500 | 1.4 | `text.primary` |
| `row.meta` | 12px | 400 | 1.4 | `text.secondary` |
| `kpi.count` | 14px | 600 | 1.2 | `text.primary` |

### Spacing scale (MUI spacing units: `theme.spacing(x)` = x*8px)
| Use | Token |
|---|---|
| Within row (icon ↔ title) | `spacing(2)` = 16px |
| Between KPI chips | `spacing(1)` = 8px |
| Row vertical padding | `spacing(1)` = 8px |
| Stream vertical gap | `spacing(3)` = 24px |
| Page padding | `spacing(3)` = 24px |
| Section separation | `spacing(6)` = 48px |

No arbitrary px. No `gap: 13px`.

### Color (MUI theme tokens)
| Purpose | Token | Rationale |
|---|---|---|
| Canvas | `background.default` (gray-50) | Flat page background |
| Surface | `background.paper` (white) | Stream + chip surfaces |
| Row hover | `action.hover` | Subtle interactivity cue |
| Divider | `divider` (gray-100) | 1px row separator |
| Primary text | `text.primary` (gray-900) | Titles + counts |
| Secondary text | `text.secondary` (gray-500) | Meta + stream labels |
| Accent | `primary.main` (teal-600) | Focus rings + deal € + KPI hover |
| Overdue badge | `error.main` (red-500) | "OVERDUE" text only, NOT row bg |
| Success toast | `success.main` (green-600) | ✓ completion only |

No row backgrounds tinted for urgency. The "URGENT" signal comes from stream position, not red fill.

### Dark mode
Same tokens, dark palette. The `<Chip>` stays visible (don't rely on white bg). Icons inherit `currentColor`.

## Interaction spec

### Click targets
| Target | Effect | Cmd+click |
|---|---|---|
| Row title link | `routeUrl` navigation | New tab native |
| Row body (anywhere non-action, non-title) | Same as title click (triggers `<a>` click via ref) | No (not a native link; acceptable compromise) |
| Action button | Action + `stopPropagation` | Same as click |
| Stream header | Toggle collapse (persisted in session store) | n/a |
| KPI chip | `href` navigation | New tab native |
| Greeting | Inert | n/a |

### Keyboard
| Shortcut | Effect |
|---|---|
| `Tab` / `Shift+Tab` | Focus cycles: KPI chips → stream headers → row titles → action groups |
| `Enter` on row title | Navigate |
| `Enter` on action button | Trigger action |
| `j` | Focus next row (skips headers) |
| `k` | Focus previous row |
| `Esc` | Close snooze menu; otherwise blur |
| Focus ring | 2px `primary.main` outline, 2px offset |

Shortcuts beyond j/k/Enter are **deferred to 145.2**.

### Animation
| Event | Effect | Duration / easing |
|---|---|---|
| Row removal (complete, dismiss, snooze) | Fade + slide-up | 150ms + 200ms ease-out |
| Stream expand/collapse | CSS height transition | 200ms ease |
| Toast enter/exit | Slide-up + fade | 250ms |
| KPI count change | Scale tween 1.0 → 1.05 → 1.0 | 300ms |
| Action button hover (opacity 0.5 → 1.0) | Opacity transition | 120ms ease-out |
| Chevron rotation on collapse | 90° rotate | 150ms ease-out |

No scroll-tied effects. No parallax. No confetti.

### States matrix

| Data state | Per-stream visual |
|---|---|
| Loading | 3 skeleton rows per stream; header shows count as `—` |
| Error | Full-page MUI `<Alert severity="error">` above streams |
| Empty stream | Stream hidden entirely |
| Empty all | `<TodayEmptyState>` renders instead of streams |
| Populated | Rows with AnimatePresence |

| Mutation state (per row) | Visual |
|---|---|
| Idle | Row as spec'd |
| Pending (optimistic) | opacity 0.5 + spinner replaces leading icon |
| Success | Row animates out; toast with Undo |
| Failure | Row reverts; toast with Retry |

### Toast contracts (via `useGlobalToast`)
- Complete: `t.dashboard.today.toast.completed` + Undo action
- Snooze: `t.dashboard.today.toast.snoozed(until)` + Unsnooze action
- Dismiss: `t.dashboard.today.toast.dismissed` + Undo action (6s)
- Mutation failure: `t.dashboard.today.toast.failed` + Retry action

All toasts auto-dismiss at 4s except Dismiss (6s — longer window for the common undo).

## Accessibility checklist

- [ ] WCAG AA contrast on all text ≥ 4.5:1 (verified via refactoring-ui rule — gray-700 on white is 10.5:1).
- [ ] All interactive elements keyboard-reachable in source order.
- [ ] `role="list"` / `role="listitem"` preserved despite framer-motion wrappers (structural fix).
- [ ] All icon buttons have `aria-label` tied to translations.
- [ ] Stream collapse state announced to screen readers via `aria-expanded`.
- [ ] Focus visible ring on all interactive elements, 2px primary, 2px offset.
- [ ] No color-only signaling — "OVERDUE" also uses bold + uppercase.
- [ ] Skip-to-content link on page (accessibility-a11y skill rule).
- [ ] Reduced-motion: when `prefers-reduced-motion: reduce`, animations collapse to instant transitions.

## Design tokens NOT in this spec

Anything not mentioned here is inherited from the existing PMSync MUI theme. This spec
is a **contract**, not a total design system — defer to the theme for: border-radius
values, button variants outside the action trio, modal design, layout outside the
dashboard column.
