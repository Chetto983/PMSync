# Phase 145.1 — Today Dashboard v2 (CONTEXT)

## Why this phase exists

Phase 145 shipped the backend (`GET /dashboard/today`) and deleted 27 legacy widget
files. The frontend surface was reviewed by the user and rejected as UI/UX-poor.
Phase 145.1 re-specs the dashboard UI from scratch. Backend gets a contract extension
(new stream taxonomy + KPI counts), not a rewrite. The `/dashboard` page swap from
145-03 stays.

Full reasoning and research in `docs/plans/2026-04-17-today-dashboard-v2-design.md`.

## Locked decisions (from brainstorming session)

### D-01 Architecture — Smart Streams
Single centered column, max-width 880px, with named batched streams. One stream per
action-context. Sticky stream headers show counts. Top of page is a greeting + KPI
chip strip.

**Rejected:** Multi-pane command center (too dense); split feed + context-rail hybrid
(split attention).

### D-02 Stream taxonomy — action-driven, 4 streams
1. **REPLIES NEEDED** — default expanded
2. **DUE TODAY** — default expanded
3. **WAITING ON OTHERS** — default collapsed
4. **FYI** — default collapsed, capped at 25 items

Membership is deterministic (no LLM) with strict precedence: 1 > 2 > 3 > 4. Each item
lives in exactly one stream. Empty streams are hidden entirely.

**Rejected:** Source-driven (Inbox/Calendar/Deals/Tasks) and time-driven (Right Now /
Later).

### D-03 Row anatomy — compact 40px, always-visible actions
- Type icon 16px + title (`<a href>`) + meta (right-aligned) + 3 action buttons.
- Row height exactly 40px. About 12 rows visible per stream.
- Actions always visible at opacity 0.5, row-hover brings to 1.0.
- Title is a real anchor tag — Cmd/Ctrl/middle-click opens in new tab natively.

**Rejected:** 64px comfortable rows; 88px Notion cards.

### D-04 Top composition — greeting + KPI chip strip
- H1 greeting (24px/600/gray-900) + H2 date (14px/400/gray-500).
- 4 clickable KPI chips: `[✉ 47] [📅 6] [💰 12 · €420k] [✅ 9]`.
- Each chip links to full section view.

**Rejected:** Minimal greeting only; AI briefing card + chip strip (deferred to 145.2).

### D-05 Visual system — grayscale-first
- 5 type roles only.
- Spacing scale `4/8/16/24/48`. No arbitrary px.
- 3 elevation levels: none, shadow-sm on KPI hover, shadow-lg on popover.
- Color is garnish: focus rings, "€420k" formatting, KPI hover, "OVERDUE" badge,
  success toast.
- Dashboard must read identically in monochrome.

### D-06 Interactions
- Click model: row title is the link; row body click triggers same navigation; action
  buttons `stopPropagation`.
- Quick actions:
  - ✓ Complete — real undo via inverse mutation
  - ⏰ Snooze — popover with 1h / Tonight / Tomorrow / Next week / custom; hidden
    (not greyed) when `canSnooze=false`
  - ✕ Dismiss — session-only (Zustand) with 6s undo
- Keyboard (v1): Tab / Shift+Tab, Enter, j/k. Defer e/s/# chords to 145.2.
- Animation budget: 150ms row removal, 200ms stream collapse, 250ms toast, 300ms
  KPI tween. No parallax, no scroll effects.
- TanStack: `staleTime: 5min`, `gcTime: 30min`, `retry: 1`, refetch on focus.

### D-07 Backend contract delta
DTO changes:
- Rename `tier` → `stream` with 4 values.
- Add `routeUrl: string` per item (backend computes).
- Add `rationale?: string` per item (deterministic string, LLM polish deferred).
- Extend `counts` with `kpi` block: `inbox`, `calendar`, `deals`, `tasks`.

Service changes:
- `TodayScorerService` — replace 3-tier logic with 4-stream precedence chain.
  Remove dead `isHardDeadline` branch (fixes WR-01). Fix `isToday` to use
  request tz (fixes WR-02).
- `DashboardTodayService` — compute `routeUrl` per item type; derive KPI counts
  from existing aggregator outputs (no new queries).

New endpoint:
- `PATCH /tasks/{id}/snooze` — so tasks can be snoozed (mirrors
  `PATCH /ai/follow-ups/{id}/snooze`).

No schema changes. No new Prisma queries.

### D-08 Out of scope
- LLM-polished rationale strings → 145.2 if wanted.
- Server-persisted dismiss → deliberate session-only choice stays.
- Keyboard shortcuts beyond Tab/Enter/j/k → 145.2.
- Mobile-specific layout refinements.
- Weather widget.
