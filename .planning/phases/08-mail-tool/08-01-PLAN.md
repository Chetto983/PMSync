<objective>
Add AI triage fields (aiPriority, aiSentiment, aiLabels) to all VoltAgent email listing/content tool Prisma select statements, and add a database index on (tenantId, aiPriority) for future filter performance.

Purpose: The system writes triage data via EmailTriageService and EmailInsightsService, but every tool that returns emails to the LLM omits these fields. The agent literally cannot see the data it computed. This plan makes triage data visible in all tool outputs.

Output: All 5 email listing/content tools return triage fields. get_email_content additionally returns the followUp relation (1:1, max 5 emails). schema.prisma has the new index.
</objective>
