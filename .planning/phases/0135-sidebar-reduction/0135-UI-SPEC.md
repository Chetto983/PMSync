## Spacing Scale

Declared values (from existing `frontend/theme/tokens.ts` spacing scale):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Gap between icon and tooltip arrow |
| sm | 8px | Vertical gap between icon rail items |
| md | 16px | Rail internal padding (top/bottom) |
| lg | 24px | Not used this phase |
| xl | 32px | Not used this phase |
| 2xl | 48px | Not used this phase |
| 3xl | 64px | Icon rail width (desktop); header height |

Exceptions:
- Icon touch target: 44px (11 * 4). Matches existing `height: 44` in current sidebar items.

- Logo icon: 32px (8 * 4). Per D-14.

| Items | 5 pillar icons stacked vertically, 8px gap between items |
| Item size | 44x44px touch target, centered horizontally in 64px rail |

## Responsive Breakpoints

| Breakpoint | Behavior |
|------------|----------|
| `>= md` (768px) | Desktop: permanent 64px icon rail on left, no bottom bar |
| `< md` (below 768px) | Mobile: no sidebar, bottom tab bar visible, content has bottom padding |

## Accessibility

| Concern | Solution |
|---------|----------|
| Icon-only navigation | Tooltip on hover/focus provides text label; `aria-label` on each link |
| DnD reorder | `aria-label` with `t.nav.dragToReorder + itemLabel` on draggable items |
| Bottom tab bar | MUI BottomNavigation provides `role="navigation"` by default |
| Active route | `aria-current="page"` on the active icon link |
| Keyboard nav | Tab through rail items; Enter/Space activates; arrow keys for DnD (via @dnd-kit KeyboardSensor) |
| Color contrast | Active gradient + glow is decorative; icon color change (secondary -> primary) meets 3:1 minimum for non-text |
