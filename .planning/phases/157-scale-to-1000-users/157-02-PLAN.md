<objective>
SCALE-02: Bound `AttachmentMetricsService.tenantCounters` — currently an unbounded `Map<string, Map<AttachmentOperation, number>>` — using `lru-cache@^11` with `max=10_000` and `ttl=24h`. Add the Jest spec the file has been missing since creation.

Purpose: Prevents unbounded in-process memory growth when the system sees many distinct tenants over its lifetime. At 10k tenants × ~600 B per inner-map (9 `AttachmentOperation` variants), the bounded cache uses at most ~6 MB — trivial. Without the bound, a tenant churn pattern (e.g., trial signups) can inflate the service's footprint linearly.

**Why this comes after Plan 01 in Wave 2 (not parallel with 01):** No file conflicts with Plan 01, so could theoretically run in Wave 1. Parked in Wave 2 because (a) waiting for 01 to ship first lets the `npm install` happen on a cleaner deps graph (smaller package-lock diff), and (b) Plan 03 (Artillery rig) can run truly parallel with this one — both touch independent file sets. Plan 01 is the only hard blocker on Wave 2.

**LRUCache API (v11) — from `lru-cache` README:**
- `new LRUCache<K, V>({ max, ttl, updateAgeOnGet, updateAgeOnHas })` — constructor
- `.get(key)` — returns V | undefined, gated by TTL on access
- `.set(key, value)` — returns `this`
- `.has(key)` — returns boolean, also TTL-gated
- `.clear()` — empties the cache
- `.size` — getter, current entry count
- `.delete(key)` — returns boolean
- **Pitfall (RESEARCH.md Pitfall 6):** TTL is access-gated, NOT time-gated. Expired entries stay in memory until accessed, unless `ttlAutopurge: true` is set (which adds a `setInterval`). This plan does NOT set `ttlAutopurge` — relying on `max` as the primary bound, with TTL as hygiene.

/**

import { AttachmentMetricsService } from '../attachment-metrics.service';

describe('AttachmentMetricsService', () => {
  let service: AttachmentMetricsService;
  const tenantId = 'test-tenant-metrics-001';

  beforeEach(() => {
    service = new AttachmentMetricsService();
  });

  describe('tenantCounters LRU bound (SCALE-02)', () => {
    it('does not exceed max=10000 tenants even when 11000 are inserted', () => {
      for (let i = 0; i < 11_000; i++) {
        service.recordOperation('upload', { tenantId: `tenant-${i}` });
      }
      // Access the private LRUCache to assert size
      const lru = (service as any).tenantCounters;
      expect(lru.size).toBeLessThanOrEqual(10_000);
    });

    it('evicts oldest tenants first when capacity is exceeded', () => {
      // Fill exactly to capacity
      for (let i = 0; i < 10_000; i++) {
        service.recordOperation('upload', { tenantId: `tenant-${i}` });
      }
      // Insert one more — LRU must evict the oldest (tenant-0)
      service.recordOperation('upload', { tenantId: 'tenant-overflow' });
      // tenant-0 metrics should now fall back to global (0) because its tenant entry is evicted
      // Note: getMetrics with tenantId returns 0 when tenant not in map — falls through getCount's `return this.counters.get(op) || 0`
      //       which returns the GLOBAL counter, not 0. So we assert via private state instead.
      const lru = (service as any).tenantCounters;
      expect(lru.has('tenant-0')).toBe(false);
      expect(lru.has('tenant-overflow')).toBe(true);
    });

    it('expires entries after 24h TTL on access', () => {
      jest.useFakeTimers();
      try {
        service.recordOperation('upload', { tenantId });
        // Immediately: tenant entry exists
        const lru = (service as any).tenantCounters;
        expect(lru.has(tenantId)).toBe(true);

        // Advance past TTL (24h + 1 ms)
        jest.advanceTimersByTime(1000 * 60 * 60 * 24 + 1);

        // lru-cache v11 TTL is access-gated — .has() triggers expiry check
        expect(lru.has(tenantId)).toBe(false);
      } finally {
        jest.useRealTimers();
      }
    });
  });

  describe('recordOperation', () => {
    it('increments the global counter', () => {
      service.recordOperation('upload', { tenantId });
      expect(service.getMetrics().totalUploads).toBe(1);
    });

    it('increments each tenant counter independently', () => {
      service.recordOperation('upload', { tenantId: 'tenant-a' });
      service.recordOperation('upload', { tenantId: 'tenant-a' });
      service.recordOperation('upload', { tenantId: 'tenant-b' });

      expect(service.getMetrics('tenant-a').totalUploads).toBe(2);
      expect(service.getMetrics('tenant-b').totalUploads).toBe(1);
      expect(service.getMetrics().totalUploads).toBe(3); // global is sum
    });
  });

  describe('resetMetrics', () => {
    it('zeroes global counters and clears all tenant counters', () => {
      service.recordOperation('upload', { tenantId: 'tenant-a' });
      service.recordOperation('upload', { tenantId: 'tenant-b' });
      service.recordOperation('download', { tenantId: 'tenant-a' });

      service.resetMetrics();

      expect(service.getMetrics().totalUploads).toBe(0);
      expect(service.getMetrics().totalDownloads).toBe(0);
      const lru = (service as any).tenantCounters;
      expect(lru.size).toBe(0);
    });
  });
});
