## Spacing Scale

Declared values from existing project tokens (`frontend/theme/tokens.ts`). This phase uses the following subset:

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| 1 | 4px | Icon-to-text gaps inside feed items |
| 2 | 8px | Compact padding inside feed item rows, inline chip margins |
| 3 | 12px | Feed item internal padding (left/right) |
| 4 | 16px | Section header padding, container side padding (xs) |
| 6 | 24px | Gap between urgency tier sections, container side padding (sm+) |
| 8 | 32px | Container top/bottom padding |
| 12 | 48px | Feed item row height (D-06: ~48px) |

Exceptions: Feed item rows are 48px total height (not a spacing token; this is the row `minHeight`).

## Typography

Uses existing MUI typography variants from `frontend/theme/typography.ts`. This phase declares 4 roles:

| Role | MUI Variant | Size | Weight | Line Height | Usage |
|------|-------------|------|--------|-------------|-------|
| Greeting heading | h5 | 18px (`lg`) | 600 (semibold) | 1.5 (`normal`) | Optional greeting line at top of feed |
| Tier section header | overline | 12px (`xs`) | 600 (semibold) | 1.5 (`normal`) | "URGENT", "TODAY", "FYI" tier labels, uppercase, letter-spacing 0.08em |
| Feed item title | body2 | 13px (`sm`) | 500 (medium) | 1.625 (`relaxed`) | Primary text of each feed item (email subject, task title, deal name, event title) |
| Feed item subtitle | caption | 12px (`xs`) | 400 (normal) | 1.5 (`normal`) | Secondary metadata line (contact name, time, context) |

Summary count badges inside the greeting use `subtitle2` (14px, weight 500).

## Component Inventory

### Page-Level

| Component | MUI Base | Notes |
|-----------|----------|-------|
| `TodayDashboard` | `Box` | Replaces `DashboardContainer`. Uses `PageContainer` wrapper. |
| Greeting section | `Box` + `Typography` | Optional 2-3 line AI summary with urgency count chips. Conditionally rendered. |
| Filter toggles bar | `ToggleButtonGroup` | Optional. Horizontal row of type filters: All, Emails, Tasks, Deals, Events. |

### Feed-Level

| Component | MUI Base | Notes |
|-----------|----------|-------|
| `TodayFeedList` | `List` | Renders all urgency tiers sequentially. No virtualization needed (max ~30 items). |
| Tier section header | `Box` + `Typography` (overline) | "URGENT (3)" / "TODAY (5)" / "FYI (2)". Sticky if feed is long. |
| `TodayFeedItem` | `ListItem` | 48px row. Structure: `[TypeIcon] [Title + Subtitle] [TimeBadge] [QuickActions]`. |

### Feed Item Anatomy (48px row)

```
+------+-----------------------------------------------+---------+----------+
| Icon | Title (body2, single-line, ellipsis)          | Time    | Actions  |
| 20px | Subtitle (caption, single-line, ellipsis)     | badge   | on hover |
+------+-----------------------------------------------+---------+----------+
  40px               flex: 1                             auto       auto
```

- **Icon column**: 40px wide. Centered 20px lucide icon in 32px circle with 12% entity-color background.
- **Text column**: `flex: 1`, `overflow: hidden`. Title truncates with ellipsis. Subtitle truncates with ellipsis.
- **Time badge**: `Chip` size="small", variant="outlined". Shows relative time ("2h ago", "in 30m"). Overdue items use `color="error"`.
- **Quick actions column**: Visible on hover (`opacity: 0` -> `opacity: 1` on row hover, `transition: opacity 150ms`). Contains:
  - Complete button (`Check` icon, 28px `IconButton`) -- tasks only, conditionally rendered
  - Dismiss button (`X` icon, 28px `IconButton`) -- all items
  - Snooze button (`Clock` icon, 28px `IconButton`) -- all items, opens `Menu` with snooze options

## Interaction Contract

### Click-through Navigation (D-08)

| Item Type | Destination Route |
|-----------|-------------------|
| Email | `/dashboard/email/thread/[threadId]` |
| Task | `/dashboard/tasks` (with task ID in query param if applicable) |
| Deal | `/dashboard/crm/deals/[dealId]` |
| Calendar event | `/dashboard/calendar` |

Click target: entire row is clickable (`cursor: pointer`, `hover: action.hover`).

### Quick Actions (D-09)

| Action | Trigger | Behavior |
|--------|---------|----------|
| Complete | Click checkmark icon | Optimistic removal with 200ms slide-out animation. Toast: "Task completed -- Undo" |
| Dismiss | Click X icon | Optimistic removal with 200ms slide-out animation. Toast: "Dismissed -- Undo" |
| Snooze | Click clock icon -> select duration | Optimistic removal with 200ms slide-out animation. Toast: "Snoozed until [time] -- Undo" |
| Undo | Click "Undo" in toast | Re-inserts item at original position. Reverses optimistic update. |

### Animations (D-10)

| Animation | Duration | Easing | Details |
|-----------|----------|--------|---------|
| Item dismiss/complete | 200ms | `cubic-bezier(0.4, 0, 0.2, 1)` | Slide left + fade out. Height collapses after opacity reaches 0. |
| Item re-insert (undo) | 200ms | `cubic-bezier(0, 0, 0.2, 1)` (ease-out) | Slide in from left + fade in. Height expands first. |
| Quick action buttons | 150ms | `cubic-bezier(0.4, 0, 0.2, 1)` | Opacity 0 -> 1 on row hover |
| Toast | MUI Snackbar default | default | Auto-dismiss after 5000ms. "Undo" action link in `primary.main` color. |

### Keyboard Interaction

No custom keyboard shortcuts for this phase. Standard tab navigation through feed items and quick action buttons.

### Filter Toggles (Claude's Discretion -- recommended)

If implemented:
- `ToggleButtonGroup` with exclusive=false (multi-select)
- Options: All | Emails | Tasks | Deals | Events
- Default: All selected
- State: local (no persistence needed)
- Filters client-side from the already-fetched feed data

## Responsive Behavior

| Breakpoint | Layout |
|------------|--------|
| xs (0-639px) | Single column. Feed items full-width. Quick actions always visible (no hover). Filter toggles scroll horizontally. Greeting hidden. |
| sm (640-1023px) | Single column. Feed items full-width. Quick actions on hover. Greeting shown. |
| md+ (1024px+) | Single column, max-width 720px centered. Feed items full-width. Quick actions on hover. Greeting shown. |

The Today feed is intentionally a single-column layout at all breakpoints -- not a grid. Max content width 720px keeps the feed scannable and focused. This aligns with the Superhuman "Important" view pattern (D-05).

## State Management

| State | Location | Details |
|-------|----------|---------|
| Feed data | TanStack Query (`useTodayFeed`) | `staleTime: 5min`, `gcTime: 30min`, `retry: 1` |

| Filter selection | `useState` (local) | No persistence needed. Resets to "All" on navigation. |
