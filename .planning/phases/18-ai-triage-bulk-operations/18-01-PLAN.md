**1. Create `backend/src/modules/ai/services/triage-suggestion.service.ts`** (~120 lines):

Injectable NestJS service with constructor DI for `PrismaService` and `LabelsService`.

Method `resolveAiLabelsToUserLabels(tenantId: string, aiLabels: string[]): Promise<Map<string, string>>`:
- For each aiLabel string:
  - Generate slug: `aiLabel.toLowerCase().trim().replace(/[^a-z0-9]+/g, '-')`
  - Find existing UserLabel: `prisma.userLabel.findFirst({ where: { tenantId, slug, isArchived: false } })`
  - If found, map aiLabel -> label.id
  - If not found, call `getOrCreateTriageParent(tenantId)` then `labelsService.create(tenantId, { name: capitalize(aiLabel), parentId: parent.id })`
  - Map aiLabel -> newLabel.id

Private method `getOrCreateTriageParent(tenantId: string): Promise<{ id: string }>`:
- Find existing: `prisma.userLabel.findFirst({ where: { tenantId, slug: 'ai-triage', isArchived: false, parentId: null } })`
- If not found: `labelsService.create(tenantId, { name: 'AI Triage' })` (no parentId = root level)
- Cache parent ID in a Map<string, string> instance variable to avoid repeated lookups within same request

**2. Create `backend/src/modules/ai/voltagent/services/executors/bulk-label-executor.ts`** (~180 lines):

Follow the exact same pattern as `bulk-email-executor.ts` (static methods, deps interface).

Interface `BulkLabelExecutorDeps`:
- `labelsService: LabelsService` (from labels module)
- `triageSuggestionService: TriageSuggestionService`
- `followUpCrudService: FollowUpCrudService`
- `prisma: PrismaService`
- `logger: Logger`

Static method `executeBulkApplyLabels(action, context, deps)`:
- Extract `{ emailIds, labelNames, labelIds }` from action.payload
- If labelNames provided (AI label strings): call `deps.triageSuggestionService.resolveAiLabelsToUserLabels(context.tenantId, labelNames)` to get labelId map
- If labelIds provided directly: use them as-is
- For each resolved labelId, call `deps.labelsService.addEmailsToLabel(context.tenantId, labelId, { emailIds })` inside a try-catch (skip failures per label)
- Return `ActionExecutionResult` with success, count of labels applied, summary

Static method `executeBulkCreateFollowUps(action, context, deps)`:
- Extract `{ emailIds, reason, dueDays }` from action.payload
- Calculate dueDate as `new Date(Date.now() + (dueDays || 3) * 86400000)`
- For each emailId, call `deps.followUpCrudService.createFollowUp(context.tenantId, emailId, { reason: reason || 'AI bulk follow-up', dueDate, followUpType: 'TODO' })` inside try-catch (skip if follow-up already exists - the service already handles dedup)
- Count successes and skipped
- Return `ActionExecutionResult` with success, created count, skipped count, summary
