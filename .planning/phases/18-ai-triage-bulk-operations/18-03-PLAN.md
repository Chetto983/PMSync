**2. Create `TriageRenderer.tsx`** (~200 lines, uses Tailwind as per ai-elements convention):

Read `EmailSearchRenderer.tsx` and `FollowUpRenderer.tsx` for patterns. This component follows the same structure:

```tsx
import { useMemo } from 'react';
import { useTranslations } from '@/lib/hooks/use-translations';
import type { ToolRendererProps, BulkActionResult } from '../types';
import { RawJsonToggle } from '../shared/RawJsonToggle';
import { EmptyState } from '../shared/EmptyState';
import { ActionBar } from '../shared/ActionBar';
// Icons from lucide-react
import { Tag, Clock, CheckCircle, AlertTriangle, Zap, XCircle } from 'lucide-react';
```

Component structure:
1. Parse `output` as `BulkActionResult` (same defensive pattern as other renderers)
2. If `error`, show error state (red AlertTriangle + error text)
3. If `requiresApproval` is true, show pending approval card:
   - Title: "AI Triage Action - Awaiting Approval" (use triage translations from Plan 02)
   - Show action type badge (BULK_APPLY_LABELS / BULK_CREATE_FOLLOW_UPS)
   - Show summary text
   - Show payload details: count of emails, label names, due days etc.
   - Action buttons via ActionBar:
     - If actionType includes 'LABELS': "Apply Labels" button (Tag icon) -> `onAction({ type: 'send-message', message: 'Approve and apply the label suggestions' })`
     - If actionType includes 'FOLLOW': "Create Follow-ups" button (Clock icon) -> `onAction({ type: 'send-message', message: 'Approve and create the follow-ups' })`
     - "Dismiss" button (XCircle icon) -> `onAction({ type: 'send-message', message: 'Dismiss the triage suggestion' })`
4. If NOT `requiresApproval` (already executed), show completed card:
   - Green CheckCircle icon + summary text
   - Show count, labels applied, follow-ups created etc.
5. RawJsonToggle at the bottom for debugging

Use Tailwind classes (NOT MUI) following ai-elements convention:
- Container: `rounded-lg border border-border/50 bg-card/50 p-3`
- Badge for action type: `inline-flex items-center rounded-full px-2 py-0.5 text-xs font-medium`
- Use semantic colors: `text-blue-600 dark:text-blue-400` for labels, `text-amber-600 dark:text-amber-400` for follow-ups
- Section headers: `text-sm font-medium text-foreground`
- Details text: `text-xs text-muted-foreground`

Action type detection logic:
```tsx
const isLabelAction = parsed.actionType === 'BULK_APPLY_LABELS';
const isFollowUpAction = parsed.actionType === 'BULK_CREATE_FOLLOW_UPS';
const isGenericBulk = !isLabelAction && !isFollowUpAction;
```

For `isGenericBulk` (delete, archive, mark_read), fall through to displaying just the summary and count - no special rendering needed since those already work via FallbackRenderer. But having them here is fine for consistency.
