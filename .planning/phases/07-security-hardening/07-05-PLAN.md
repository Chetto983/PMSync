## Objective

Integrate CSRF protection into the frontend API client by automatically fetching and sending CSRF tokens on state-changing requests (SEC-04).

## Context

**Dependency:** Requires backend CSRF infrastructure from 07-04 (middleware, endpoint, CORS).

**Frontend Flow:**
1. On first mutation request, fetch token from `GET /api/v1/auth/csrf-token`
2. Cache token in memory (NOT localStorage - XSS risk)
3. Send token in `X-CSRF-Token` header on POST/PUT/DELETE/PATCH
4. Clear token on 403 response (might be expired/invalid)

**Key Decisions:**
- Token stored in module-level variable, not React state or localStorage
- Concurrent token fetch prevention with promise caching
- Auto-clear on 403 to trigger re-fetch on next request

### Task 1: Add CSRF Token Logic to Frontend API Client

**Files:** `frontend/lib/api-client.ts`

**Action:**

1. Add CSRF token cache at module level (after imports, around line 3):

```typescript
// CSRF token cache (SEC-04)
// Stored in memory, not localStorage, to prevent XSS token theft
let csrfToken: string | null = null;
let csrfTokenPromise: Promise<string> | null = null;

/**
 * Fetch CSRF token from backend (cached)
 */
async function getCsrfToken(): Promise<string> {
  if (csrfToken) {
    return csrfToken;
  }

  // Prevent concurrent token fetches
  if (csrfTokenPromise) {
    return csrfTokenPromise;
  }

  csrfTokenPromise = apiClient
    .get('/api/v1/auth/csrf-token')
    .then((res) => {
      csrfToken = res.data.csrfToken;
      csrfTokenPromise = null;
      return csrfToken!;
    })
    .catch((err) => {
      csrfTokenPromise = null;
      console.warn('Failed to fetch CSRF token:', err);
      return '';
    });

  return csrfTokenPromise;
}

/**
 * Clear cached CSRF token (call on logout or 403)
 */
export function clearCsrfToken(): void {
  csrfToken = null;
}
```

2. Modify the request interceptor (around line 63) to add CSRF header for mutations:

```typescript
// Add token and CSRF header to requests
apiClient.interceptors.request.use(async (config) => {
  if (typeof window !== 'undefined') {
    // Auth token from Zustand
    const stored = localStorage.getItem('auth-storage');
    if (stored) {
      try {
        const parsed = JSON.parse(stored);
        const token = parsed?.state?.token;
        if (token) {
          config.headers.Authorization = `Bearer ${token}`;
        }
      } catch {
        // Invalid JSON, skip
      }
    }

    // CSRF token for mutations (SEC-04)
    const method = config.method?.toUpperCase();
    if (method && ['POST', 'PUT', 'DELETE', 'PATCH'].includes(method)) {
      const csrf = await getCsrfToken();
      if (csrf) {
        config.headers['X-CSRF-Token'] = csrf;
      }
    }
  }
  return config;
});
```

3. Add CSRF token clear on 403 in response interceptor (around line 84):

```typescript
// Handle token expiration and CSRF errors
apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      if (typeof window !== 'undefined') {
        useAuthStore.getState().logout();
      }
    }
    // Clear CSRF token on 403 (might be expired/invalid)
    if (error.response?.status === 403) {
      clearCsrfToken();
    }
    return Promise.reject(error);
  },
);
```
