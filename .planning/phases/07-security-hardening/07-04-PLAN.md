## Objective

Implement CSRF protection backend using the Double Submit Cookie pattern for all state-changing API requests (SEC-04).

## Context

**Why Double Submit Cookie:**
- `csurf` package is deprecated (security vulnerabilities)
- SPA architecture (Next.js frontend + NestJS backend) needs stateless CSRF
- Pattern: Server sets HMAC-signed cookie, frontend sends token in header, server verifies match

**Package:** `csrf-csrf` (maintained, designed for SPAs)
- Install: `npm install csrf-csrf`
- Provides `doubleCsrf()` function with Express middleware

**Flow:**
1. Frontend calls `GET /api/v1/auth/csrf-token` on page load
2. Backend generates token, sets `__Host-csrf` cookie, returns token in JSON
3. Frontend stores token in memory (NOT localStorage - XSS risk)
4. Frontend sends token in `X-CSRF-Token` header on mutations
5. Backend verifies token matches HMAC(cookie value)

**Excluded Routes:**
- Webhook endpoints (use webhook signatures instead)
- OAuth callbacks (no user session yet)
- Health checks

### Task 2: Create CSRF Middleware

**Files:** `backend/src/common/middleware/csrf.middleware.ts` (NEW)

**Action:**

Create the middleware file:

```typescript
import { doubleCsrf } from 'csrf-csrf';
import { Request, Response, NextFunction } from 'express';

const CSRF_SECRET = process.env.CSRF_SECRET || process.env.JWT_SECRET;

if (!CSRF_SECRET) {
  throw new Error('CSRF_SECRET or JWT_SECRET must be set for CSRF protection');
}

/**
 * Double Submit Cookie CSRF Protection (SEC-04)
 *
 * Uses HMAC-signed cookies for stateless CSRF validation.
 * Token is sent in X-CSRF-Token header, cookie is httpOnly.
 */
const {
  generateToken,
  doubleCsrfProtection,
  invalidCsrfTokenError,
} = doubleCsrf({
  getSecret: () => CSRF_SECRET!,
  cookieName: process.env.NODE_ENV === 'production' ? '__Host-csrf' : 'csrf',
  cookieOptions: {
    httpOnly: true,
    sameSite: 'strict',
    secure: process.env.NODE_ENV === 'production',
    path: '/',
    maxAge: 60 * 60 * 24, // 24 hours
  },
  getTokenFromRequest: (req: Request) => req.headers['x-csrf-token'] as string,
});

/**
 * Routes to exclude from CSRF protection
 */
const CSRF_EXCLUDED_PATHS = [
  '/health',
  '/health/ready',
  '/api/v1/auth/csrf-token', // Token fetch endpoint itself
  '/api/v1/webhooks',        // Webhook endpoints use signatures
  '/api/v1/providers/oauth', // OAuth callbacks
];

/**
 * Check if request should skip CSRF validation
 */
function shouldSkipCsrf(req: Request): boolean {
  // Skip safe methods
  if (['GET', 'HEAD', 'OPTIONS'].includes(req.method)) {
    return true;
  }

  // Skip excluded paths
  const path = req.path || req.url;
  return CSRF_EXCLUDED_PATHS.some(
    (excluded) => path === excluded || path.startsWith(excluded),
  );
}

/**
 * CSRF middleware that skips safe methods and excluded routes
 */
export function csrfMiddleware(req: Request, res: Response, next: NextFunction) {
  if (shouldSkipCsrf(req)) {
    return next();
  }
  return doubleCsrfProtection(req, res, next);
}

export { generateToken, invalidCsrfTokenError };
```

```typescript
/**
 * Get CSRF token for form submissions (SEC-04)
 * Frontend should call this on page load and include token in X-CSRF-Token header
 */
@Get('csrf-token')
@SkipThrottle() // Don't rate limit token fetches
getCsrfToken(@Req() req: Request, @Res() res: Response) {
  const token = generateToken(req, res);
  return res.json({ csrfToken: token });
}
```
