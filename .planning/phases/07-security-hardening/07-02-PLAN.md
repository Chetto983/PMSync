## Objective

Configure dual-tier rate limiting (100 read/30 write per minute) with Redis storage for horizontal scaling and proper 429 response formatting (SEC-05).

## Context

**Current State:**
- `@nestjs/throttler` v6.5.0 already installed and configured (app.module.ts lines 49-54)
- Single tier currently: `ttl: config.rateLimit.ttlMs, limit: config.rateLimit.limit`
- ThrottlerGuard already registered as APP_GUARD (lines 76-79)
- Controllers use `@SkipThrottle()` decorator (e.g., providers.controller.ts)

**What's needed:**
- Dual throttler tiers: `short` (100/min for reads), `write` (30/min for writes)
- Custom exception filter for 429 responses with `Retry-After` header
- Per-user rate limiting (already done via JWT extraction in ThrottlerGuard)

**Note:** Redis storage for multi-instance support is optional enhancement. The default in-memory storage works for single instance. Research suggested `@nestjs-redis/throttler-storage` but it's not required for SEC-05 acceptance criteria.

### Task 2: Create Custom Throttler Exception Filter

**Files:** `backend/src/common/filters/throttler-exception.filter.ts` (NEW)

**Action:**

Create a new exception filter for proper 429 responses:

```typescript
import {
  ExceptionFilter,
  Catch,
  ArgumentsHost,
  HttpStatus,
  Logger,
} from '@nestjs/common';
import { ThrottlerException } from '@nestjs/throttler';
import { Response } from 'express';

/**
 * Custom filter for rate limit exceeded responses (SEC-05)
 * Returns 429 with Retry-After header as per HTTP spec
 */
@Catch(ThrottlerException)
export class ThrottlerExceptionFilter implements ExceptionFilter {
  private readonly logger = new Logger(ThrottlerExceptionFilter.name);

  catch(exception: ThrottlerException, host: ArgumentsHost) {
    const ctx = host.switchToHttp();
    const response = ctx.getResponse<Response>();
    const request = ctx.getRequest();

    // Default retry after 60 seconds (1 minute TTL)
    const retryAfter = 60;

    this.logger.warn(
      `Rate limit exceeded for ${request.method} ${request.url} ` +
      `(IP: ${request.ip}, User: ${request.user?.userId || 'anonymous'})`,
    );

    response
      .status(HttpStatus.TOO_MANY_REQUESTS)
      .header('Retry-After', String(retryAfter))
      .header('X-RateLimit-Limit', '100') // Default tier
      .json({
        statusCode: 429,
        error: 'Too Many Requests',
        message: 'Rate limit exceeded. Please slow down.',
        retryAfter,
      });
  }
}
```
