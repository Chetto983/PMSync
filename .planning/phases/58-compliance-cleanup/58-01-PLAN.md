   - `/sign-out` -> `AUTH:LOGOUT`

   - `/verify-email` -> `AUTH:EMAIL_VERIFIED`

   - `/callback/google` -> `AUTH:SOCIAL_LOGIN`
   - `/callback/microsoft` -> `AUTH:SOCIAL_LOGIN`

   - Takes `(prisma: PrismaClient, path: string, userId: string | null, tenantId: string | null, request: Request | undefined, metadata?: Record<string, unknown>)`

   - If no match or tenantId is null, returns early (no audit for events without tenant context -- signup audit happens AFTER provisioning in databaseHooks)
   - Writes to `prisma.auditLog.create` wrapped in `withoutTenantScopingAsync`
   - Maps: action=eventType, entity='BetterAuth', entityId=userId ?? 'unknown', changes=metadata, ipAddress from request
   - Catches all errors silently (fire-and-forget, log nothing to avoid noise)
