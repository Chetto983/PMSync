<objective>
Refactor the HITL controller to use registry-based lookups and clean the DTO contracts for both pending actions and approval responses.

Purpose: The controller currently hardcodes tool resolution (resolveToolName, getExecutableTool, mapSeverity) and the DTO has redundant fields. This plan replaces mapSeverity and resolveToolName with registry queries, simplifies getExecutableTool, cleans the DTO to a canonical shape, and updates the frontend to consume the new contract.

Output: Clean HITL controller, canonical PendingActionDto, outcome-based ApprovalResponseDto, updated frontend types and components.
</objective>
