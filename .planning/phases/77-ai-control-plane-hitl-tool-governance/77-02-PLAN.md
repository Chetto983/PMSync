- Use this inline implementation (do NOT import from library -- no reliable named export exists):
```typescript
sendAutomaticallyWhen: ({ messages }) => {
  const last = messages[messages.length - 1];
  if (!last || last.role !== 'assistant') return false;
  // Auto-resubmit when all tool invocations have been resolved (approved/denied)
  // i.e., none remain in 'requires-action' state
  const toolParts = last.content?.filter((p: any) => p.type === 'tool-call' || p.type?.startsWith('tool-'));
  if (!toolParts?.length) return false;
  return !toolParts.some((p: any) => p.state === 'requires-action');
}
```
- This makes the runtime auto-resubmit the conversation after the user approves/denies a tool, continuing the AI conversation loop
- If the exact shape of message parts differs at runtime, adjust the predicate to match the actual assistant-ui message structure. The key logic: return true when the last assistant message has tool invocations and NONE are in requires-action state.
