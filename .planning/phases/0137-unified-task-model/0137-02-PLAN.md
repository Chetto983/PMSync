**Main method: `async listTasks(tenantId: string, userId: string, query: ListTasksQueryDto): Promise<UnifiedTaskListResponseDto>`**

Logic:
1. Parse query defaults: `page = query.page ?? 1`, `limit = query.limit ?? 50`, `statusFilter = query.status ?? ['pending', 'in_progress']`, `sortBy = query.sortBy ?? 'dueDate'`, `sortOrder = query.sortOrder ?? 'asc'`.

2. Determine which sources to query. If `query.sourceType` is set, only query those sources. Otherwise query all 5.

3. Build source queries array (only for requested sourceTypes). Use `Promise.all` for parallel execution:

   **Follow-ups query** (if 'follow_up' in sources):
   ```typescript
   this.prisma.emailFollowUp.findMany({
     where: {
       tenantId,
       userId,
       status: { in: this.mapToFollowUpStatuses(statusFilter) },
       ...(query.dueBefore ? { dueDate: { lte: new Date(query.dueBefore) } } : {}),
       ...(query.dueAfter ? { dueDate: { gte: new Date(query.dueAfter) } } : {}),
     },
     include: { email: { select: { subject: true, from: true } } },
     take: 500,
   })
   ```
   Where `mapToFollowUpStatuses` reverses the FOLLOW_UP_STATUS_MAP: unified 'pending' -> ['PENDING', 'REMINDED'], 'completed' -> ['RESOLVED'], 'expired' -> ['EXPIRED'].

   **Reminders query** (if 'reminder' in sources):
   ```typescript
   this.prisma.reminder.findMany({
     where: {
       tenantId,
       userId,
       status: { in: this.mapToReminderStatuses(statusFilter) },
       ...(query.dueBefore ? { scadenzaDatetime: { lte: new Date(query.dueBefore) } } : {}),
       ...(query.dueAfter ? { scadenzaDatetime: { gte: new Date(query.dueAfter) } } : {}),
       ...(query.contactId ? { contatto: { contains: query.contactId } } : {}),
     },
     take: 500,
   })
   ```
   Where `mapToReminderStatuses` reverses REMINDER_STATUS_MAP: 'pending' -> ['attivo', 'sospeso'], 'completed' -> ['completato'], 'dismissed' -> ['annullato'].

   **NBAActions query** (if 'deal_action' in sources):
   ```typescript
   this.prisma.nBAAction.findMany({
     where: {
       tenantId,
       status: { in: this.mapToNBAStatuses(statusFilter) },
       ...(query.contactId ? { contactId: query.contactId } : {}),
     },
     include: { contact: { select: { firstName: true, lastName: true } } },
     take: 500,
   })
   ```
   Where `mapToNBAStatuses` reverses NBA_STATUS_MAP: 'pending' -> ['SUGGESTED'], 'in_progress' -> ['ACCEPTED'], 'completed' -> ['EXECUTED'], 'dismissed' -> ['DISMISSED'].

   **Tickets query** (if 'ticket' in sources):
   ```typescript
   this.prisma.ticket.findMany({
     where: {
       tenantId,
       assigneeId: userId,
       status: { in: this.mapToTicketStatuses(statusFilter) },
       ...(query.dueBefore ? { slaDeadline: { lte: new Date(query.dueBefore) } } : {}),
       ...(query.dueAfter ? { slaDeadline: { gte: new Date(query.dueAfter) } } : {}),
       ...(query.contactId ? { contactId: query.contactId } : {}),
     },
     include: { contact: { select: { firstName: true, lastName: true } } },
     take: 500,
   })
   ```
   Where `mapToTicketStatuses` reverses TICKET_STATUS_MAP: 'pending' -> ['open', 'waiting'], 'in_progress' -> ['in_progress'], 'completed' -> ['resolved', 'closed'].

   **ManualTasks query** (if 'manual' in sources):
   Use `this.manualTaskService.findAll(tenantId, userId, { status: statusFilter, priority: query.priority, dueBefore: query.dueBefore, dueAfter: query.dueAfter, contactId: query.contactId })`.

4. After `Promise.all`, normalize each source's results using the appropriate normalizer function from `normalizers.ts`.

5. Merge all normalized arrays into one flat array.

6. Apply priority filter if `query.priority` is set: `merged.filter(t => query.priority!.includes(t.priority))`.

7. Sort the merged array:
   - If `sortBy === 'dueDate'`: nulls last, then by date
   - If `sortBy === 'createdAt'`: by createdAt
   - If `sortBy === 'priority'`: by priority weight (urgent=4, high=3, medium=2, low=1)
   - Apply `sortOrder` (asc/desc)

8. Count items per sourceType from the full merged array (before pagination): `{ follow_up: N, reminder: N, ... }`.

9. Paginate: `const start = (page - 1) * limit; const paged = sorted.slice(start, start + limit);`

10. Return `{ data: paged, meta: { total: sorted.length, page, limit, counts } }`.

**Helper methods** (private):
- `mapToFollowUpStatuses(unified: string[]): FollowUpStatus[]`
- `mapToReminderStatuses(unified: string[]): ReminderStatus[]`
- `mapToNBAStatuses(unified: string[]): string[]`
- `mapToTicketStatuses(unified: string[]): string[]`

Each reverse-maps unified statuses back to source-specific statuses.

**Complete action method: `async completeTask(tenantId: string, userId: string, sourceType: TaskSourceType, sourceId: string): Promise<void>`**

Switch on `sourceType`:
- `'follow_up'`: `this.prisma.emailFollowUp.update({ where: { id: sourceId }, data: { status: 'RESOLVED', resolvedAt: new Date(), resolvedBy: userId } })` -- verify tenantId matches first

For each source except manual, do a `findUnique` first to verify `tenantId` matches, throw `NotFoundException` if not found or wrong tenant.

**File 1: `backend/src/modules/tasks/controllers/tasks.controller.ts`**

Follow the exact pattern from `reminder.controller.ts`:

```typescript
@ApiTags('Tasks')
@ApiCookieAuth()
@UseGuards(TenantGuard, RolesGuard)
@Controller('tasks')
export class TasksController {
  constructor(
    private readonly aggregationService: TasksAggregationService,
    private readonly manualTaskService: ManualTaskService,
  ) {}
```

Endpoints:

1. `@Get() @ApiOperation({ summary: 'List unified tasks from all sources' })`
   `async list(@Req() req: AuthenticatedRequest, @Query() query: ListTasksQueryDto): Promise<UnifiedTaskListResponseDto>`
   - Calls `this.aggregationService.listTasks(req.user.tenantId, req.user.id, query)`

2. `@Post() @RateTierDecorator('safe-write') @HttpCode(201) @ApiOperation({ summary: 'Create a manual task' })`
   `async create(@Req() req: AuthenticatedRequest, @Body() dto: CreateManualTaskDto)`
   - Calls `this.manualTaskService.create(req.user.tenantId, req.user.id, dto)`
   - Returns `{ data: normalizeManualTask(result) }`

3. `@Patch(':sourceType/:id') @RateTierDecorator('safe-write') @ApiOperation({ summary: 'Update a task' })`
   `async update(@Req() req: AuthenticatedRequest, @Param('sourceType') sourceType: TaskSourceType, @Param('id') id: string, @Body() dto: UpdateManualTaskDto)`
   - If `sourceType !== 'manual'`, throw `BadRequestException('Only manual tasks can be updated via this endpoint')`
   - Calls `this.manualTaskService.update(req.user.tenantId, id, dto)`
   - Returns `{ data: normalizeManualTask(result) }`

4. `@Delete(':sourceType/:id') @RateTierDecorator('safe-write') @ApiOperation({ summary: 'Delete a task' })`
   `async remove(@Req() req: AuthenticatedRequest, @Param('sourceType') sourceType: TaskSourceType, @Param('id') id: string)`
   - If `sourceType !== 'manual'`, throw `BadRequestException('Only manual tasks can be deleted via this endpoint')`
   - Calls `this.manualTaskService.delete(req.user.tenantId, id)`
   - Returns `{ success: true }`

5. `@Post(':sourceType/:id/complete') @RateTierDecorator('safe-write') @HttpCode(200) @ApiOperation({ summary: 'Complete a task' })`
   `async complete(@Req() req: AuthenticatedRequest, @Param('sourceType') sourceType: TaskSourceType, @Param('id') id: string)`
   - Validate `sourceType` is in `TASK_SOURCE_TYPES`, throw `BadRequestException` if not
   - Calls `this.aggregationService.completeTask(req.user.tenantId, req.user.id, sourceType, id)`
   - Returns `{ success: true }`

Use the same `AuthenticatedRequest` interface pattern as reminder.controller.ts: `interface AuthenticatedRequest { user: { id: string; tenantId: string }; }`.
