    **READ endpoints (GET):** Simply REMOVE @SkipThrottle(). The global default (100 req/min) is sufficient for reads. Only add explicit @Throttle if the endpoint needs a DIFFERENT limit than the global default.

    **WRITE endpoints (POST/PUT/DELETE):** Remove @SkipThrottle(). If the endpoint is heavy (creates resources, triggers syncs), add `@Throttle({ default: { limit: 20, ttl: 60000 } })`.

    5. After all changes, run `grep -rn "SkipThrottle" backend/src/ --include="*.ts"` to confirm ZERO remaining occurrences (except possibly in test files, which is fine).

    NOTE: The global ThrottlerModule is already configured with dual-tier limits. Most READ endpoints just need @SkipThrottle removed to fall under the global default. Don't over-annotate with @Throttle unless the endpoint genuinely needs a different limit.
