## Spacing Scale

Declared values from `frontend/theme/tokens.ts` (8px base, MUI spacing factor). All values are multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| 1 | 4px | Icon gaps, inline padding |
| 2 | 8px | Compact element spacing, chip gaps, list item internal padding |
| 4 | 16px | Default element spacing, card padding (sm) |
| 6 | 24px | Section padding, card padding (md/lg) |
| 8 | 32px | Layout gaps, section spacing |
| 12 | 48px | Large section breaks |
| 16 | 64px | Header height, page-level spacing |

Exceptions: none

**Accessibility constraint:** Touch targets on calendar event cards and reminder action buttons must have a minimum height of 44px per WCAG 2.1 SC 2.5.5. This is a component sizing constraint, not a spacing token.

Phase-specific typography usage:

## Icon-Only Action Policy

All icon-only buttons must declare an `aria-label` attribute and render a MUI `Tooltip` on hover/focus. This applies to:
- Calendar navigation arrows (prev/next)
- Calendar view toggle icons (day/week/month/list)
- Contact detail action icons (edit, delete, VIP toggle)
- Reminder card action icons (complete, delete)
- Calendar event card action icons (edit, delete)

Pattern: `<Tooltip title={t.section.actionLabel}><IconButton aria-label={t.section.actionLabel}>...</IconButton></Tooltip>`

## Interaction States (Verification Checklist)

### Loading States
- Calendar: Loading skeleton or spinner while FullCalendar initializes (`calendar.loading`)
- Contacts: List skeleton while contacts fetch
- Reminders: Card skeleton while reminders fetch

### Error States
- Calendar: Error alert with retry for failed event load. Copy: "Failed to load events. Check your connection and try again."
- Contacts: Error alert for failed contact operations
- Contacts activity: Error alert with retry. Copy: "Failed to load activity history. Pull to refresh or try again later."
- Reminders: Error handling for failed reminder operations

### Empty States
- Calendar: "No events scheduled" message with create prompt
- Calendar (no provider): "No calendar providers configured" with link to Providers page
- Contacts: "No contacts found" with body copy guiding next step (import or create)
- Contacts detail: "Select a contact to view details"
- Reminders: "No reminders" with create prompt
- Contact activity: "No recent activity found" (known stub -- always empty)

### Destructive Actions
- Delete event: Confirmation dialog with event title
- Delete calendar: Confirmation dialog naming the calendar
- Delete contact: Confirmation dialog (DeleteContactDialog)
- Bulk delete contacts: Bulk action bar confirmation
- Delete reminder: Soft-delete (status -> annullato), no confirmation dialog
- Mark Complete reminder: Immediate action via "Mark Complete" button, no confirmation
