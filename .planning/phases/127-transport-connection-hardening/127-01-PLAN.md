
This is a single-line change. Do NOT modify anything else in the file. The server gateway at `realtime.gateway.ts:84` already has `transports: ['websocket']` -- this change makes the client match.

Why: Railway load balancer does not support sticky sessions. HTTP long-polling sends multiple HTTP requests during a Socket.IO session; without sticky sessions, sequential polls hit different replicas causing "Session ID unknown" (HTTP 400) errors. WebSocket uses a single persistent TCP connection, eliminating the need for sticky sessions.
