ApiExceptionFilter envelope shape (from backend/src/common/filters/api-exception.filter.ts):
```typescript
// ALL 4xx/5xx responses produced by ApiExceptionFilter have this shape:
// { error: { code: string, message: string, details: Record<string,unknown>|null }, meta: { requestId: string } }
// IMPORTANT: There is NO top-level "statusCode" field. HTTP status is in the status line only.
// For 401: code = 'UNAUTHORIZED', message = 'Invalid or expired session'
// For 403: code = 'FORBIDDEN'
```
