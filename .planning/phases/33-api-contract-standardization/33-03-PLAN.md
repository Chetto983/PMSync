
    **2. Install @stoplight/spectral-cli in backend (devDependency):**
    Run: `cd backend && npm install -D @stoplight/spectral-cli`

    **3. Add npm scripts to backend/package.json** (read first, then edit scripts section):
    ```json
    "openapi:generate": "ts-node scripts/generate-openapi.ts",
    "openapi:lint": "spectral lint ./openapi-spec.json --ruleset .spectral.yaml"
    ```

    **4. Create backend/scripts/generate-openapi.ts** -- a script that boots the NestJS app just enough to extract the OpenAPI spec and write it to disk:
    ```typescript
    import { NestFactory } from '@nestjs/core';
    import { SwaggerModule, DocumentBuilder } from '@nestjs/swagger';
    import { AppModule } from '../src/app.module';
    import { writeFileSync } from 'fs';

    async function generateSpec() {
      const app = await NestFactory.create(AppModule, { logger: false });
      const config = new DocumentBuilder()
        .setTitle('MailAgent API')
        .setDescription('AI-powered multi-tenant email assistant API')
        .setVersion('1.0')
        .addBearerAuth()
        .build();
      const document = SwaggerModule.createDocument(app, config);
      writeFileSync('openapi-spec.json', JSON.stringify(document, null, 2));
      await app.close();
      console.log('OpenAPI spec written to openapi-spec.json');
    }

    generateSpec().catch((err) => {
      console.error('Failed to generate OpenAPI spec:', err);
      process.exit(1);
    });
    ```

    NOTE: This script may fail if the app requires running database/Redis connections. If so, create a simpler approach: use `curl http://localhost:3000/api/docs-json -o openapi-spec.json` in the CI step instead (requires the app to be running). Choose whichever works -- if the NestFactory approach fails during execution, fall back to the curl approach and document the decision.
