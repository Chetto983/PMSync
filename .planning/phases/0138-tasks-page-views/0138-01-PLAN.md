**1. Create `frontend/lib/api/tasks.ts`** (~80 lines) following `crm-deals.ts` pattern exactly:

Types to define (mirror backend DTOs):
- `TaskSourceType` = `'follow_up' | 'reminder' | 'deal_action' | 'ticket' | 'manual'`
- `UnifiedTaskStatus` = `'pending' | 'in_progress' | 'completed' | 'dismissed' | 'expired'`
- `UnifiedTaskPriority` = `'low' | 'medium' | 'high' | 'urgent'`
- `UnifiedTask` interface with all fields from `UnifiedTaskDto` (id, sourceType, sourceId, title, description, status, priority, dueDate, contactName, contactId, dealId, emailId, ticketId, createdAt, updatedAt)
- `TaskCounts` = `Record<TaskSourceType, number>`
- `TaskMeta` = `{ total: number; page: number; limit: number; counts: TaskCounts }`
- `UnifiedTaskListResponse` = `{ data: UnifiedTask[]; meta: TaskMeta }`
- `ListTasksQuery` interface with: `sourceType?: TaskSourceType[]`, `status?: UnifiedTaskStatus[]`, `priority?: UnifiedTaskPriority[]`, `dueBefore?: string`, `dueAfter?: string`, `contactId?: string`, `page?: number`, `limit?: number`, `sortBy?: 'dueDate' | 'createdAt' | 'priority'`, `sortOrder?: 'asc' | 'desc'`
- `CreateManualTaskDto` = `{ title: string; description?: string; priority?: UnifiedTaskPriority; dueDate?: string; contactId?: string; dealId?: string; emailId?: string }`
- `UpdateManualTaskDto` = `Partial<CreateManualTaskDto> & { status?: UnifiedTaskStatus }`

API object `tasksApi`:
- `list(query?: ListTasksQuery)` -> `apiClient.get<UnifiedTaskListResponse>('/tasks', { params: query })`
  - For array params (`sourceType`, `status`, `priority`), pass them via `paramsSerializer` or use the default axios array serialization. The backend uses `@Transform` to handle both single and array values, so standard `params: query` should work.
- `create(dto: CreateManualTaskDto)` -> `apiClient.post<{ data: UnifiedTask }>('/tasks', dto)`
- `update(sourceType: TaskSourceType, id: string, dto: UpdateManualTaskDto)` -> `apiClient.patch<{ data: UnifiedTask }>(\`/tasks/${sourceType}/${id}\`, dto)`
- `delete(sourceType: TaskSourceType, id: string)` -> `apiClient.delete<{ success: boolean }>(\`/tasks/${sourceType}/${id}\`)`
- `complete(sourceType: TaskSourceType, id: string)` -> `apiClient.post<{ success: boolean }>(\`/tasks/${sourceType}/${id}/complete\`)`

Import `apiClient` from `'../api-client'`.

**3. Create `frontend/hooks/queries/use-tasks.ts`** (~100 lines) following `use-crm-deals.ts` pattern:

- `taskListOptions(filters?: ListTasksQuery)` using `queryOptions()` with `queryKey: tasksKeys.list(filters as Record<string, unknown>)`, `queryFn: () => tasksApi.list(filters).then(r => r.data)`, `staleTime: 5 * 60 * 1000`, `gcTime: 30 * 60 * 1000`, `retry: 1`
- `useTasks(filters?: ListTasksQuery)` -> `useQuery(taskListOptions(filters))`

- `useDeleteTask()` mutation: `mutationFn: ({ sourceType, id }: { sourceType: TaskSourceType; id: string }) => tasksApi.delete(sourceType, id).then(r => r.data)`, `onSuccess: invalidate tasksKeys.all`
- `useCompleteTask()` mutation: `mutationFn: ({ sourceType, id }: { sourceType: TaskSourceType; id: string }) => tasksApi.complete(sourceType, id).then(r => r.data)`, `onSuccess: invalidate tasksKeys.all`

Import `useQuery, useMutation, useQueryClient, queryOptions` from `@tanstack/react-query`.
