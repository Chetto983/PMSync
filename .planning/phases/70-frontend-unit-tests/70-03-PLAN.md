### authClient methods called per component (from source file reads)

**SecurityMfaSection.tsx:**
- `authClient.getSession()` → returns `{data:{user:{twoFactorEnabled:boolean}}}`
- `authClient.passkey.listUserPasskeys()` → returns `{data:[{id,name,createdAt,credential}]}`
- `authClient.passkey.addPasskey({name})` → resolves on success
- `authClient.passkey.deletePasskey({id})` → resolves on success
- `authClient.twoFactor.enable({password})` → returns TOTP uri
- `authClient.twoFactor.disable({password})` → resolves on success
- `authClient.twoFactor.verifyTotp({code})` → resolves on success
- `authClient.twoFactor.generateBackupCodes({password})` → returns codes array
- Also uses `next/image` (already mocked in jest.setup.ts after plan 01)
- Also uses `require('ua-parser-js')` — works fine in jsdom, no mock needed

**SecurityPasswordSection.tsx:**
- `authClient.listAccounts()` → returns `{data:[{providerId:'credential'}]}`
- `authClient.changePassword({currentPassword, newPassword, revokeOtherSessions:false})` → resolves on success

**SecuritySessionsSection.tsx:**
- `authClient.listSessions()` → returns `{data:[{id,token,userAgent,ipAddress,createdAt}]}`
- `authClient.getSession()` → returns `{data:{session:{token:string}}}`
- `authClient.revokeSession({token})` → resolves on success

**SecurityAccountsSection.tsx:**
- `authClient.listAccounts()` → returns `{data:[{accountId,providerId}]}`
- `authClient.linkSocial({provider,callbackURL})` → resolves (triggers redirect)
- `authClient.unlinkAccount({accountId})` → resolves on success

### ThemeProvider not required
MUI components render without ThemeProvider in jsdom — they use default theme. Do NOT add ThemeProvider wrapper unless a test fails due to theme access.

### userEvent setup pattern
```typescript
import userEvent from '@testing-library/user-event';
const user = userEvent.setup();
// Then: await user.click(button)
```

### Data-testid vs getByRole
Prefer `screen.getByRole('button', {name:/text/i})` over data-testid. Use `getByText` for static text. Use `findBy*` variants (async) after API calls resolve. Use `waitFor` for state changes triggered by async effects.
