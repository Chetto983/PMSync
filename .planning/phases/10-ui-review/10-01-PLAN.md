  <action>
    **1. Skip navigation link in Layout.tsx:**
    Add as the FIRST child inside the outermost container of Layout.tsx:
    ```tsx
    <a
      href="#main-content"
      className="sr-only focus:not-sr-only focus:absolute focus:z-[9999] focus:top-2 focus:left-2 focus:px-4 focus:py-2 focus:rounded-lg focus:bg-primary focus:text-primary-foreground focus:outline-none focus:ring-2 focus:ring-ring"
    >
      {t.common?.skipToContent || 'Skip to main content'}
    </a>
    ```
    If `t.common.skipToContent` doesn't exist in translations, add it to `frontend/locales/en.ts` ("Skip to main content") and `frontend/locales/it.ts` ("Vai al contenuto principale"). Add the type to `frontend/locales/index.ts` if needed.

    Then find the `<main>` or primary content wrapper element and add `id="main-content"` and `tabIndex={-1}` to it. If the main content area uses `<Box component="main">`, add the id there.

    **2. Reduced motion CSS in globals.css:**
    Add this media query at the END of globals.css (after all other rules):
    ```css
    @media (prefers-reduced-motion: reduce) {
      *,
      *::before,
      *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
        scroll-behavior: auto !important;
      }
    }
    ```

    **3. MotionConfig in _app.tsx:**
    Import `MotionConfig` from `framer-motion` in the app entry point (`_app.tsx` or equivalent).
    Wrap the app content (inside existing providers but wrapping the page content) with:
    ```tsx
    <MotionConfig reducedMotion="user">
      {/* existing content */}
    </MotionConfig>
    ```
    This tells framer-motion to respect the user's OS reduced motion preference automatically.
