  <files>
    frontend/components/dashboard/widgets/* (card hover effects)

    frontend/components/ai/AiDashboard/* (message entrance)
    frontend/src/components/ai-elements/* (tool card reveals)
    frontend/components/layout/Layout.tsx (page transitions, if not already present)
  </files>
  <action>
    Add subtle framer-motion animations to key interactive elements. All animations MUST work within the MotionConfig wrapper from Plan 01 (reducedMotion="user"), so they automatically disable for users with reduced motion preference.

    **1. Dashboard Widget Cards -- hover lift:**
    ```tsx
    import { motion } from 'framer-motion';

    // Wrap each widget card
    <motion.div
      whileHover={{ y: -2, boxShadow: '0 8px 24px rgba(0,0,0,0.08)' }}
      transition={{ duration: 0.2, ease: 'easeOut' }}
    >
      {/* existing card content */}
    </motion.div>
    ```

    **2. Button press effects -- scale tap:**
    Add to primary action buttons (Send, Save, Submit) across the app:
    ```tsx
    <motion.button
      whileTap={{ scale: 0.97 }}
      transition={{ duration: 0.1 }}
    >
    ```
    For MUI Buttons, wrap with motion.div or use `component={motion.button}` if compatible. Test that MUI Button props still work.

    **3. Chat message entrance -- fade + slide:**
    In ChatMessages or the message rendering component:
    ```tsx
    <motion.div
      initial={{ opacity: 0, y: 8 }}
      animate={{ opacity: 1, y: 0 }}
      transition={{ duration: 0.2, ease: 'easeOut' }}
    >
      {/* message content */}
    </motion.div>
    ```

    **4. Tool result card reveal -- fade in:**
    In smart tool renderers:
    ```tsx
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={{ duration: 0.15 }}
    >
      {/* tool result content */}
    </motion.div>
    ```

    **5. List item stagger (optional, if performant):**
    For email list or contact list, if VList allows it:
    ```tsx
    // Only apply to visible items, not the entire virtual list
    <motion.div
      initial={{ opacity: 0 }}
      animate={{ opacity: 1 }}
      transition={{ duration: 0.1, delay: index * 0.02 }}
    >
    ```
    IMPORTANT: Do NOT add stagger to virtualized lists if it causes scroll jank. Test with 100+ items.

    **6. Page/panel transitions:**
    If not already present, add fade transition to main content area when navigating between dashboard pages.

    Keep animations SUBTLE -- durations between 0.1-0.25s, small transform values (y: -2 to 8px, scale: 0.97-1.02). This is polish, not spectacle.
  </action>

    4. Chat messages animate in smoothly.
    5. Set OS to reduced motion -- verify all animations are disabled.
    6. No scroll jank in email list with 100+ items.
  </verify>

    **1. Focus indicator consistency (globals.css):**

    Add a global focus-visible style if not already comprehensive:
    ```css
    /* Consistent focus indicators */
    :focus-visible {
      outline: 2px solid hsl(var(--primary));
      outline-offset: 2px;
      border-radius: 4px;
    }

    /* Remove default outline for mouse users */
    :focus:not(:focus-visible) {
      outline: none;
    }
    ```
    This ensures ALL interactive elements get a visible focus ring when tabbing, without affecting mouse users. Check that this doesn't conflict with existing focus styles in specific components.
