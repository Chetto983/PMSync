## Color

All colors from existing MUI theme. No new colors introduced.

| Role | Value (Dark / Light) | Usage |
|------|----------------------|-------|
| Dominant (60%) | `background.default` (#0c1017 / #f8fafc) | Page background behind banners |
| Secondary (30%) | `background.paper` (#131a24 / #ffffff) | Snackbar surface, Dialog surface |
| Accent (10%) | `info.main` (#55cae5 / #00aced) | Install banner icon, "Install" button |
| Destructive | not used | No destructive actions in this phase |

Accent reserved for: Download icon in Snackbar, "Install" primary action button. NOT for dismiss/close button (dismiss uses default text color).

Info severity used for install Snackbar because install is informational guidance, matching the existing `OfflineBanner` pattern which uses `severity="warning"` for a different purpose. Install = info. Offline = warning.

## Component Inventory

| Component | MUI Base | Behavior | INST Req |
|-----------|----------|----------|----------|
| `InstallPromptBanner` | `Snackbar` + `Alert` | Bottom-center Snackbar with info severity. Two actions: "Install" Button + "Not now" text button. Auto-hidden when standalone. | INST-01, INST-03 |
| `InstallPromptBanner` (iOS path) | `Snackbar` + `Alert` | Bottom-center Snackbar with info severity. Single action: "Learn how" text button that opens iOS dialog. | INST-02, INST-03 |
| iOS instructions Dialog | `Dialog` + `DialogTitle` + `DialogContent` + `DialogActions` | Modal with 3 numbered steps. Share icon (`Share` from lucide-react, or inline SVG of iOS share icon) next to step 1. Single close button. | INST-02 |

### Component Interaction States

**InstallPromptBanner (Chromium):**
- **Visible:** `beforeinstallprompt` captured AND not standalone AND not dismissed within 30 days
- **Hidden:** standalone mode OR dismissed OR `appinstalled` fired
- **Install click:** calls `deferredPrompt.prompt()` (must be in click handler). If accepted, banner hides permanently. If dismissed by browser prompt, banner hides (same session).
- **"Not now" click:** banner hides, timestamp written to localStorage (`pmsync:install-prompt-dismissed`), re-shows after 30 days.
- **Position:** `anchorOrigin={{ vertical: 'bottom', horizontal: 'center' }}`

**InstallPromptBanner (iOS):**
- **Visible:** iOS detected AND not standalone AND not dismissed within 30 days
- **Hidden:** standalone mode OR dismissed
- **"Learn how" click:** opens iOS instructions Dialog
- **"Not now" / dismiss:** same as Chromium path

**iOS instructions Dialog:**
- **Open:** triggered by "Learn how" from Snackbar
- **Close:** "Close" button in DialogActions, or backdrop click
- **No dismiss persistence on dialog close:** only the Snackbar "Not now" persists dismissal

## Layout Integration

The `InstallPromptBanner` wires into `Layout.tsx` identically to `OfflineBanner`:

```
<OfflineBanner />           -- existing (top, Collapse)
<InstallPromptBanner />     -- new (bottom, Snackbar)
```

The Snackbar's bottom position avoids conflict with the top-positioned OfflineBanner. Both can be visible simultaneously (offline + install prompt) without overlap.
