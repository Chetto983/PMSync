**4. Add session.create hook for activeOrganizationId auto-set (Pitfall 4 fix):**

In the `databaseHooks` section of better-auth config, add a `session.create.before` hook that auto-sets `activeOrganizationId` to the user's first organization:

```typescript
session: {
  create: {
    before: async (session) => {
      // Auto-set activeOrganizationId on login to user's first org
      const member = await prisma.member.findFirst({
        where: { userId: session.userId },
        orderBy: { createdAt: 'asc' },
        select: { organizationId: true },
      });
      if (member) {
        return {
          data: {
            ...session,
            activeOrganizationId: member.organizationId,
          },
        };
      }
      return { data: session };
    },
  },
},
```

This prevents the scenario where `activeOrganizationId` is null after login, which would cause TenantGuard to reject requests (RESEARCH.md Pitfall 4).

**4. Create and run data migration for existing users:**

Create `backend/prisma/seed-members.ts` (one-time migration script):

```typescript
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

async function main() {
  // Find all users with a tenantId but no Member record
  const users = await prisma.user.findMany({
    where: {
      tenantId: { not: null },
    },
    select: { id: true, tenantId: true },
  });

  let created = 0;
  let skipped = 0;

  for (const user of users) {
    if (!user.tenantId) continue;

    const existing = await prisma.member.findUnique({
      where: {
        organizationId_userId: {
          organizationId: user.tenantId,
          userId: user.id,
        },
      },
    });

    if (existing) {
      skipped++;
      continue;
    }

    await prisma.member.create({
      data: {
        organizationId: user.tenantId,
        userId: user.id,
        role: 'admin',
      },
    });
    created++;
  }

  console.log(`Migration complete: ${created} member records created, ${skipped} skipped (already exist)`);
}

main()
  .catch(console.error)
  .finally(() => prisma.$disconnect());
```

Run the migration: `cd backend && npx ts-node prisma/seed-members.ts`
