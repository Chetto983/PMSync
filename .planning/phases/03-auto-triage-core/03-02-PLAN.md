Add a GET endpoint `@Get('triage/suggested-vips')` to the existing AiController. This endpoint queries contacts with high interaction counts who are NOT already isVip=true.

The endpoint should:

1. Accept `@Req() req` to get `tenantId` from `req.user.tenantId`.
2. Accept an optional `@Query('limit')` parameter (default 10, max 20).
3. Query Prisma for contacts matching:

```typescript
const suggestedVips = await this.prisma.contact.findMany({
  where: {
    tenantId,
    isDeleted: false,
    isVip: false,
    OR: [
      { totalInteractions: { gte: 10 } },
      { relationshipScore: { gte: 60 } },
    ],
  },
  select: {
    id: true,
    displayName: true,
    firstName: true,
    lastName: true,
    company: true,
    emails: true,
    totalInteractions: true,
    relationshipScore: true,
    lastInteractedAt: true,
  },
  orderBy: [
    { totalInteractions: 'desc' },
    { relationshipScore: 'desc' },
  ],
  take: Math.min(limit, 20),
});
```

4. Return `{ suggestions: suggestedVips, total: suggestedVips.length }`.
