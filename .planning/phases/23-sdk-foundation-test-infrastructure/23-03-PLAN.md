    **Step 2: Create MSW handler for Mistral chat completions SSE streaming**
    Create `backend/src/test/msw-handlers/mistral-chat.handler.ts`:

    This handler intercepts `POST https://api.mistral.ai/v1/chat/completions` and returns deterministic responses. For non-streaming requests (`stream: false` or absent), it returns a standard JSON response. For streaming requests (`stream: true`), it returns SSE-formatted chunks via ReadableStream. The SSE format must be OpenAI-compatible (what `@ai-sdk/mistral` expects).

    ```typescript
    import { http, HttpResponse } from 'msw';

    const CHAT_CHUNKS = [
      { content: 'Hello' },
      { content: ' from' },
      { content: ' MSW' },
      { content: ' mock' },
    ];

    export const mistralChatHandler = http.post(
      'https://api.mistral.ai/v1/chat/completions',
      async ({ request }) => {
        const body = (await request.json()) as { stream?: boolean; model?: string };

        if (!body.stream) {
          return HttpResponse.json({
            id: 'chatcmpl-msw-test',
            object: 'chat.completion',
            model: body.model ?? 'mistral-small-latest',
            choices: [{
              index: 0,
              message: { role: 'assistant', content: 'Hello from MSW mock' },
              finish_reason: 'stop',
            }],
            usage: { prompt_tokens: 10, completion_tokens: 4, total_tokens: 14 },
          });
        }

        const encoder = new TextEncoder();
        const stream = new ReadableStream({
          async start(controller) {
            for (const chunk of CHAT_CHUNKS) {
              const sseData = JSON.stringify({
                id: 'chatcmpl-msw-test',
                object: 'chat.completion.chunk',
                model: body.model ?? 'mistral-small-latest',
                choices: [{ index: 0, delta: { content: chunk.content }, finish_reason: null }],
              });
              controller.enqueue(encoder.encode(`data: ${sseData}\n\n`));
            }
            const finalData = JSON.stringify({
              id: 'chatcmpl-msw-test',
              object: 'chat.completion.chunk',
              model: body.model ?? 'mistral-small-latest',
              choices: [{ index: 0, delta: {}, finish_reason: 'stop' }],
              usage: { prompt_tokens: 10, completion_tokens: 4, total_tokens: 14 },
            });
            controller.enqueue(encoder.encode(`data: ${finalData}\n\n`));
            controller.enqueue(encoder.encode('data: [DONE]\n\n'));
            controller.close();
          },
        });

        return new HttpResponse(stream, {
          status: 200,
          headers: {
            'Content-Type': 'text/event-stream',
            'Cache-Control': 'no-cache',
            Connection: 'keep-alive',
          },
        });
      },
    );
    ```

    **Step 3: Create MSW handler for Mistral embeddings**
    Create `backend/src/test/msw-handlers/mistral-embed.handler.ts`:

    Intercepts `POST https://api.mistral.ai/v1/embeddings`. Returns deterministic 1024-dim vectors using `Math.sin(seed + i * 0.1) * 0.5` so tests can assert exact values.

    ```typescript
    import { http, HttpResponse } from 'msw';

    function makeDeterministicVector(seed: number): number[] {
      return Array.from({ length: 1024 }, (_, i) => Math.sin(seed + i * 0.1) * 0.5);
    }

    export const mistralEmbedHandler = http.post(
      'https://api.mistral.ai/v1/embeddings',
      async ({ request }) => {
        const body = (await request.json()) as { model?: string; input: string | string[] };
        const inputs = Array.isArray(body.input) ? body.input : [body.input];
        const data = inputs.map((text, index) => ({
          object: 'embedding' as const,
          index,
          embedding: makeDeterministicVector(index),
        }));
        return HttpResponse.json({
          id: 'embd-msw-test',
          object: 'list',
          model: body.model ?? 'mistral-embed',
          data,
          usage: {
            prompt_tokens: inputs.reduce((sum, t) => sum + t.length, 0),
            total_tokens: inputs.reduce((sum, t) => sum + t.length, 0),
          },
        });
      },
    );
    ```

    **Step 5: Create MSW setup file**
    Create `backend/src/test/setup.ts`:

    This file exports a pre-configured MSW server instance. It does NOT install global lifecycle hooks -- MSW-using tests import `mswServer` and manage `listen()`/`resetHandlers()`/`close()` themselves. This prevents MSW from intercepting real-API tests that hit the same Mistral URLs.

    ```typescript
    import { setupServer } from 'msw/node';
    import { handlers } from './msw-handlers';

    // MSW server with Mistral API handlers for deterministic testing.
    // Usage in test files:
    //   import { mswServer } from '../test/setup';
    //   beforeAll(() => mswServer.listen({ onUnhandledRequest: 'error' }));
    //   afterEach(() => mswServer.resetHandlers());
    //   afterAll(() => mswServer.close());
    export const mswServer = setupServer(...handlers);
    ```

    **Why per-test lifecycle (not global setupFiles):** The existing real-API tests in `src/modules/mistral/__tests__/` hit `https://api.mistral.ai/v1/...` -- the exact URLs our MSW handlers intercept. If MSW were activated globally, those tests would get mocked responses instead of real API responses. Per-test lifecycle keeps MSW active only in tests that explicitly import and start the server.

    **Step 6: Create deterministic MSW-mocked streaming test**
    Create `backend/src/test/msw-streaming.test.ts`:

    This test proves the full MSW infrastructure works: AI SDK calls `createMistral` -> makes HTTP request to `https://api.mistral.ai/v1/...` -> MSW intercepts -> returns deterministic data -> AI SDK processes it. Uses a dummy API key since MSW intercepts before the request leaves the process.

    ```typescript
    import { describe, it, expect, beforeAll, afterEach, afterAll } from 'vitest';
    import { generateText, streamText, embed } from 'ai';
    import { createMistral } from '@ai-sdk/mistral';
    import { mswServer } from './setup';

    const mistral = createMistral({ apiKey: 'msw-test-key' });

    beforeAll(() => mswServer.listen({ onUnhandledRequest: 'error' }));
    afterEach(() => mswServer.resetHandlers());
    afterAll(() => mswServer.close());

    describe('MSW-mocked Mistral API', () => {
      describe('chat completions', () => {
        it('returns deterministic text via generateText', async () => {
          const { text, finishReason, usage } = await generateText({
            model: mistral('mistral-small-latest'),
            prompt: 'This prompt is intercepted by MSW',
            maxOutputTokens: 50,
          });
          expect(text).toBe('Hello from MSW mock');
          expect(finishReason).toBe('stop');
          expect(usage.promptTokens).toBe(10);
          expect(usage.completionTokens).toBe(4);
        });

        it('streams deterministic chunks via streamText', async () => {
          const result = streamText({
            model: mistral('mistral-small-latest'),
            prompt: 'This prompt is intercepted by MSW',
            maxOutputTokens: 50,
          });
          const chunks: string[] = [];
          for await (const chunk of result.textStream) {
            chunks.push(chunk);
          }
          const fullText = chunks.join('');
          expect(fullText).toBe('Hello from MSW mock');
          expect(chunks.length).toBeGreaterThanOrEqual(1);
        });
      });

      describe('embeddings', () => {
        it('returns deterministic 1024-dim embedding via embed', async () => {
          const { embedding, usage } = await embed({
            model: mistral.embedding('mistral-embed'),
            value: 'test content for deterministic embedding',
          });
          expect(embedding).toHaveLength(1024);
          expect(embedding.every(v => typeof v === 'number' && Number.isFinite(v))).toBe(true);
          const expectedFirst = Math.sin(0 + 0 * 0.1) * 0.5; // sin(0) * 0.5 = 0
          expect(embedding[0]).toBeCloseTo(expectedFirst, 5);
          expect(usage.tokens).toBeGreaterThan(0);
        });
      });
    });
    ```
