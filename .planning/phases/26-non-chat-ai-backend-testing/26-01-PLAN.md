**BriefingService** (briefing.service.ts, ~250 lines):

Export `briefingSchema` as a Zod object with these fields:
```
priorityEmails: z.array(z.object({ emailId, subject, sender, urgency: enum, reason }))
calendarSnapshot: z.array(z.object({ eventId, title, startTime, endTime, hasConflict }))
pendingFollowUps: z.array(z.object({ emailId, contactName, reason, suggestedDueDate, urgency }))
executiveSummary: z.string()
staleContactsAlert: z.array(z.object({ contactId, name, daysSinceContact, suggestedAction }))
draftSuggestions: z.array(z.object({ emailId, subject, reason }))
emailVolumeTrends: z.object({ todayReceived, todaySent, weeklyAvgReceived, weeklyAvgSent, trend })
focusTimeRecommendations: z.array(z.object({ startTime, endTime, reason }))
```
Export `type BriefingOutput = z.infer<typeof briefingSchema>`.

`generateBriefing(tenantId: string)` method:
1. Pre-fetch in parallel via `Promise.all()`:
   - Priority emails: `prisma.email.findMany({ where: { tenantId, isRead: false }, orderBy: { receivedAt: 'desc' }, take: 20, select: { id, subject, from, snippet, receivedAt } })`
   - Today's events: `prisma.calendarEvent.findMany({ where: { tenantId, startTime: { gte: startOfDay, lte: endOfDay } }, select: { id, title, startTime, endTime } })`
   - Pending follow-ups: `prisma.emailFollowUp.findMany({ where: { tenantId, status: 'PENDING' }, take: 10, select: { id, emailId, reason, dueDate } })`
   - Stale contacts: `prisma.contact.findMany({ where: { tenantId, isDeleted: false, lastInteractedAt: { lt: 30daysAgo } }, orderBy: { lastInteractedAt: 'asc' }, take: 5, select: { id, displayName, lastInteractedAt } })`
   - Email volume: `prisma.email.count()` for today + weekly average via grouped query
2. Build prompt with pre-fetched data serialized as JSON context
3. Call `generateText({ model: this.mistralProvider.getChatModel(), output: Output.object({ schema: briefingSchema }), system: '...', prompt: dataContext })`
4. Return output with graceful fallback

System prompt: "You are a professional executive assistant analyzing a user's email, calendar, and contacts data to produce a comprehensive daily briefing. Return structured data matching the exact schema. Be concise and actionable."

```typescript
// GET /ai/briefing -- Generate daily briefing
@Get('briefing')
@RequiresConsent('ai_email_processing')
@RequiresQuota('ai')
async getBriefing(@Request() req: AuthenticatedRequest) {
  const result = await this.briefingService.generateBriefing(req.user.tenantId);
  return { success: true, briefing: result };
}

// POST /ai/briefing/refresh -- Force regenerate briefing (bypass cache)
@Post('briefing/refresh')
@HttpCode(HttpStatus.OK)
@RequiresConsent('ai_email_processing')
@RequiresQuota('ai')
async refreshBriefing(@Request() req: AuthenticatedRequest) {
  const result = await this.briefingService.generateBriefing(req.user.tenantId);
  return { success: true, briefing: result };
}

// POST /ai/follow-ups/detect -- Run follow-up detection
@Post('follow-ups/detect')
@HttpCode(HttpStatus.OK)
@RequiresConsent('ai_email_processing')
@RequiresQuota('ai')
async detectFollowUps(@Request() req: AuthenticatedRequest) {
  const result = await this.followUpDetectionService.detectFollowUps(req.user.tenantId);
  return { success: true, ...result };
}

// POST /ai/drafts/generate -- Generate reply draft
@Post('drafts/generate')
@HttpCode(HttpStatus.OK)
@RequiresConsent('ai_email_processing')
@RequiresQuota('ai')
async generateDraft(
  @Request() req: AuthenticatedRequest,
  @Body() dto: { emailId: string; instruction: string; tone?: string },
) {
  const result = await this.draftGenerationService.generateDraft(req.user.tenantId, dto);
  return { success: true, draft: result };
}
```
