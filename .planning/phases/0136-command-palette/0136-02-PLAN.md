**1. Create `frontend/components/ai/CommandPalette/use-command-search.ts` (~120 lines):**

Import `useState`, `useEffect`, `useRef` from React. Import `useRouter` from `next/router`. Import all 5 API modules. Import `SearchResult`, `SearchResultGroup` from `./types`. Import `useTranslations` from `@/lib/hooks/use-translations`. Import `Mail`, `User`, `Handshake`, `Ticket`, `BookOpen` from `lucide-react`. Import `useUserTimezone` and `formatDateInTz` from existing utils (same pattern as current index.tsx).

Export `function useCommandSearch(query: string): { results: SearchResultGroup[]; isSearching: boolean; hasError: boolean }`.

Implementation:
- If `!query || query.length < 2`, return empty results, not searching, no error.
- Use `reqIdRef = useRef(0)` for stale request prevention (monotonically increasing counter).
- On query change, increment `reqIdRef.current`, capture as `currentReqId`.
- Set `isSearching = true`.
- Fire `Promise.allSettled([...])` with all 5 API calls, each limited to 5 results:
  - `emailsApi.searchEmails(query, 5)`
  - `contactsApi.listContacts({ search: query, limit: 5 })`
  - `crmDealsApi.list({ search: query, limit: 5 })`
  - `crmTicketsApi.list({ search: query, limit: 5 })`
  - `crmKBApi.search(query, 5)`
- In `.then()`, check `reqIdRef.current !== currentReqId` — if stale, return early.
- Map each fulfilled result into a `SearchResultGroup`:
  - **Emails**: type `'email'`, label `t.commandPalette.emailResults`, icon `Mail`, primary = `email.subject || '(No subject)'`, secondary = `${email.from} - ${formatDateInTz(email.receivedAt, tz)}`, action = `router.push(/dashboard/email?id=${email.id})`
  - **Contacts**: type `'contact'`, label `t.commandPalette.contactResults`, icon `User`, primary = `contact.displayName || contact.emails?.[0]?.value || 'Unknown'`, secondary = `contact.company || contact.emails?.[0]?.value || ''`, action = `router.push(/dashboard/contacts?id=${contact.id})`
  - **Deals**: type `'deal'`, label `t.commandPalette.dealResults`, icon `Handshake`, primary = `deal.name`, secondary = `${deal.stage?.name || ''} - ${deal.value ? '$' + deal.value.toLocaleString() : ''}`.trim(), action = `router.push(/dashboard/crm/deals?id=${deal.id})`
  - **Tickets**: type `'ticket'`, label `t.commandPalette.ticketResults`, icon `Ticket`, primary = `ticket.subject`, secondary = `${ticket.status} - ${ticket.priority}`, action = `router.push(/dashboard/crm/tickets?id=${ticket.id})`
  - **KB Articles**: type `'kb'`, label `t.commandPalette.kbResults`, icon `BookOpen`, primary = `article.title`, secondary = `article.snippet?.substring(0, 80) || ''`, action = `router.push(/dashboard/crm/kb?id=${article.id})`
- Only add groups that have at least 1 result.
- If ALL 5 promises rejected, set `hasError = true`.
- Set `isSearching = false` after processing.

**Rewrite `frontend/components/ai/CommandPalette/index.tsx` (~200 lines):**

This file becomes the dialog shell orchestrating the extracted modules. Remove ALL inline command definitions, search logic, and result rendering. Keep: Dialog shell, keyboard handling, state management, footer hints.

**Imports:**
- React: `useEffect`, `useState`, `useCallback`, `useMemo`, `useRef`
- `next/router`: `useRouter`
- `use-debounce`: `useDebounce`
- MUI: `Dialog`, `TextField`, `Box`, `Typography`, `Divider`, `InputAdornment`, `alpha`
- lucide-react: `Search`
- Local modules:
  - `{ CommandItem } from './types'`
  - `{ buildCommands, GROUP_ORDER, GROUP_LABELS } from './commands'`
  - `{ CommandList } from './CommandList'`
  - `{ SearchResults } from './SearchResults'`
  - `{ useCommandSearch } from './use-command-search'`
- Existing: `authClient`, `clearOfflineData`, `useTranslations`, `createLogger`

**State:**
- `open: boolean` (dialog visibility)
- `search: string` (raw input)
- `debouncedSearch` via `useDebounce(search, 300)`
- `focusedIndex: number` (keyboard nav across both commands and results)
- `listRef: useRef<HTMLUListElement>(null)`

**Hooks:**
- `const commands = useMemo(() => buildCommands(router, t, handleLogout), [router, t, handleLogout])`
- `const { results: searchResults, isSearching, hasError } = useCommandSearch(debouncedSearch)`
- `const groupLabels = useMemo(() => Object.fromEntries(Object.entries(GROUP_LABELS).map(([k, fn]) => [k, fn(t)])), [t])`

**Derived state:**
- `filteredCommands`: If `search.length >= 2`, filter `commands` where `command.name.toLowerCase().includes(search.toLowerCase())` OR any `command.keywords` includes the search term (case-insensitive). If `search.length < 2`, show all commands.
- `showSearchResults`: `search.length >= 2` (show search results section below commands)
- `totalItems`: `filteredCommands.length + searchResults.reduce((sum, g) => sum + g.results.length, 0)` (for keyboard nav bounds)

**Keyboard handling (global Cmd+K):** Keep existing `useEffect` for toggle.

**Keyboard handling (within dialog):** On `keyDown` of the `TextField`:
- `ArrowDown`: increment focusedIndex (wrap to 0 at totalItems)
- `ArrowUp`: decrement focusedIndex (wrap to totalItems - 1 at 0)
- `Enter`: if focusedIndex < filteredCommands.length, execute that command's action and close. If focusedIndex >= filteredCommands.length, find the search result at `focusedIndex - filteredCommands.length` offset, execute its action and close.
- `Escape`: close dialog (MUI Dialog also handles this)

**Render structure:**
```
<Dialog open={open} onClose={handleClose} maxWidth="sm" fullWidth
  PaperProps={{ sx: { position: 'fixed', top: '20%', borderRadius: 3, maxHeight: '60vh', overflow: 'hidden' } }}
  BackdropProps={{ sx: { backdropFilter: 'blur(4px)' } }}
  aria-label={t.commandPalette.title}
>
  {/* Search input */}
  <Box sx={{ px: 2, pt: 2 }}>
    <TextField
      fullWidth autoFocus variant="outlined" placeholder={t.commandPalette.searchPlaceholder}
      value={search} onChange={(e) => setSearch(e.target.value)}
      onKeyDown={handleKeyDown}
      InputProps={{
        startAdornment: <InputAdornment position="start"><Search size={20} /></InputAdornment>,
        sx: { fontSize: '1.1rem', '& fieldset': { border: 'none' } }
      }}
    />
  </Box>

  {/* Command list (always visible, filtered when typing) */}
  <CommandList
    commands={filteredCommands}
    focusedIndex={focusedIndex}
    onSelect={handleCommandSelect}
    groupLabels={groupLabels}
    listRef={listRef}
  />

  {/* Search results (visible when query >= 2 chars) */}
  {showSearchResults && (
    <>
      <Divider />
      <SearchResults
        groups={searchResults}
        isSearching={isSearching}
        hasError={hasError}
        focusedIndex={focusedIndex}
        onSelect={handleSearchResultSelect}
        commandCount={filteredCommands.length}
        listRef={listRef}
      />
    </>
  )}

  {/* Footer hints bar */}
  <Divider />
  <Box sx={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', px: 2, py: 1 }}>
    {/* Three hint groups: ArrowUp/Down = Navigate, Enter = Select, Esc = Close */}
    {/* Each hint: kbd-styled Box with alpha(text.primary, 0.06) bg, borderRadius: 1 */}
    <Box sx={{ display: 'flex', gap: 1.5, alignItems: 'center' }}>
      <HintBadge keys="↑↓" label={t.commandPalette.navigate} />
      <HintBadge keys="↵" label={t.commandPalette.select} />
      <HintBadge keys="esc" label={t.commandPalette.close} />
    </Box>
  </Box>
</Dialog>
```

**HintBadge** can be a small inline component or extracted at file top (~10 lines): renders a `Box` with `display: 'inline-flex'`, `alignItems: 'center'`, `gap: 0.5`. The key part: `Box` with `sx: { bgcolor: (theme) => alpha(theme.palette.text.primary, 0.06), borderRadius: 1, px: 0.75, py: 0.25, fontSize: '0.7rem', fontWeight: 400 }}`. The label: `Typography` with `variant="caption"`, `fontSize: '0.75rem'`, `color="text.secondary"`.

**handleCommandSelect**: execute `command.action()`, then `handleClose()`.

Keep existing `export function CommandPalette()` and `export default CommandPalette` (both were present in original).
