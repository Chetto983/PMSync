## Color

All colors reference MUI theme tokens from `frontend/theme/tokens.ts`. No hardcoded hex values in components.

| Role | Theme Token | Usage |
|------|-------------|-------|
| Dominant (60%) | `palette.background.paper` / Dialog surface | Dialog background |
| Secondary (30%) | `alpha(palette.text.primary, 0.06)` | Shortcut badge bg, footer hint bg, focused item highlight |
| Accent (10%) | `palette.primary.main` (#55cae5 dark / #00aced light) | Reserved for: (1) search input caret, (2) loading spinner, (3) focused item left border |
| Destructive | `palette.error.main` | Logout command icon tint only |
| Backdrop | `backdropFilter: 'blur(4px)'` | Dialog backdrop (existing) |

### Search Results (SearchResults.tsx, ~150 lines)

When query >= 2 chars, show BOTH matching commands (filtered by keyword) AND API search results simultaneously. Matching commands appear first, then a divider, then search results grouped by entity type.

| Entity Group | Label (i18n key) | Icon | Fields shown |
|--------------|-------------------|------|-------------|
| Emails | `t.commandPalette.emailResults` | `Mail` | primary: subject, secondary: "from -- date" |
| Contacts | `t.commandPalette.contactResults` | `User` | primary: displayName, secondary: company or email |
| Deals | `t.commandPalette.dealResults` | `Handshake` | primary: deal name, secondary: "stage -- amount" |
| Tickets | `t.commandPalette.ticketResults` | `Ticket` | primary: subject, secondary: "status -- priority" |
| KB Articles | `t.commandPalette.kbResults` | `BookOpen` | primary: title, secondary: snippet (truncated) |

Each result item has a `Chip` showing entity type:
- `size="small"`, `variant="outlined"`
- `fontSize: '0.65rem'`, `height: 20`, `textTransform: 'capitalize'`
- Border color matches entity semantic color (see Color section)

## Interaction Contract

### Keyboard Shortcuts

| Key | Context | Action |
|-----|---------|--------|
| `Cmd+K` / `Ctrl+K` | Global (any screen) | Toggle palette open/close |
| `ArrowDown` | Palette open | Move focus to next item |
| `ArrowUp` | Palette open | Move focus to previous item |
| `Enter` | Palette open, item focused | Execute focused item action, close palette |
| `Escape` | Palette open | Close palette |

### Search Behavior

| Trigger | Behavior |
|---------|----------|
| 0-1 chars typed | Show all command groups (no API calls) |
| 2+ chars typed | Filter commands by name + keywords AND fire parallel API searches (debounced 300ms) |
| API calls | `Promise.allSettled` across 5 endpoints; skip failed; no blocking on slow endpoints |
| Stale prevention | Monotonic request ID via `useRef`; discard responses from outdated queries |
| Result limit | 5 results per entity type (25 max from API + filtered commands above) |

## File Structure Contract

Per 500-line limit and RESEARCH.md architecture:

```
frontend/components/ai/CommandPalette/
  index.tsx              # Dialog shell, keyboard handling, state orchestration (~200 lines)
  CommandList.tsx         # Grouped command list rendering with group headers (~120 lines)
  SearchResults.tsx       # Unified search results rendering by entity type (~150 lines)
  commands.ts            # Static command registry: navigation + CRM + actions + AI + system (~150 lines)
  use-command-search.ts  # Custom hook: parallel API calls, result merging, stale prevention (~120 lines)
  types.ts               # CommandItem, SearchResult, SearchResultGroup interfaces (~40 lines)
```

## Accessibility Contract

| Requirement | Implementation |
|-------------|---------------|
| Dialog focus trap | MUI Dialog built-in |
| Combobox pattern | `role="combobox"` on input, `aria-expanded="true"`, `aria-controls` pointing to list ID |
| Listbox pattern | `role="listbox"` on List, `role="option"` on each item |
| Active descendant | `aria-activedescendant` updated on keyboard navigation |
| Escape to close | Handled by MUI Dialog + explicit keydown handler |
| Screen reader label | `aria-label={t.commandPalette.title}` on Dialog |
| Keyboard-only operation | Full ArrowUp/ArrowDown/Enter/Escape support, no mouse required |
