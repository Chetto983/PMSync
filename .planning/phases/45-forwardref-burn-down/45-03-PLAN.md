Strategy depends on what you find:

READ `backend/src/modules/email-sync/email-sync.module.ts` to understand why it imports AiModule. This is likely for embedding queue services triggered after email sync.

Strategy: Use domain events. EmailSync emits `email.indexed` event after syncing an email, and AiModule's embedding handler listens via @OnEvent. This is the exact pattern proven in Phase 32.

Steps:
1. Add `EmailIndexedEvent` to `common/events/email.events.ts` (or extend existing if similar event exists):

export class EmailIndexedEvent {

3. In AiModule, create an @OnEvent handler for 'email.indexed' that calls the embedding queue
4. Remove `forwardRef(() => AiModule)` from email-sync.module.ts imports
5. Update `common/events/index.ts` to export new events
