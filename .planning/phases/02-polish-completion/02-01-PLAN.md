Add viewport meta tag with `viewport-fit=cover` to the existing Head component in `_app.tsx`.

**IMPORTANT:** Per Next.js docs, viewport meta MUST be in `_app.tsx` (NOT `_document.tsx`) to avoid deduplication warnings.

In the existing `<Head>` block (around line 164-167), add the viewport meta tag:

```tsx
<Head>
  <title>PMSync</title>
  {/* iOS safe area support - must be in _app, not _document */}
  <meta
    name="viewport"
    content="width=device-width, initial-scale=1, viewport-fit=cover"
  />
  <link rel="icon" type="image/svg+xml" href="/favicon.svg" sizes="any" />
</Head>
```

This enables `env(safe-area-inset-*)` CSS functions to return actual values on iOS devices with notches.
