<objective>
Surface CSRF token errors as structured JSON with auto-retry, so expired tokens don't produce empty/confusing error messages.

Purpose: CLN-01/CLN-02 -- currently the CSRF middleware passes the raw csrf-csrf error through to Express, which may produce an empty or generic error. The frontend retries ALL 403s as CSRF, risking infinite retry loops on auth failures. This plan adds a CSRF-specific error code for targeted retry.

Output: Enhanced CSRF middleware, ApiExceptionFilter CSRF handler, frontend CSRF-specific retry, unit test.
</objective>

1. **Backend CSRF middleware** (`csrf.middleware.ts`):
   - Replace the direct `return doubleCsrfProtection(req, res, next)` call with a callback wrapper:
     ```typescript
     doubleCsrfProtection(req, res, (err?: unknown) => {
       if (err) {
         if (err === invalidCsrfTokenError || (err as any)?.code === 'EBADCSRFTOKEN') {
           const csrfErr: any = new Error('Security token expired. Please retry.');
           csrfErr.statusCode = 403;
           csrfErr.code = 'CSRF_TOKEN_INVALID';
           return next(csrfErr);
         }
         return next(err);
       }
       next();
     });
     ```
   - The `invalidCsrfTokenError` is already imported (line 28). Reference it directly.

2. **ApiExceptionFilter** (`api-exception.filter.ts`):
   - In `resolveException()`, add a CSRF check BEFORE the generic Error handler (section 4, line 84):
     ```typescript
     // 4a. CSRF token error (from csrf.middleware.ts)
     if (exception instanceof Error && (exception as any).code === 'CSRF_TOKEN_INVALID') {
       return {
         status: 403,
         code: 'CSRF_TOKEN_INVALID',
         message: (exception as any).message || 'Security token expired. Please retry.',
         details: null,
       };
     }
     ```
   - Place this BEFORE the existing `if (exception instanceof Error)` block at line 85.

3. **Frontend api-client.ts** (line 216-222):
   - Change the CSRF 403 retry to check the error code:
     ```typescript
     if (error.response?.status === 403 && !error.config._csrfRetried) {
       const errorCode = error.response?.data?.error?.code;
       if (errorCode === 'CSRF_TOKEN_INVALID') {
         clearCsrfToken();
         error.config._csrfRetried = true;
         const freshToken = await getCsrfToken();
         if (freshToken) {
           error.config.headers['X-CSRF-Token'] = freshToken;
         }
         return apiClient.request(error.config);
       }
     }
     ```
   - This ensures non-CSRF 403s (authorization failures) are NOT retried.
