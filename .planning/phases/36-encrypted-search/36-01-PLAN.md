<objective>
Build HMAC blind index infrastructure for exact-match sender search on the Email `from` field.

Purpose: Enable searching encrypted `from` field by exact sender email without exposing plaintext in queries. This is the SEC-02 requirement -- HMAC-SHA256 blind indexes with per-tenant key derivation, a Prisma extension for automatic hash injection on writes, a dual-path query builder (HashSearchService), a backfill script for existing data, and the ADR documenting the design decision.

Output: fromHash column in schema, hmacForBlindIndex function, TenantKeyService.getHmacKey, field-encryption extension upgraded, HashSearchService (in common/services for global DI access), backfill script, ADR document, and comprehensive unit tests.
</objective>

    const masterKey = config.fieldEncryption.masterKey;
