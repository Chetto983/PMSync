model GraphNode {
  id         String   @id @default(cuid())
  tenantId   String

  outEdges   GraphEdge[] @relation("EdgeSource")
  inEdges    GraphEdge[] @relation("EdgeTarget")

  @@index([tenantId])

model GraphEdge {
  id        String   @id @default(cuid())
  tenantId  String
  sourceId  String
  targetId  String
  edgeType  String   // 'sent', 'received', 'mentions', 'replies_to', 'about', 'attended', 'anchored_to'
  weight    Float    @default(1.0)
  metadata  Json     @default("{}")
  createdAt DateTime @default(now())

  tenant    Tenant   @relation(fields: [tenantId], references: [id], onDelete: Cascade)
  source    GraphNode @relation("EdgeSource", fields: [sourceId], references: [id], onDelete: Cascade)
  target    GraphNode @relation("EdgeTarget", fields: [targetId], references: [id], onDelete: Cascade)

  @@unique([tenantId, sourceId, targetId, edgeType])
  @@index([tenantId])
  @@index([sourceId])
  @@index([targetId])
  @@index([tenantId, edgeType])

**1. Create `backend/src/modules/ai/services/entity-extraction.service.ts`:**

```typescript
@Injectable()
export class EntityExtractionService {
  private readonly logger = new Logger(EntityExtractionService.name);

  constructor(
    private readonly prisma: PrismaService,
    private readonly configService: ConfigService,
  ) {}
```

Core method: `async extractAndUpsert(tenantId: string, params: EmailExtractionParams | ContactExtractionParams): Promise<void>`

For **email extraction** (`params.type === 'email'`):
- Call the configured simple AI model (use `AI_MODEL_SIMPLE` env var, which is `mistralai/mistral-small-2603`) via the existing `MistralService.generateText()` or direct `@ai-sdk/mistral` call
- Prompt: Extract entities (people, orgs, topics) and relationships from email fields (from, to, cc, subject, body snippet limited to 500 chars)
- Parse JSON response with zod schema validation: `z.object({ entities: z.array(z.object({ type: z.enum(['person', 'organization', 'topic']), name: z.string(), metadata: z.record(z.unknown()).optional() })), relationships: z.array(z.object({ source: z.string(), target: z.string(), type: z.enum(['sent', 'received', 'mentions', 'about']), metadata: z.record(z.unknown()).optional() })) })`
- Upsert email node: `prisma.graphNode.upsert({ where: { tenantId_externalId unique filter }, create: { tenantId, nodeType: 'email', externalId: emailId, label: subject, metadata: { from, to, receivedAt, snippet } } })`
- For each extracted entity, upsert a node (contact node by contactId if found in unified_contacts via email match, topic node by label+tenantId)
- For each relationship, upsert an edge with `@@unique([tenantId, sourceId, targetId, edgeType])` -- use Prisma's `upsert` or `createMany` with `skipDuplicates: true`
- Wrap entire extraction in try/catch -- log and swallow errors (extraction failure must NOT fail the embedding pipeline)

For **contact extraction** (`params.type === 'contact'`):
- Simpler: just upsert a `contact` node with `externalId: contactId`, `label: displayName`, `metadata: { company, jobTitle, emails }`
- No LLM call needed for contacts -- direct mapping
