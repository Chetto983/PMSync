**Knowledge Base (BAPI-15) -- all under `/ai/knowledge-base/*`:**

1. `POST /ai/knowledge-base/emails/backfill` -- body: `{ limit: 10 }` -- expect `{ success: true, processed: N, embedded: N, skipped: N, remaining: N }`. This is admin-only (uses `ensureAdmin(req.user.role)`).
2. `GET /ai/knowledge-base/embeddings` -- query: `page=1&limit=10` -- expect `{ success: true, items: [...], total: N }`. Admin-only.
3. `DELETE /ai/knowledge-base/embeddings/:id` -- use an embedding ID from step 2 (if safe to delete a test one) -- expect `{ success: true }`. Admin-only.
4. `DELETE /ai/knowledge-base/embeddings/email/:emailId` -- purge all embeddings for one email -- expect `{ success: true, deleted: N }`. Admin-only.
5. `POST /ai/knowledge-base/search` -- body: `{ query: "meeting", limit: 5 }` -- expect `{ items: KnowledgeBaseSearchHit[], total: N }`. Available to all authenticated users.

**Important sequencing:** Run backfill (step 1) BEFORE search (step 5) to ensure embeddings exist. If search returns empty after backfill, check if emails exist in the tenant and if pgvector extension is enabled.
