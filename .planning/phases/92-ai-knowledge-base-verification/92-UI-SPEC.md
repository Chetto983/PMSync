| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (spacing.1) | Icon gaps, inline padding |
| sm | 8px (spacing.2) | Compact element spacing, HITL card inner gaps |
| md | 16px (spacing.4) | Default element spacing, card padding |

## Color

All values from `frontend/theme/tokens.ts`. Both dark and light themes are already defined.

| Role | Value (Dark / Light) | Usage |
|------|---------------------|-------|
| Dominant (60%) | #0c1017 / #f8fafc | Chat background, page background |
| Secondary (30%) | #131a24 / #ffffff | Message bubbles, sidebar, tool result cards |
| Accent (10%) | #55cae5 / #00aced (primary.main) | Send button, active conversation highlight, streaming cursor |
| Destructive | #ef4444 / #dc2626 (error.main) | HITL deny button, delete conversation action |

Accent reserved for: chat send button, active conversation indicator in thread list, streaming text cursor, AI avatar/icon glow.

**Semantic colors used by existing chat components:**
- HITL approval card border: `warning.main` (#f59e0b / #d97706)
- HITL approve button: `success.main` (#22c55e / #16a34a)
- HITL deny button: `error.main` (#ef4444 / #dc2626)
- HITL risk chip: `error.light` background with `error.main` text
- Tool UI icons use domain-semantic colors: email=cyanVibrant, calendar=#FF9800, contacts=purple

## Interaction States to Verify

| State | Expected Behavior |
|-------|-------------------|
| Chat loading | Thread list loads with skeleton or spinner |
| Streaming response | Text appears token-by-token, cursor/indicator visible |
| HITL requires-action | Warning-bordered card with approve/deny buttons appears inline |
| HITL approve busy | Approve button shows spinner, both buttons disabled |
| HITL deny busy | Deny button shows spinner, both buttons disabled |
| Tool result rendering | Structured card with domain-colored icon and formatted data |
| Empty thread list | "No conversations yet" text displayed |
| Empty active thread | Chat empty state with capability cards |
| Chat error | Error message with retry guidance |
| Delete conversation | Confirmation prompt before deletion |
| Mobile layout | Thread list and thread are separate panels (not side-by-side) |
