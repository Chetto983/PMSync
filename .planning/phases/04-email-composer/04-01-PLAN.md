Create a new TipTap extension that registers Cmd+J (Mac) / Ctrl+J (Windows) keyboard shortcut.

Implementation details:
1. Use `Extension.create()` from `@tiptap/core`
2. Define `AiShortcutOptions` interface with `onTriggerAi: () => void` callback
3. Use `addKeyboardShortcuts()` method to register `Mod-j` (TipTap handles Mac/Windows automatically)
4. In the shortcut handler:
   - Call `this.options.onTriggerAi()` to trigger the callback
   - Return `true` to prevent browser default (Chrome uses Ctrl+J for downloads bar)

Reference pattern from RESEARCH.md:
```typescript
import { Extension } from '@tiptap/core';

export interface AiShortcutOptions {
  onTriggerAi: () => void;
}

export const AiShortcutExtension = Extension.create<AiShortcutOptions>({
  name: 'aiShortcut',

  addOptions() {
    return {
      onTriggerAi: () => {},
    };
  },

  addKeyboardShortcuts() {
    return {
      'Mod-j': () => {
        this.options.onTriggerAi();
        return true;
      },
    };
  },
});
```

Keep file small (~25 lines). No dependencies beyond @tiptap/core.

**CRITICAL - Pitfall from RESEARCH.md:**
The existing `handleOpenAiMenu` expects `MouseEvent.currentTarget` for Popover anchor.
Keyboard shortcut has no MouseEvent. Solution: Use ref to AI button element.

Modify handleOpenAiMenu to accept optional `fromKeyboard` flag:
```typescript
const handleOpenAiMenu = useCallback((event?: React.MouseEvent<HTMLElement>, fromKeyboard = false) => {
  const selection = getSelectedHtml();
  const hasSelection = selection && selection.length > 0;

  setSelectedText(selection);
  setIsModifyMode(hasSelection || false);

  // Use ref for keyboard trigger, event.currentTarget for click
  if (fromKeyboard && aiButtonRef.current) {
    setAiMenuAnchor(aiButtonRef.current);
  } else if (event) {
    setAiMenuAnchor(event.currentTarget);
  }
}, [getSelectedHtml]);

const handleOpenAiMenuFromKeyboard = useCallback(() => {
  handleOpenAiMenu(undefined, true);
}, [handleOpenAiMenu]);
```
