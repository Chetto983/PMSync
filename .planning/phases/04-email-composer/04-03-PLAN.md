  <action>
Add responsive fullscreen behavior to ComposeDialog.

**Step 1: Add imports**
```typescript
import useMediaQuery from '@mui/material/useMediaQuery';
import AppBar from '@mui/material/AppBar';
import Toolbar from '@mui/material/Toolbar';
```

**Step 2: Add mobile detection (near top of component)**
```typescript
const theme = useTheme(); // Already imported via useTranslations likely, or add import
const isMobile = useMediaQuery(theme.breakpoints.down('md')); // < 768px
```

Note: Check if `useTheme` is already imported. If not, add: `import { useTheme } from '@mui/material/styles';`

**Step 3: Modify Dialog props**
Change the Dialog component from:
```tsx
<Dialog
  open={open}
  onClose={onClose}
  maxWidth={isFullscreen ? false : 'md'}
  fullWidth
  fullScreen={isFullscreen}
  ...
>
```

To:
```tsx
<Dialog
  open={open}
  onClose={onClose}
  maxWidth={isMobile || isFullscreen ? false : 'md'}
  fullWidth
  fullScreen={isMobile || isFullscreen}
  PaperProps={{
    sx: {
      // iOS safe area handling for mobile fullscreen
      ...(isMobile && {
        paddingTop: 'env(safe-area-inset-top)',
        paddingBottom: 'env(safe-area-inset-bottom)',
        paddingLeft: 'env(safe-area-inset-left)',
        paddingRight: 'env(safe-area-inset-right)',
      }),
      // Existing fullscreen styles
      ...(isMobile || isFullscreen
        ? { display: 'flex', flexDirection: 'column' }
        : {
            height: '80vh',
            maxHeight: 800,
            display: 'flex',
            flexDirection: 'column',
          }),
    },
  }}
>
```

**Step 4: Add mobile-specific header**
Replace existing DialogTitle with conditional rendering:

```tsx
{isMobile ? (
  // Mobile: AppBar with sticky header for thumb reach
  <AppBar
    position="sticky"
    color="default"
    elevation={0}
    sx={{
      borderBottom: 1,
      borderColor: 'divider',
    }}
  >
    <Toolbar sx={{ minHeight: 56 }}>
      <IconButton edge="start" onClick={onClose} aria-label={t.common.close}>
        <CloseIcon />
      </IconButton>
      <Typography variant="h6" sx={{ flex: 1, ml: 1 }}>
        {getTitle()}
      </Typography>
      {/* Save status on mobile */}
      {getSaveStatus() && (
        <Typography variant="caption" color="text.secondary" sx={{ mr: 1 }}>
          {getSaveStatus()}
        </Typography>
      )}
      {/* Send button in header for thumb reach */}
      <Button
        variant="contained"
        size="small"
        onClick={() => handleSend()}
        disabled={!canSend || isSending || isPendingSend}
        startIcon={isSending || isPendingSend ? <CircularProgress size={16} color="inherit" /> : <SendIcon />}
      >
        {isSending || isPendingSend ? composer.sending : t.common.send}
      </Button>
    </Toolbar>
  </AppBar>
) : (
  // Desktop: existing DialogTitle
  <DialogTitle
    sx={{
      display: 'flex',
      alignItems: 'center',
      justifyContent: 'space-between',
      py: 1.5,
    }}
  >
    {getTitle()}
    <Box sx={{ display: 'flex', alignItems: 'center', gap: 1 }}>
      {getSaveStatus() && (
        <Typography variant="caption" color="text.secondary">
          {getSaveStatus()}
        </Typography>
      )}
      <Tooltip title={isFullscreen ? t.common.exitFullscreen : t.common.fullscreen}>
        <IconButton onClick={toggleFullscreen} size="small">
          {isFullscreen ? <CloseFullscreenIcon /> : <OpenInFullIcon />}
        </IconButton>
      </Tooltip>
      <IconButton onClick={onClose} size="small">
        <CloseIcon />
      </IconButton>
    </Box>
  </DialogTitle>
)}
```

**Step 5: Conditionally hide desktop DialogActions on mobile**
The Send button is now in the mobile header, so hide the footer on mobile:

      disabled={!canSend || isSending || isPendingSend}
    >
      {isSending || isPendingSend ? composer.sending : t.common.send}
