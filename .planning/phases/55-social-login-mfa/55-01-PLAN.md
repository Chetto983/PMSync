Add new TwoFactor model (after WebAuthnCredential model):
```prisma
/// better-auth twoFactor plugin table
model TwoFactor {
  id          String  @id @default(cuid())
  secret      String
  backupCodes String
  userId      String
  user        User    @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId])
  @@map("two_factor")
}
```

Add new Passkey model:
```prisma
/// better-auth passkey plugin table
model Passkey {
  id           String   @id @default(cuid())
  name         String?
  publicKey    String
  userId       String
  credentialID String
  counter      Int      @default(0)
  deviceType   String
  backedUp     Boolean  @default(false)
  transports   String?
  aaguid       String?
  createdAt    DateTime @default(now())
  user         User     @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId])
  @@index([credentialID])
  @@map("passkeys")
}
```
