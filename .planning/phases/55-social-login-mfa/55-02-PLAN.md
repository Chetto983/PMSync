**2. Create SecurityMfaSection.tsx:**

Component with three subsections:

**TOTP subsection:**
- Shows status (enabled/disabled) with colored indicator
- If disabled: "Enable TOTP" button -> opens dialog
  - Dialog step 1: password input, submit calls `authClient.twoFactor.enable({ password })`
  - On success: receive `{ totpURI, backupCodes }`
  - Dialog step 2: display QR code (use `import QRCode from 'qrcode'` -> `QRCode.toDataURL(totpURI)` in useEffect)
  - Dialog step 3: 6-digit verification input, submit calls `authClient.twoFactor.verifyTotp({ code })`
  - Dialog step 4: show backup codes with download button + warning
- If enabled: "Disable TOTP" button with password confirmation dialog -> `authClient.twoFactor.disable({ password })`

**Passkeys subsection:**
- List passkeys via `authClient.passkey.listPasskeys()` in useEffect on mount
- Each row: name (editable), deviceType, createdAt, remove button
- "Add Passkey" button (disabled if 5 already) -> `authClient.passkey.addPasskey({ name: autoDetectedName })`
  - Auto-detect name from navigator.userAgent using ua-parser-js: "{browser} on {os}"
- Remove: confirmation dialog -> `authClient.passkey.deletePasskey({ id })`
- Max 5 passkeys per user decision

**Backup codes subsection:**
- Only visible when TOTP is enabled
- "Regenerate Codes" button with confirmation dialog -> `authClient.twoFactor.generateBackupCodes({ password })`
- Shows backup codes in a monospace Box + "Download as .txt" button
- Download creates a Blob with codes joined by newlines, triggers download

MUI components: Card, CardContent, Typography, Button, Dialog, DialogTitle, DialogContent, DialogActions, TextField, Chip, IconButton, Box, Alert, List, ListItem, ListItemText, ListItemSecondaryAction, Divider, Skeleton.
