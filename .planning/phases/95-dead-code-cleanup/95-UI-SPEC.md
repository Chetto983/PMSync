## Phase Classification: NON-VISUAL

Phase 95 is a **pure deletion/cleanup phase**. All 8 requirements (CLN-01 through CLN-08) involve removing dead code, unused exports, stale shims, debug statements, and unused dependencies. No new UI components, pages, or visual changes are introduced.

**Why this contract is minimal:** A design contract specifying spacing, typography, color, and copywriting serves no purpose when the phase only deletes files and removes unused exports. Specifying these values would be fabricated busywork with no downstream consumer benefit.

## Visual Validation Criteria

Since this phase has no visual changes, validation is limited to:

1. **No visual regression:** After all deletions, the application renders identically to pre-phase state
2. **Type-check passes:** `npx tsc --noEmit` succeeds in both frontend and backend after each deletion wave
3. **No broken imports:** Deleted exports are not referenced anywhere in remaining code
4. **i18n completeness:** Any strings moved to locale files render the same text as before
