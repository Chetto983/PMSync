  <action>
Add prefetch behavior when user hovers an email row:

1. Import `useQueryClient` from `@tanstack/react-query`
2. Import `emailThreadOptions` from `@/hooks/queries/use-emails`
3. In the component, get queryClient: `const queryClient = useQueryClient()`
4. Create a debounced prefetch handler (300ms delay to avoid prefetch spam):
   ```typescript
   const prefetchTimeoutRef = useRef<NodeJS.Timeout | null>(null);

   const handleMouseEnter = useCallback(() => {
     onMouseEnter();
     // Debounce prefetch to avoid spam on quick mouse movements
     prefetchTimeoutRef.current = setTimeout(async () => {
       await queryClient.prefetchQuery({
         ...emailThreadOptions(thread.id),
         staleTime: 30 * 1000, // Only prefetch if data older than 30s
       });
     }, 300);
   }, [onMouseEnter, thread.id, queryClient]);

   const handleMouseLeave = useCallback(() => {
     onMouseLeave();
     // Cancel pending prefetch if mouse leaves quickly
     if (prefetchTimeoutRef.current) {
       clearTimeout(prefetchTimeoutRef.current);
       prefetchTimeoutRef.current = null;
     }
   }, [onMouseLeave]);
   ```
5. Update the Box component to use these handlers instead of raw onMouseEnter/onMouseLeave

AVOID: Prefetching on every hover (causes API flood). The 300ms debounce + staleTime check prevents this.
