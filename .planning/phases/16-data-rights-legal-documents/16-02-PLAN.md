<objective>
Implement the GDPR Article 20 data portability export: user requests export, system assembles all their data into a ZIP archive of JSON files, user downloads it.

Purpose: DATA-01 requires users can export all their data in a machine-readable format. This plan creates the export pipeline using the DataExportRequest model from Plan 16-01, the `archiver` npm package for ZIP generation, and NestJS StreamableFile for download.

Output: DataExportService (assemble + ZIP + cleanup), DataExportController (request, status, download endpoints), cleanup cron integration.
</objective>

**2. Create `services/data-export.service.ts`:**

Inject PrismaService, ConfigService, Logger.

**`requestExport(userId, tenantId)`:**
- Check for existing PENDING/PROCESSING export for this user (prevent duplicates). If exists, return existing exportId.
- Create DataExportRequest record with status PENDING.
- Call `this.processExport(exportRequest.id, userId, tenantId)` -- for simplicity, run inline as a fire-and-forget promise (not blocking the response). Log errors if the processing fails.
  - Note: The research suggests BullMQ, but for a single-tenant app with one user, inline async is simpler and avoids adding a new queue. If performance becomes an issue, this can be migrated to BullMQ later. Document this choice.
- Return `{ exportId, status: 'PENDING' }`.

**`processExport(exportId, userId, tenantId)`:**
- Update DataExportRequest status to PROCESSING.
- Call `assembleUserData(userId, tenantId)` to gather all data.
- Call `generateExportZip(exportId, data)` to create the ZIP file.
- Get file size from fs.stat.
- Update DataExportRequest with status READY, filePath, fileSize, expiresAt (now + 72 hours), completedAt.
- On error: update status to FAILED with error message.

**`assembleUserData(userId, tenantId)`:**
Follow the research code example exactly. Use `Promise.all` to query in parallel:
- `prisma.user.findUnique` with select (EXCLUDE: passwordHash, deletedAt, internal IDs)
- `prisma.userPreferences.findUnique` with select (theme, language, timezone, etc.)
- `prisma.email.findMany` where tenantId, select (subject, from, to, cc, bcc, textBody, receivedAt, sentAt, isRead, isStarred, isDraft -- EXCLUDE: externalId, providerId, htmlBody to reduce size)
  - Take limit: 50000
- `prisma.contact.findMany` where tenantId, select (displayName, emails, phoneNumbers, company, jobTitle, department, notes, tags, birthday, addresses)
- `prisma.calendarEvent.findMany` where tenantId, select (title, description, startTime, endTime, location, isAllDay, recurrence, attendees)
- `prisma.aIMemory.findMany` where tenantId, select (key, value, category, createdAt)
- `prisma.userConsent.findMany` where userId and tenantId, select (feature, granted, version, createdAt)
- `prisma.auditLog.findMany` where userId and tenantId, select (action, entity, entityId, createdAt), take 10000

Return typed `ExportData` object.

**`generateExportZip(exportId, data)`:**
- Create export directory: `path.join(process.cwd(), 'tmp', 'exports')` using `fs.mkdir(dir, { recursive: true })`
- Use `archiver('zip', { zlib: { level: 6 } })` piped to `createWriteStream`
- Append each data category as separate JSON file (profile.json, preferences.json, emails.json, contacts.json, calendar-events.json, ai-history.json, consent-history.json, audit-logs.json)
- Append metadata.json with exportDate, format ('GDPR Article 20 Data Portability Export'), application ('PMSync'), version ('1.0')
- `await archive.finalize()` and return filePath via output.on('close') promise
- Handle archive.on('error') with reject

**`getExportStatus(exportId, userId)`:**
- Query DataExportRequest by id and userId (security: user can only see their own)
- Return status, fileSize, expiresAt, createdAt

**`getExportFilePath(exportId, userId)`:**
- Query DataExportRequest by id and userId, verify status is READY and not expired
- Throw NotFoundException if not found or not ready
- Throw GoneException if expired
- Return filePath

**`listExports(userId, tenantId)`:**
- Return recent exports for this user (last 10, ordered by createdAt desc)

**`cleanupExpiredExports()`:**
- Find all DataExportRequest where status = READY and expiresAt < now
- For each: delete file from disk (fs.unlink, ignore ENOENT), update status to EXPIRED
- Also find and clean FAILED exports older than 24 hours

**1. Create `controllers/data-export.controller.ts`:**

  - Return `new StreamableFile(stream)` (import from `@nestjs/common`)
