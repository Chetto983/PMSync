**RACE-4:**
Find `persistToolResults` (or whatever method saves tool results in the `onStepFinish` callback). Currently it calls `saveToolMessage` in a loop, each creating its own transaction. Refactor to:
1. Use a single `this.prisma.$transaction()` (or via `withPrismaRetry` since RACE-1 established the pattern) that creates all tool messages and touches the conversation once.
2. Pattern from RESEARCH.md:
```typescript
await withPrismaRetry(async () => {
  await this.prisma.$transaction(async (tx) => {
    for (const toolResult of toolResults) {
      await tx.aiMessage.create({ data: { conversationId, role: 'tool', content: ..., toolCallId: ..., stepIndex } });
    }
    await tx.aiConversation.update({ where: { id: conversationId }, data: { updatedAt: new Date() } });
  });
}, { loggerName: 'AiChatService.persistToolResults' });
```
3. If `persistToolResults` is in conversation.service.ts instead of ai-chat.service.ts, edit that file instead. Check both.
