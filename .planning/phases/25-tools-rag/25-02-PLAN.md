**IntentRouterService** (intent-router.service.ts, ~200 lines):

1. `@Injectable()` class injecting `IntentClassifierService` and `MistralProviderService`
2. Define `INTENT_TOOL_MAP: Record<PrimaryIntent, string[]>` mapping each intent to 6-8 relevant tool names:
   - `email_search` -> ['search_emails', 'semantic_search', 'read_email']
   - `email_compose` -> ['draft_email', 'send_email', 'search_contacts']
   - `email_reply` -> ['read_email', 'reply_email', 'search_emails']
   - `email_forward` -> ['read_email', 'forward_email', 'search_contacts']
   - `email_delete` -> ['search_emails', 'read_email', 'delete_email']
   - `email_archive` -> ['search_emails', 'archive_email']
   - `email_move` -> ['search_emails', 'move_email', 'list_folders']
   - `email_read` -> ['read_email', 'search_emails', 'semantic_search']
   - `email_summarize` -> ['search_emails', 'read_email', 'semantic_search']
   - `calendar_view` -> ['view_calendar', 'search_contacts']
   - `calendar_create` -> ['create_event', 'view_calendar', 'search_contacts']
   - `calendar_update` -> ['update_event', 'view_calendar']
   - `calendar_delete` -> ['delete_event', 'view_calendar']
   - `contact_search` -> ['search_contacts', 'semantic_search']
   - `contact_create` -> ['create_contact']
   - `contact_update` -> ['search_contacts', 'update_contact']
   - `folder_list` -> ['list_folders']
   - `folder_create` -> ['create_folder', 'list_folders']
   - `greeting/farewell/thanks/help/settings_view` -> [] (no tools, LLM responds directly)
   - `status_check` -> ['search_emails', 'view_calendar']
   - `unknown` -> ['search_emails', 'semantic_search', 'view_calendar'] (fallback set)
3. Method `classifyAndRoute(message: string): Promise<{ intent: PrimaryIntent, confidence: number, activeTools: string[] }>`:
   - Call `this.intentClassifier.classify(message)` to get `{ intent, confidence }`
   - If `confidence >= 0.5`: return `{ intent, confidence, activeTools: INTENT_TOOL_MAP[intent] }`
   - If `confidence < 0.5`: Use Ministral 3B LLM fallback via `generateText()`:
     - Model: `this.mistralProvider.getChatModel('mistral-small-latest')` (cheapest model available)
     - System prompt: "Classify the user's intent into ONE of these categories: email_search, email_compose, email_reply, ... Return ONLY the category name."
     - Parse LLM response, match to PrimaryIntent, return mapped tools
     - If LLM response doesn't match any intent, default to 'unknown'
4. Method `expandForFollowUp(lastToolCalls: Array<{ toolName: string }>, allToolNames: string[]): string[]`:
   - After a search tool: add read/reply/forward tools
   - After a read tool: add reply/forward/archive/delete tools
   - After a create tool: add the matching view/search tool
   - Return union of current active + expanded, filtered to `allToolNames`
5. Confidence threshold: 0.5 (configurable via private constant)

**MemoryService** (memory.service.ts, ~150 lines):

1. `@Injectable()` class injecting `PrismaService` and `MistralProviderService`
2. Method `getRelevantMemories(tenantId: string, userId: string, query: string, limit: number = 3): Promise<Array<{ content: string; category: string | null; createdAt: Date }>>`:
   - Generate embedding for query via `embed()` from 'ai' package using `MistralProviderService.getEmbeddingModel()`
   - Execute raw SQL: `SELECT content, category, "createdAt" FROM ai_memories WHERE "tenantId" = $1 AND "userId" = $2 AND (vector <-> $3::vector) < 0.5 ORDER BY (vector <-> $3::vector) ASC LIMIT $4`
   - Return results array
   - On error (e.g., no embeddings, pgvector unavailable), log warning and return empty array -- never block chat
3. Method `formatMemoriesForPrompt(memories: Array<{ content: string; category: string | null; createdAt: Date }>): string`:
   - Return formatted block: `## Known Facts About This User\n- [category] content (saved DATE)\n...`
   - If no memories, return empty string

   const allTools = this.createToolSet(tenantId, conversation.id);
   const allToolNames = Object.keys(allTools);

   // Inside streamText config:
   prepareStep: async ({ stepNumber, steps }) => {
     if (stepNumber === 0) {
       const classification = await this.intentRouterService.classifyAndRoute(message);
       this.logger.debug(`Intent: ${classification.intent} (${classification.confidence}), tools: ${classification.activeTools.join(', ')}`);

     // Subsequent steps: expand based on what tools were just called
     const lastStep = steps[steps.length - 1];
     const lastToolCalls = lastStep?.toolCalls ?? [];

     return { activeTools: expanded };
   },
