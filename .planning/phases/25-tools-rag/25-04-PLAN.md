This is the E2E validation gate for Phase 25. Pattern mirrors Phase 24's `24-03-PLAN.md` E2E tests.

**Test setup:**
- Use `Test.createTestingModule()` from `@nestjs/testing` to wire the full `AiChatModule` (includes all ToolsService classes, IntentRouterService, MemoryService, HybridSearchService)
- Import `dotenv/config` for MISTRAL_API_KEY and POSTGRES_URL
- Create a test Tenant and User record (reuse from Phase 24 test fixtures if available, or create fresh)
- Clean up created conversations/messages/memories after each test
- All tests use 60s timeout for real LLM calls

**Test 1: "tool execution -- search emails query triggers search_emails tool and returns results"** (AI-02)
- Call `aiChatService.streamChat({ tenantId, userId, message: 'Search my emails from last week about invoices' })`
- Read the streaming response to completion
- Use `vi.spyOn()` on `IntentRouterService.classifyAndRoute` to capture the classification result
- Verify intent is `email_search` or similar email intent
- Verify `activeTools` array contains `search_emails` (and NOT all 20 tools)
- Verify the stream produced a response (not empty)
- Timeout: 60s

**Test 2: "intent routing gates tools correctly -- calendar query activates calendar tools"** (AI-03)
- Spy on `IntentRouterService.classifyAndRoute`
- Call `streamChat` with message "What meetings do I have tomorrow?"
- Verify classification returned a calendar-related intent
- Verify `activeTools` contains `view_calendar` and does NOT contain email-specific tools like `send_email`, `draft_email`
- Verify the number of activeTools is <= 8 (not all 20)
- Timeout: 60s

**Test 3: "hybrid search -- semantic_search tool uses HybridSearchService"** (RAG-01, RAG-02)
- Spy on `HybridSearchService.search`
- Call `streamChat` with message "Find information about project deadlines in my emails and contacts"
- This should trigger the `semantic_search` tool via intent routing
- Verify `HybridSearchService.search` was called at least once (spy was invoked)
- Verify the call received correct tenantId
- If the hybrid search SQL functions are not yet applied to the database, the service should degrade gracefully (no crash)
- Timeout: 60s

**Test 4: "memory auto-injection -- relevant memories injected into system prompt"** (AI-02)
- First, seed a test memory: insert a row into `ai_memories` table with `tenantId`, `userId`, a vector embedding (generate via MistralProviderService.getEmbeddingModel()), and content "User prefers concise responses and works at Acme Corp"
- Spy on `MemoryService.getRelevantMemories`
- Call `streamChat` with message "What do you know about me?"
- Verify `MemoryService.getRelevantMemories` was called with correct tenantId and userId
- Verify the spy returned at least 1 memory (the seeded one)
- Clean up: delete the seeded memory after test
- Timeout: 60s

**Test 5: "no regressions -- Phase 24 pipeline still works (conversation persistence)"**
- Call `streamChat` with a simple message (no tool call expected): "Say hello"
- Verify streaming response completes
- Verify conversation was persisted in Prisma (AiConversation + AiMessage records exist)
- Timeout: 30s
