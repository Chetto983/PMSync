**EmailToolsService** (email-tools.service.ts, ~400 lines):
- Inject: `EmailSearchService`, `EmailCrudService`, `EmailSendService`, `EmailBulkService`, `EmailFetchService`, `PrismaService`
- 9 tools: `send_email` (needsApproval: true), `search_emails`, `read_email`, `archive_email`, `move_email`, `delete_email` (needsApproval: true), `forward_email` (needsApproval: true), `reply_email` (needsApproval: true), `draft_email`
- `send_email`: Look up user's default provider via `prisma.providerConfig.findFirst({ where: { tenantId, type: { in: ['GMAIL', 'MICROSOFT', 'IMAP'] }, enabled: true } })`. Call `EmailSendService.queueSend()` with resolved args.
- `search_emails`: Call `EmailSearchService.searchEmails(tenantId, query, undefined, limit)`. Return `{ results: [{id, from, subject, date, snippet, labels}], count }`.
- `read_email`: Use `EmailFetchService` or `prisma.email.findFirst({ where: { id, tenantId } })` to load full email. Return `{ id, from, to, subject, date, bodyText (truncated 2000 chars), snippet, labels, triageSummary, sentiment }`.
- `archive_email`: Call `EmailCrudService.updateEmail(tenantId, id, { isArchived: true })`. Return `{ id, archived: true }`.
- `move_email`: Call `EmailCrudService.updateEmail(tenantId, id, { folderId })`. Return `{ id, movedTo: folder }`.
- `delete_email`: Call `EmailCrudService.deleteEmail(tenantId, id)`. Return `{ id, deleted: true }`.
- `forward_email`: Call `EmailSendService.queueSend()` with resolved args. needsApproval checks if recipient is external.
- `reply_email`: Load original email, call `EmailSendService.queueSend()`. needsApproval: true.
- `draft_email`: Call `EmailSendService.queueSend()` with `isDraft: true`. No needsApproval (internal-only, not sent). Return `{ id, draftId, subject, to }`.

**CalendarToolsService** (calendar-tools.service.ts, ~250 lines):
- Inject: `CalendarEventsService`, `PrismaService`
- 4 tools: `view_calendar`, `create_event`, `update_event`, `delete_event` (needsApproval: true)
- `view_calendar`: Query events by date range via `CalendarEventsService` or Prisma. Input: `{ startDate?: string, endDate?: string, limit?: number }`. Return `{ events: [{id, title, start, end, location, attendees, calendarName}] }`.
- `create_event`: Input `{ title, startDate, endDate, description?, location?, attendees?: string[] }`. Return full created event.
- `update_event`: Input `{ eventId, title?, startDate?, endDate?, description?, location? }`. Return updated event.
- `delete_event`: Input `{ eventId }`. Return `{ id, deleted: true }`.
- Datetime handling: Accept ISO 8601 strings in tool input. Server-side parsing with `new Date()`.

**ContactToolsService** (contact-tools.service.ts, ~200 lines):
- Inject: `ContactsService`, `PrismaService`
- 3 tools: `search_contacts`, `create_contact`, `update_contact`
- `search_contacts`: Query contacts by name/email. Return `{ contacts: [{id, name, email, company, jobTitle, phoneNumbers}], count }`.
- `create_contact`: Input `{ name, email, company?, jobTitle?, phoneNumbers?: string[] }`. Return created contact.
- `update_contact`: Input `{ contactId, name?, email?, company?, jobTitle? }`. Return updated contact.

**FolderToolsService** (folder-tools.service.ts, ~100 lines):
- Inject: `EmailFolderService` (from email module), `PrismaService`
- 2 tools: `list_folders`, `create_folder`
- `list_folders`: Query folders for tenant. Return `{ folders: [{id, name, type, unreadCount}] }`.
- `create_folder`: Input `{ name, parentId? }`. Return created folder.

**RagToolsService** (rag-tools.service.ts, ~250 lines):
- Inject: `EmbeddingsService`, `KnowledgeBaseService`, `MistralProviderService`, `PrismaService`
- 2 tools: `semantic_search`, `save_memory`
- `semantic_search`: Single unified tool. Input `{ query: string, sources?: ('emails'|'contacts'|'calendar')[], limit?: number }`. Generate embedding for query via `MistralProviderService.getEmbeddingModel()` + `embed()`. Call `EmbeddingsService.findSimilarContent()` filtered by source type. Return `{ results: [{source, id, title, snippet, relevanceScore}], count }`.
- `save_memory`: Input `{ content: string, category?: string, tags?: string }`. Insert into `AIMemory` table via Prisma with vector embedding. Return `{ id, content, category, savedAt }`.
