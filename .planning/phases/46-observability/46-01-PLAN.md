5. Mark as `@Global()` so metric tokens are injectable everywhere without importing MetricsModule in each consumer module

   - Implement NestInterceptor
   - Inject `http_request_duration_seconds` Histogram via `@InjectMetric('http_request_duration_seconds')`
   - Inject `http_requests_in_flight` Gauge via `@InjectMetric('http_requests_in_flight')`
   - In `intercept()`:
     - Get method from `req.method`
     - Inc in-flight gauge `{ method }`
     - Start timer via `this.duration.startTimer({ method })`
     - Use `tap({ next, error })` on the Observable:
       - On next: get `route = req.route?.path || 'unmatched'`, end timer with `{ route, status_code: res.statusCode }`, dec in-flight
       - On error: get route same way, end timer with `{ route, status_code: error?.status || 500 }`, dec in-flight
   - Use `finalize()` operator as safety net to dec in-flight if tap doesn't fire (stream cancellation)
