**3. Add P2034 retry handling to sync services:**

Check if `backend/src/common/services/prisma-retry.service.ts` exists. If not, create it:
```typescript
export async function withPrismaRetry<T>(
  operation: () => Promise<T>,
  maxRetries = 3,
): Promise<T> {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await operation();
    } catch (error) {
      if (error?.code === 'P2034' || error?.code === 'P2002') {
        const delay = Math.min(100 * Math.pow(2, attempt), 2000);
        await new Promise(r => setTimeout(r, delay));
        continue;
      }
      throw error;
    }
  }
  throw new Error('Max retries exceeded for Prisma operation');
}
```

Wrap critical sync operations (upserts, batch creates) in `withPrismaRetry()`. Focus on `folder-sync.service.ts` and `base-email-sync.service.ts` where P2002/P2034 are most likely.
