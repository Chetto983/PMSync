**Test structure:**

Use `test.describe.serial` for the ban/unban block to prevent parallel execution:

```typescript
import { test, expect } from '@playwright/test';

const MEMBER_EMAIL = process.env.E2E_MEMBER_EMAIL ?? 'member@pmsync.local';
const MEMBER_PASSWORD = process.env.E2E_MEMBER_PASSWORD ?? 'MemberPassword123!';

test.describe('Admin panel — user management', () => {
  test('navigate to admin and view user list', async ({ page }) => { ... });
  test('search users by email', async ({ page }) => { ... });
  test('impersonate a user', async ({ page }) => { ... });
  test('view and revoke a user session', async ({ page }) => { ... });
});

test.describe.serial('Admin panel — ban/unban', () => {
  test.afterAll(async ({ browser }) => {
    // Unban member@pmsync.local with try/finally
  });

  test('ban member user', async ({ page }) => { ... });
  test('verify banned user cannot log in', async ({ browser }) => { ... });
  test('unban member user', async ({ page }) => { ... });
});
```

**Test: navigate to admin and view user list:**
- `page.goto('/dashboard/admin/users')`
- Assert the page title or heading contains "Users" or "Admin"
- Assert the user table is visible (not "Access denied")
- Assert `member@pmsync.local` appears in the table

**Test: search users by email:**
- On `/dashboard/admin/users`, find the search input
- Type `'member@'` into the search field
- Assert only rows containing "member" appear
- Assert `admin@pmsync.local` is NOT visible after filtering

**Test: impersonate a user:**
- On `/dashboard/admin/users`, find the impersonate button for `member@pmsync.local`
- Register dialog handler BEFORE clicking: `page.on('dialog', d => d.accept())`
- Click the impersonate action button/icon
- Wait for page to settle after reload
- Assert `ImpersonationBanner` is visible (e.g., `page.locator('[data-testid="impersonation-banner"]')` or look for text "You are impersonating")
- Find and click "Stop impersonating" button
- Assert ImpersonationBanner is no longer visible
- Assert page navigated back to admin context (admin email visible again)

**Test: view and revoke a user session:**
- On `/dashboard/admin/users`, find the "Sessions" icon/button for `member@pmsync.local`
- Click to open `UserSessionsDialog`
- Assert at least one session row is visible
- Click "Revoke" on one session
- Assert the revoked session disappears from the list or a success message appears
- Close the dialog

**Test: ban member user (serial):**
- On `/dashboard/admin/users`, find the ban button/icon for `member@pmsync.local`
- Click to open `BanUserDialog`
- Confirm the ban (click "Ban" or "Confirm")
- Assert success toast or the user row shows "Banned" status

**Test: verify banned user cannot log in (serial):**
- Open a fresh unauthenticated browser context: `const bannedCtx = await browser.newContext()`
- `const bannedPage = await bannedCtx.newPage()`
- Navigate to `/auth/login`
- Fill email: `MEMBER_EMAIL`, password: `MEMBER_PASSWORD`
- Click submit
- Assert: either an error `[role="alert"]` is visible, or the page does NOT redirect to `/dashboard`
  (i.e., login fails because user is banned)
- `await bannedCtx.close()`

**Test: unban member user (serial):**
- On `/dashboard/admin/users`, find the unban action for `member@pmsync.local`
- Click to unban
- Assert the user row no longer shows "Banned" status

**afterAll (serial block — try/finally):**
- Open admin context
- Navigate to `/dashboard/admin/users`
- Find member@pmsync.local and unban if still banned
- Close context
- Wrap entire body in try/finally so cleanup never throws

**Important notes:**
- The serial describe block's `afterAll` receives `{ browser }` in newer Playwright — check the Playwright version's afterAll signature. In Playwright 1.58, `test.afterAll` can take a fixture-like callback.
- When asserting the ban prevents login, use `await expect(bannedPage.locator('[role="alert"]')).toBeVisible({ timeout: 10000 })` with generous timeout.
- The `page.on('dialog')` handler must be registered before the action that triggers the confirm dialog — register it at the start of the impersonate test.
