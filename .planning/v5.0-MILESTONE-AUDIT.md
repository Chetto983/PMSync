## Integration Check Results

### Broken Flows

**1. Invited user accepts via email link (ORG-02)**

- Backend sends invitation email with link to `${frontendUrl}/dashboard/invitations/accept?id=...`
- No Next.js page exists at `frontend/pages/dashboard/invitations/accept.tsx`
- User following email link hits middleware redirect → `/auth/login` → `/dashboard` (losing `?id=` param)
- **Workaround:** `PendingInvitationBanner` in Layout handles in-app acceptance for authenticated users
- **Fix:** Create `frontend/pages/dashboard/invitations/accept.tsx` that reads `?id=` and calls `authClient.organization.acceptInvitation`

**2. User switches org → WS delivers events from new org (ORG-04, P62-04)**

- `OrgSwitcher` calls `setActive` → session updated → TanStack caches invalidated → HTTP requests use new tenantId
- WebSocket client is NOT reconnected after org switch
- WS room assignment is set at handshake time; stays in old tenant room
- Real-time events for new org don't arrive until page refresh
- **Fix:** `useSetActiveOrg.onSuccess` should trigger `websocketClient.disconnect()` + `websocketClient.connect()`

### Connected Flows (Verified)

1. **New user signup → verify → onboard → dashboard** — COMPLETE
2. **OAuth login → auto-connect provider → dashboard** — COMPLETE
3. **Admin bans user → banned user blocked** — COMPLETE
4. **GDPR erasure → org membership cleaned** — COMPLETE
