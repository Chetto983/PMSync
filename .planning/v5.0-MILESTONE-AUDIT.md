## Critical Gaps

### GAP 1: FEUI-04 — Server-side Route Protection is Dead Code

**Severity:** Critical
**Root Cause:** `frontend/proxy.ts` must be named `frontend/middleware.ts` for Next.js to invoke it.

The file contains correct logic for:
- Redirecting unauthenticated users from `/dashboard/*` to `/auth/login`
- Redirecting authenticated users from `/auth/login` to `/dashboard`
- Redirecting non-onboarded users from `/dashboard` to `/onboarding`
- Exempting `/dashboard/invitations/accept` from onboarding redirect
- Preserving `?id=` query params in `returnTo`

**None of this executes.** Next.js middleware requires the file to be named `middleware.ts`.

**Fix:** Rename `frontend/proxy.ts` to `frontend/middleware.ts` and rename the exported function from `proxy` to `middleware`.

### GAP 2: FEUI-01 — Requirement Text Mismatch

**Severity:** High (requirement accuracy, not functionality)
**Root Cause:** Post-verification regression. Commit `1a21c0bd` removed `@daveyplate/better-auth-ui` and recreated auth pages with custom MUI components.

Auth pages are **functional** — users can sign up, sign in, reset passwords. The requirement text says "better-auth-ui components" which no longer matches.

**Fix:** Update FEUI-01 requirement text to "User sees login/signup pages with custom MUI auth forms" to match actual implementation.

### GAP 3: P62-06 — Playwright E2E Specs Missing (Partial)

**Severity:** Low
**Root Cause:** Marked as optional in validation plan. Backend + frontend unit tests exist.
