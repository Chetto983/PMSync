## Cross-Phase Integration Findings

### Blockers

1. **Phase 72 not started** — MUI-01 through MUI-04 have no implementation. This is the only remaining phase in v5.1.

2. **Phase 71 E2E never run** — All four E2E specs (organizations, admin, onboarding, security) were written but never executed against a real backend. Plan 71-06 (gap closure) has no summary. FE2E-01 through FE2E-04 are satisfied at artifact level only.

### Warnings

3. **BINT-03 contract tests non-functional** — `openapi-spec.json` does not exist in the repo. All 67 contract test assertions gracefully skip. Generation requires manual `npx ts-node scripts/generate-openapi.ts` — no automated hook.

4. **FE2E-04 passkey Chromium-only** — `security.spec.ts` CDP virtual authenticator only works in Chromium. No `test.skip` annotation for non-Chromium projects. Will fail on firefox, webkit, mobile-chrome, mobile-safari.

5. **Onboarding E2E non-repeatable** — `onboarding.spec.ts` requires `prisma db seed` before each run. No automation in CI to re-seed.

6. **Parallel FK race condition** — Subscription specs call `cleanupTestData()` (global TRUNCATE) while calendar specs use targeted `deleteMany`. Could cause intermittent failures in parallel Jest execution.

7. **Dead code in fixtures.ts** — `authedPage`, `mockEmails`, `mockFolders`, `mockUser` are orphaned exports never imported by any E2E spec.
