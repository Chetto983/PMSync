## Integration Issues

### INT-01: HITL Approval Routing Implicit (Medium)
**Affected:** BAPI-14, FE-06
HITL approval cards only surface when a tool call falls through to `FallbackToolRenderer` (tool name not in `TOOL_RENDERERS` registry). High-risk tools like `send_email` are currently unregistered, so this works. But adding any destructive tool to `TOOL_RENDERERS` would silently bypass HITL approval.
**Recommendation:** Add explicit HITL check in `ToolDispatcher` before checking `TOOL_RENDERERS`.

### INT-02: Provider Connect → Sync (Informational)
**Affected:** BAPI-09
After OAuth provider connection, sync is triggered by the backend event pipeline, not by the frontend. The frontend shows no explicit sync-in-progress indicator after connect. This is by design.
