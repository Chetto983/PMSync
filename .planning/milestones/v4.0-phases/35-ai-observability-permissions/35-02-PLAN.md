  <action>
    1. Create `backend/src/modules/ai/dto/ai-runs-query.dto.ts`:
       - `AiRunsQueryDto` class with class-validator decorators:
         - `page?: number` (@IsOptional, @IsInt, @Min(1), @Type(() => Number)) default 1
         - `limit?: number` (@IsOptional, @IsInt, @Min(1), @Max(100), @Type(() => Number)) default 20
         - `startDate?: string` (@IsOptional, @IsDateString)
         - `endDate?: string` (@IsOptional, @IsDateString)
         - `runType?: string` (@IsOptional, @IsString)
       - Add @nestjs/swagger decorators (@ApiPropertyOptional) for OpenAPI generation

    2. Create `backend/src/modules/ai/controllers/ai-observability.controller.ts`:
       - `@Controller('ai')` (no manual prefix -- `api/v1` is global from Phase 33)
       - `@UseGuards(JwtAuthGuard, TenantGuard)` at class level
       - `@ApiTags('AI Observability')` for OpenAPI grouping
       - Inject `PrismaService` directly (thin controller, no separate query service needed for 2 endpoints)

       **GET /ai/runs**:
       - `@Get('runs')` with `@ApiOperation({ summary: 'List AI run records' })`
       - Accepts `@Query() query: AiRunsQueryDto` and `@Req() req: AuthenticatedRequest`
       - Builds Prisma `where` clause: `{ tenantId: req.user.tenantId }`, conditionally adds `createdAt: { gte, lte }` from startDate/endDate, `runType` filter
       - Runs `Promise.all([prisma.aiRunLedger.findMany({ where, orderBy: { createdAt: 'desc' }, skip, take }), prisma.aiRunLedger.count({ where })])`
       - Returns `{ items, total, page, limit }` (ResponseEnvelopeInterceptor wraps in `{ data, meta }`)

       **GET /ai/runs/cost-summary**:
       - `@Get('runs/cost-summary')` with `@ApiOperation({ summary: 'Aggregate AI run cost summary' })`
       - Accepts same date filters via `@Query()` (reuse AiRunsQueryDto, page/limit ignored)
       - Uses `prisma.aiRunLedger.aggregate({ where, _sum: { estimatedCostUsd, promptTokens, completionTokens, totalTokens }, _count: true })`
       - Returns `{ totalCost: _sum.estimatedCostUsd, totalPromptTokens, totalCompletionTokens, totalTokens, runCount: _count }`

    3. Create test file `backend/src/modules/ai/__tests__/ai-observability.controller.test.ts`:

       - Instantiate controller directly (not full NestJS testing module -- unit test)
       - Test all 6 behaviors listed above
       - For auth rejection tests, verify the @UseGuards metadata is applied (reflect metadata check)

    4. Register `AiObservabilityController` in `backend/src/modules/ai/ai.module.ts`:
