### E2E Flows Verified (7/7)

1. **First visit → SW install → precache** (100): User visits → SW registers → static assets cached
2. **Go offline → see fallback page** (100, 101): Network drops → uncached route → branded offline.html
3. **Go offline → see banner → go online → banner disappears** (101): Collapse animation with WifiOff icon
4. **Install app from prompt** (102): beforeinstallprompt → Snackbar → native dialog
5. **Read emails offline after cold restart** (103): Emails persisted in IndexedDB → readable on cold start
6. **Perform actions offline → auto-replay** (104): Queue in IndexedDB → replay on reconnect → toast notifications
7. **Sign out → all offline data cleared** (103, 104, 105): IndexedDB + SW caches + push sub cleared

### Integration Observations (non-blocking)

- **web-push package dead weight:** `web-push@^3.6.7` is in backend `package.json` but never imported. Push dispatch is explicitly deferred to v9+. Package should be removed or moved to a future milestone branch.
- **VAPID env var unvalidated:** `NEXT_PUBLIC_VAPID_KEY` not checked at build time. Absent key causes silent subscription failure (graceful but invisible). Recommend adding to env validation for v9.
