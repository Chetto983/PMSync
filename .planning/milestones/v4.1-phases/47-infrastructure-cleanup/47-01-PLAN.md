   - Extend `IoAdapter` from `@nestjs/platform-socket.io`
   - `connectToRedis()`: create ioredis pub client using `getRedisConnectionOptions()` with `connectionName: 'ws-pub'`, create sub client via `pubClient.duplicate({ connectionName: 'ws-sub' })`. Store `adapterConstructor = createAdapter(pubClient, subClient)`.

   - Export `RedisIoAdapter` class.

   - Import `RedisIoAdapter` from `./common/adapters/redis-io.adapter`
   - BEFORE `app.listen()`, add:
     ```typescript
     const redisIoAdapter = new RedisIoAdapter(app);
     await redisIoAdapter.connectToRedis();
     app.useWebSocketAdapter(redisIoAdapter);
     ```

4. Update `backend/src/modules/realtime/gateways/realtime.gateway.ts`:
   - Remove `'polling'` from `transports` array in `@WebSocketGateway` decorator (keep only `'websocket'`).
   - Replace `private activeTenantConnections = new Map<string, number>()` with injected Redis client.
   - Add constructor parameter: inject Redis via `@Inject('REDIS_CLIENT')` or create a new ioredis instance using `getRedisConnectionOptions()`. Use the same approach as BullMQ -- import `getRedisConnectionOptions` and create a dedicated client in constructor with `connectionName: 'ws-counter'`.
   - Key pattern: `ws:tenant:${tenantId}:conns`
   - `handleConnection`: replace `Map.set` with `await redis.incr(key)`
   - `handleDisconnect`: replace `Map.delete/set` with `const count = await redis.decr(key); if (count <= 0) await redis.del(key);`
   - `hasTenantConnections`: replace `Map.get` with `const count = await redis.get(key); return parseInt(count || '0', 10) > 0;`
   - Import `Redis` from `ioredis` and `getRedisConnectionOptions` from config.
   - Add `onModuleDestroy`: disconnect the Redis counter client.

Setup:
- Create 2 HTTP servers on random ports (0).
- Create 2 Socket.IO servers, each with `createAdapter(pub, sub)` using same Redis.
- Use `transports: ['websocket']` on both client and server.

Test cases:
1. "message emitted on server A is received by client connected to server B":
   - Client connects to server B, listens for 'test-event'.
   - Server A emits 'test-event' to the room the client joined.
   - Assert client receives the event within 2 seconds.

2. "tenant-scoped room isolation":
   - Client A joins room `tenant:t1:updates`, client B joins room `tenant:t2:updates`.
   - Server emits to room `tenant:t1:updates`.
   - Assert client A receives, client B does NOT receive.

Teardown: close all clients, servers, Redis connections.

Mark test with `@jest/globals` describe block. Use `jest.setTimeout(10000)` for Redis connection time.

IMPORTANT: Skip test gracefully if Redis is not available (catch ECONNREFUSED in beforeAll, call `test.skip`).
