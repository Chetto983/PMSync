**Step 1: Find Outlook provider**
From syncStatus, find provider with `providerType === 'microsoft'` or `providerType === 'outlook'`. If none found, return skipped result.

**Step 2: Trigger full sync (skip in quick mode)**
Same pattern as Gmail: POST `/api/v1/email-sync/sync/{providerId}`, then waitForSyncCompletion.

**Step 3: Folder validation**
- GET `/api/v1/folders?providerId={providerId}`
- Check system folders present via `specialUse`: at minimum `INBOX`, `SENT`, `DRAFTS`, `TRASH` (Microsoft maps wellKnownName: inbox, sentitems, drafts, deleteditems)
- Microsoft may also have `JUNK` (junkemail). Check it exists but don't fail if absent.
- Verify each folder has non-empty `name` and non-null `externalId`
- Check folder hierarchy: verify parentId references are valid

**Step 4: Email count validation**
- GET `/api/v1/emails?providerId={providerId}&folder=INBOX&limit=1` -- check pagination total
- Verify count > 0 and <= 2500 (budget)
- Verify INBOX has emails

**Step 5: Email field spot-check (5 emails)**
- GET `/api/v1/emails?providerId={providerId}&folder=INBOX&limit=5`
- For each email verify: subject non-empty, from contains "@", to is array with >= 1, receivedAt is valid date, externalId non-empty
- GET single email by ID, verify bodyHtml or bodyText present
- NOTE: Outlook emails do NOT have `labels` array (that's Gmail-specific). Skip labels check.

**Step 6: Dedup check**
Same as Gmail: fetch 100 emails, verify unique externalId count matches array length.

**Step 7: Report**
Return `{ name: 'Outlook', checks, passed, failed, failures }`.
