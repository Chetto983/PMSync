Phase 117 is a **backend API validation phase** with no frontend UI surface. Per REQUIREMENTS.md:

> "Frontend UI testing is OUT OF SCOPE — Focus is backend API + provider integration"

### What This Phase Does

- Runs validation scripts against `POST /api/v1/emails/send`, `POST /api/v1/emails/:id/reply`, `POST /api/v1/emails/:id/forward`
- Validates email delivery across Gmail, Outlook, and IMAP/SMTP providers
- Fixes the confirmed forward-attachments bug in `EmailSendService.forwardEmail()`
- Verifies threading headers (In-Reply-To, References) on replies
- All work is backend Node.js scripts + NestJS service code
