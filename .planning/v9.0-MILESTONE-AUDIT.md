### Partial Connection (1/19)

**GRAG-04: `getMemoriesByEntity()` orphaned from proactive assembly**

`MemoryService.getMemoriesByEntity()` exists, is unit-tested (7 tests), and correctly queries by `contactId`/`emailId` FK. However, the proactive context assembly path in `ai-chat.service.ts` (lines 254-291) never calls it. After `entityGraphService.traverse()` returns nodes with contact/email entity IDs, there is no code to fetch FK-anchored memories for those entities. The 20% memory budget in `ContextAssemblyService.assemble()` is filled solely from vector similarity search.

**Fix:** After `entityGraphService.traverse()` returns results, extract entity IDs from nodes where `nodeType === 'contact'` or `nodeType === 'email'`, call `memoryService.getMemoriesByEntity()` for each, and merge with vector-search memories before passing to `contextAssemblyService.assemble()`.
