## Scope

Phase 10 establishes the user-facing teaching layer for triage:

- first-run triage onboarding
- label taxonomy review
- natural-language `aiPrompt` authoring
- customer domains, project keywords, and follow-up timing defaults

## Sprints

- `Sprint 14` — Onboarding Rules & Label Taxonomy
- `Sprint 15` — First-Run Setup & Label Prompt UX

## Exit Criteria

- users can define a small set of triage rules without seeing extra PMS complexity
- custom labels and default labels are framed as workflow tools, not decorative tags
- onboarding output can be consumed by the backend triage pipeline
